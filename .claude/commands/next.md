世界の時間を進める。日数: $ARGUMENTS（空なら1日）。

**最初に1回だけ**、satoya に次を短く聞く: 今夜どこで眠るか（宿・野宿など）／夢式で仕込む型（枠の数まで。対象・作用・規模）／枠を空けて夢の中で修練するか／触媒を消費するか（持っていれば）。$ARGUMENTS や直前の会話ですでに分かっていれば聞かない。2日以上進めるときは、毎晩同じでよいかも一緒に確認する。

そのあと、黙って1日ずつ次の手順を繰り返すこと。判定はすべて `python3 tools/roll.py` で行い、結果を自分で選ばない。

0. **暮らしの出費**（`world/state/inventory.md` と `world/economy.md`）:
   - その日の食事（satoya の予定どおり。食べなければ翌日「空腹」で判定 −1、二日続けば HP −1）と、寝床の代金を引く。払えなければ寝床は野宿（悪い寝床）になる。
   - 使った消耗品（たいまつ、油、保存食、薬）を減らす。
   - スマホの電池を減らす（使った日は −10%、使わなくても −2%）。
   - 取引の記録に1行ずつ書く。
0.5 **館の石鹸場**（CLAUDE.md 2.8）: `roll.py 1d6` を2回振り、琥珀石鹸と花香の琥珀石鹸の出来を `inventory.md` に足す。
1. `world/state/now.md` の日付と「転移してから◯日目」を進める。天気は `roll.py pick` で決める（季節に合う候補から）。
2. `world/state/clocks.md` の各クロックを、それぞれの「進み方」に従って進める。「世界の動き」のクロックも毎日振る（2d6、11以上で+1。南の海の商いは10以上）。進んだら、`world/realm.md` の「町への届き方」に従って、遅れて町に届ける。
3. 全マス埋まったクロックの出来事を起こす。`world/places/`（いまの様子・変化の履歴）、関係する `characters/` と `journal/`、`now.md` の噂を書き換える。必要なら新しいクロックを作る（隠すものは `world/_gm/secrets.md` へ）。
4. `world/state/consequences.md` で期日が来た結果を起こし、「発生済み」にする。
4.5 **隠しステータス**（`world/_gm/hidden_stats.md`）: その日の出来事を見て値を上下させ、「変化」に一行書く。閾値をまたいだら、書いてある出来事を起こす（その場か翌日）。足りない軸があれば、語り手が新しく足してよい。
5. `roll.py event` を1回振り、町の偶然の出来事を1つ作って反映する（小さくてよい）。新しく作った事実は `world/state/pending.md` に【仮】で書く。
   - 割合は CLAUDE.md 4章の「町の出来事の割合」に従う（別の筋がおよそ半分、ユウや知っている人物に関わる出来事がおよそ半分。夢・夢式に結びつくものは十に一つくらい）。
6. 進行中のクロックが3つ未満なら、町の状況から新しいクロックを足す。
7. `world/state/sheet.md` の成長処理（`rules/system.md` の「成長」）:
   - ✓ の付いた能力値ごとに `roll.py grow <現在値> transferee` を振り、値と修正値を更新して ✓ を消す。
   - 技能の「今日の使用」と、その日の修練を修練ptに足す。必要量に達したらレベルを上げる。
   - HP を休息分回復する。MP は寝床に応じて回復する（ちゃんと眠れば全回復）。「疲労」を消す。
   - 夢式: 前の晩の仕込みを消して、今夜の型を仕込む。枠を空けて修練したなら夢式の修練pt +1。触媒を消費したなら、`_gm/secrets.md` の対応表に従って作用のかけらを与え、翌朝の描写で夢の内容としてそれとなく見せる。
   - 熟練: 各作用の「30日内の成功」から30日より古いものを消し、5回以上なら熟練にする。
   - 成長があれば「成長の記録」に書く。

すべて終わったら、**satoya に見えたり聞こえたりする範囲だけ**を、世界の中のものとして短く伝える。たとえば朝の様子、張り紙、宿の主人の世間話など。3〜6文で、見えないところで起きたことは書かない。
そのあと、成長した能力値・技能があれば `〔…〕` の1行ずつで表示する（修正値が上がったものは目立たせる）。所持金の増減も `〔所持金 …〕` の1行でまとめて出す。
最後に1行だけ、素の Claude として `// ◯日進めました（世界の日付: …）` と出し、commit と push をする。
