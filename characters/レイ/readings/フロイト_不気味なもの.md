# 不気味なもの

- 著者：ジークムント・フロイト
- 原題・発表年：Das Unheimliche（1919年、雑誌『イマーゴ』に発表）
- 読んでいる版：（瀬島が決めたら書く。邦訳は複数ある。例：光文社古典新訳文庫（中山元訳）、岩波書店『フロイト全集』第17巻。どの巻・どの文庫かは手元の本で確かめる）
  - オンライン：ドイツ語原文は Project Gutenberg（eBook #34222）で無料で読める。底本は『イマーゴ』第5巻（1919年）pp.297–324。日本語訳は青空文庫などでは見つからなかった（2026-11-09 調べ）
- 長さ・区切り方：全3節。一回に1節ずつ読む
  - 第1節：heimlich / unheimlich という言葉の分析（辞書をたどる、やや退屈だが核心）
  - 第2節：ホフマン『砂男』の分析と、不気味さの実例（分身、くり返し、思考の全能など）
  - 第3節：現実で出会う不気味さと、物語の中の不気味さの違い
- 読む理由：瀬島がホラーのシナリオを書くうえで、恐怖の「型」の一つを根本から知るため
- 進み具合：未読（これから第1節）

## 全体の見取り図
- 先に言葉から攻め、次に実例を集め、最後に「では物語ではどうなるか」に進む構成
