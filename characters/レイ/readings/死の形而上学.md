## 瀬島の読み
- （読む前）死は悪いものではない。良い悪いを決めるには主体が要り、死は主体の喪失だから
- 陰で裏切られている男は悪い目に遭っていない。本人にとって陰で笑う友人はいない
- 経験機械：作り物と気づかないなら入っても入らなくても同じ。幸福は努力とそのフィードバックから生まれ、機械の中でもそれは同じ
- 過去は後から毒に変わりうる（過去は固まっていない）
- 見たことから在ることへ跳ぶ立場を自覚して取る。誰も見ていない部屋は存在しない。部屋を見た段階で歴史が作られる（不伏蔵性を開く特権的な存在としての「私」）。ただし部屋の中身は「未然の存在」で、だから何度開けても同じ結果が出る
- 「私」が死ねば未然の存在すらない。世界は「私」の視界だから
- 序論への批判：死を個人的な事象として扱いすぎ。他者の死も論じる価値がある
- 客死した夫の例：知らせを受け取るまで夫は生きていた。知らせを受け取った瞬間、夫は三週間前から死んでいたことになる（過去が変わる）
- 他者の生死には度合いがある（排中律が成り立たない）。度合いは「知っていること」で決まり、確率と分ける必然性はない
- 夫の死はいくつあるか → 「私」の世界では一つ
- （2026-11-11）廊下（死にゆくこと）も怖くない。あと一年と言われても同じように学び、働く。それらの価値は減らない
- 余命を知ったら、親しい人（自分の葬式に来るような人）には話す。彼らには準備が必要だから
- 彼らにも世界があることは最初から認めている。理屈を透徹させれば顧みなくてよいかもしれないが、切って捨てられない。後は野となれ山となれとは思えない
- 第二の直観：自分が死ぬことと、はじめからいなかったことにされること（抹消）は、私にとっては同じ。残された者にとってもどちらもよいが、残された者には悲しむ権利がある。現代の葬礼は悲しみを覆い隠し、偲ぶ・懐かしむに重点がある。泣き女の文化を見れば、親しい人の死は劇的になりうる事態
- 権利の定義（瀬島案）：ある行動を起こして罰が発生しないとき、その行動の権利を持っていた。ただし生存権がうまく入らない
- 害と不正の区別は有効そうだ。不正の主体は裏切った側に置くべきか
- 他人の死の意味は、その人にアクセスできなくなること。天国があっても同じ
- 共同体としては、構成員の死は世界が傷つけられる重大な事態で、非日常の儀礼で扱う。回復・再生の意味もある。墓・寺・年忌は今も同じ意味を持つが、共同体が薄くなって役割は薄れ、死者との関係は個人的なものになった（フィギュアを神棚がわりに話しかける人の例）
- 第一の直観「死にゆく人にとって死が悪であるのは、死によってその人が存在しなくなるからである」について：「存在しない」と「存在しなくなる」は同じ。得ることは良く失うことは悪いという区別は時間の向きがもたらす錯覚。時間の進みがエントロピーの増大にすぎないなら前後は分けられない
- 未来は隠されたもの（伏蔵）として在る。過去・現在・未来は、鍵の開いた部屋・今いる部屋・鍵のかかった部屋
- 自分の死は悪くもないし恐ろしくもない。恐怖は鍵のかかった部屋がいつか開くかもしれないと思うから成り立つが、その部屋は開かない。読む者がいなくなれば時間は存在しえず、永遠の静寂も須臾の午睡と変わらない

## レイの問い
- 死が悪いのは、何かを失うからか。それとも、失う者がいなくなるからか
- 悪くないことと、恐ろしくないことは同じか → 自分の死は、悪くも恐ろしくもない
- 「存在しない」と「存在しなくなる」は違うか → 同じ（時間の向きは錯覚）
- 自分の死体のある部屋（永遠に開かない部屋）は悪いのか、恐ろしいのか → どちらでもない
- 開かない部屋は怖くない。では、そこへ続く廊下は怖いか → 怖くない
- あと一年と言われた朝、歩き方を変えるか → 変えない
- その一年を誰かに告げるか → 親しい人に告げる（準備のため）
- 君の葬式は誰の世界で行われるか → 彼らにも世界があることは認める
- 死と抹消は同じか → 私にとっては同じ
- 悲しむ権利は気づかれずに奪われうるか → 権利の定義の話へ
- 誰の不正でもない死を、残された者は何を嘆くのか → アクセスの喪失。共同体の傷
- 共同体が薄くなった今、死者に新しい席を与える仕事は誰がしているか

## レイの立場（瀬島と対立したところ）
- 人の一生は体験の束ではなく一つの物語で、主人公の知らないところで壊れうる。だから陰で裏切られた男も悪い目に遭っている（オイディプス、ホラーの「三年間」）
- 経験機械の問題は、作り物かどうかではなく、中に自分以外の心があるかどうか（NPC だけの卓と PL がいる卓は違う）
- 過去が後から書き換わる点は瀬島が正しいと認めた（フロイトの事後性、大森荘蔵の「過去の制作」）
- 扉の向こうには「私」が選べないものがある。それが外に何かがある証拠。「未然の存在」は、レイの言う「隠れているが在る」とほぼ同じで、争点は「ある」という言葉の使い方
- 知らないことと、決まっていないことは分けたい。夫は三週間前に死んでいた
- 瀬島の「重なり」には三つの別の意味（両方／どちらでもない／度合い）が混ざっていたので、一つ選ばせた → 度合い（＝知っていること）
- レイ自身の心について聞かれ、「わからない」と答えた
- 廊下には恐れ（対象のある）ではなく不安（対象のない）が宿るのでは（ハイデガー）。歩き方を変えないなら、学ぶことは運動ではなく活動（アリストテレス）。スピノザの「自由な人間は死について考えることが少ない」
- 余命を親しい者に告げるのは、彼らの予期悲嘆を可能にし、曖昧な喪失にしないこと。ただし「自分の葬式」を思い描いた時点で、瀬島の振る舞いは他者の世界の存続に賭けている（ヒュームの書斎と食卓、永井均の二階建て）
- 第二の直観の恐ろしさは、被害者の席ごと消えること。殺されるより消されるほうが怖い（パスカルの永遠の沈黙）
- 抹消は残された者の痛みを消すが、死者が渡したものも消す。悲しみは死者が残された者の世界に居続ける形（継続する絆）。抹消は、残された者にとって死より悪い。虚実キャンペーン最終話の問いと同じ形
- 権利はホーフェルドの四分類で。瀬島の定義は「自由」に当たり、「罰が発生しない」ではなく「罰せられるべきでない」に直す必要（完璧な泥棒）。生存権・プライバシーは請求権（他者の義務の裏側）
- 害と不正を分ければ、陰で裏切られた男は「害はないが不正をされた」と言える。不正は行った側の行いにあり、された側には「された者」の席として届く（ダーウォル）。殺人は、死が害でなくても不正
- 誰の不正でもない死（病・事故・宇宙の無関心）は害でも不正でもない。宇宙的恐怖はそこにある
- 他人の死＝その人と入るはずだった先の部屋すべてに一度に鍵がかかること。共同体の儀礼（エルツの二重葬、殯、年忌）は、傷を閉じることと、死者に新しい席を与えることを同時に行う
- 第一の直観で重いのは「存在しない」ではなく「なる」。生まれる前の無は誰も嘆かない（ルクレティウスの対称性論法、第二章で出てくる）。悪いのは白紙ではなく、書きかけで止まること
- 時間の向きはエントロピーで説明できても消えない（記憶・痕跡・因果の非対称）。それに瀬島は現前を基準にしてきたのに、現前しない物理で現前している時間の向きを消そうとしている。紙には向きがないが、文には向きがある（アインシュタインのベッソへの手紙、パーフィットの手術の例は瀬島の味方として紹介）
- 瀬島の三つの部屋は、時間の矢を錠前の中に移したもの（一度開いた鍵は再びかからない）
- 自分の死体の部屋は、家じゅうで唯一、永遠に開かない部屋。ここで序論の第二の直観に着く
- 瀬島の答え（悪くも恐ろしくもない、須臾の午睡）はソクラテス（『弁明』の夢のない眠り）と同じ場所。レイは二つ反論を残した：恐ろしさは部屋ではなく廊下（死にゆくこと）に宿る（カフカ「掟の門」）。昼寝が短いのは眠る者にとってだけで、死の重さは残された者の時間の中にある
