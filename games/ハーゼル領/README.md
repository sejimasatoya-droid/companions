# ハーゼル領記 ― 辺境男爵家の跡取りに転生して

中世ヨーロッパ風ファンタジー世界の小さな領主の息子に転生し、
子ども時代を経て、いずれ領主として領地を運営していくシミュレーションゲーム。

Claude がゲームマスター（GM）兼、登場人物全員を演じる。

## ファイル構成
| ファイル | 中身 | プレイヤーが読んでよいか |
|---|---|---|
| `system.md` | ゲームのシステム（ターン・資源・クロック・説得・勢力・人物の演じ分け） | ○ |
| `state.md` | 現在の状況（年・能力・資源・指標・クロック・噂） | ○ |
| `log.md` | これまでの出来事の記録 | ○ |
| `world/王国.md` | アルヴェン王国の歴史・政治・身分・法・軍事 | ○ |
| `world/宗教と魔法.md` | 光輪教会、祝福（ギフト）、魔獣 | ○ |
| `world/経済と暮らし.md` | 通貨、物価、税、暦、技術水準、日常 | ○ |
| `world/勢力/` | 寄親・隣領・教会・商会・外国などの勢力 | ○ |
| `domain/ハーゼル領.md` | 領の地理・村・産業・財政・課題 | ○ |
| `npcs/` | 人物シート（性格・価値観・欲・秘密・話し方・関係値）。`index.md` に対比表 | △（秘密の欄はネタバレ） |
| `gm/秘密.md` | GM だけが知る隠しクロック・裏設定 | ✕ |

## 遊び方（プレイヤー向け）
- 「ハーゼル領の続きをやろう」「ゲームを始めよう」と言えば始まる
- 主人公として、したいことを自由に書けばよい（「父の書斎に忍び込む」「村の水車小屋を見に行く」など）
- 「今の状況は？」で数値を確認、「季節を進める」で時間を進める
- 「今日はここまで」で記録して終了

## 物語の段階
1. **幼年期（5〜11歳）**：前世の記憶が戻ったところから。領内を知り、人と縁を結び、小さな改良を試す
2. **少年期（12〜16歳）**：主家ローゼンハイム辺境伯の城へ小姓・従士として出仕。人脈と武芸と政治を学ぶ
3. **領主期（家督相続以降）**：領主として内政・外交・軍事を担う
