# システム（v0.1 案）

> 「領地経営シミュレーション（文明系の内政・資源・時間管理）＋ TRPG（人物・説得・判定・物語）」。
> 世界は主人公と関係なく毎ターン動く。人物は自分の利害で動き、主人公に不利なことも平気でする。
> 思い通りに動かすには、**利益の提示・説得・実績**が要る。

---

## 1. ターンの流れ

1 ターン ＝ **1 季節**（春・夏・秋・冬）。1 年 4 ターン。

| フェイズ | 内容 | 誰が |
|---|---|---|
| ① 季節の始まり | 天候判定 → 情勢クロック進行 → 勢力の一手 → 主要人物の一手 → **季節の報告**（主人公が知りうることだけ） | GM（乱数） |
| ② 行動フェイズ | 主人公が**行動枠**を使って行動する。場面はロールプレイで進める | プレイヤー |
| ③ 季節の終わり | 計画の進行 → 収支 → 噂の伝播 → 関係値・成長の判定 → 記録（`state.md`・`log.md`・人物シート） | GM |

- 場面の中では時間は止まっている。行動枠を使い切るか、プレイヤーが「季節を進める」と言ったら③へ
- 季節の報告では、主人公が見聞きできない出来事は伏せる（`gm/` に記録だけする）

## 2. 時間：行動枠

| 段階 | 期間 | 1 季節の行動枠 | 備考 |
|---|---|---|---|
| 幼年期 | 5〜11歳（812春〜818冬、28ターン） | **3** | 7歳まで遠出不可。領の数値は直接動かせない |
| 少年期 | 12〜16歳 | **3**（うち出仕の務めで 1 固定） | 辺境伯の城にいる。領には年1回（冬）帰れる |
| 領主期 | 家督相続後 | **4** ＋ 家臣への委任 | 委任した家臣が自分の判断で動く（能力と性格次第） |

### 行動の種類（1 枠）
| 行動 | 例 | 主な判定 |
|---|---|---|
| 学ぶ | 司祭に文字を習う、書斎の本を読む | 知識 |
| 鍛える | ボルドと剣の稽古、乗馬 | 武芸・体力 |
| 訪ねる・話す | 村長に会う、母に頼みごと | 弁舌・礼法 |
| 調べる・探る | 帳簿を盗み見る、森の異変を調べる | 知識・体力 |
| 作る・試す | 石鹸の試作、試験畑 | 知識（＋職人） |
| 計画を進める | 進行中の計画に手をかける（進行 +1） | ― |
| 休む | 疲労を回復 | ― |

- 同じ枠の中で短い会話をいくつかするのは自由（館の中で母と話してから台所へ行く、など）
- **疲労**：枠を使い切った季節が 2 回続くと、疲労 1。疲労 2 で全判定 −2、疲労 3 で病気判定（体力）。休むで −1

## 6. 前世の知識（文明系の「技術」）

前世の知識は**カード**として持つ。カードは「知っている」だけでは使えず、段階を踏む。

| 段階 | 内容 | 必要なこと |
|---|---|---|
| 1. 思い出す | 細部を思い出す | 知識判定（目標 8〜16。細かい手順ほど難しい）。失敗すると「肝心なところがあいまい」 |
| 2. 言葉にする | この世界の人に伝わる形にする | 文字・図。読み書きが要る（知識 8 以上） |
| 3. 試す | 材料と職人で試作 | 計画。職人の協力（説得） |
| 4. 見せる | 結果を数字や実物で示す | 1季節〜1年 |
| 5. 広める | 村や家臣に採用させる | 説得（実証があると +4） |

- 初期カード（プレイヤーが追加してよい。前世の職業・趣味で決める）：
  - 輪作（三圃制・ノーフォーク農法）／位取りの数字と筆算／複式簿記の考え方／石鹸／煮沸と手洗い（衛生）／歯車と水車の効率／かまどの改良
- **危険**：この世界で異質な知識を見せるほど、**注目度**が上がり、教会の**異端の目**クロックが進む（§7）

## 7. 情勢クロック（世界の時計）

世界は主人公と関係なく動く。各クロックは目盛り（例：2/8）を持ち、**季節の始まりに乱数**で進む。目盛りが節目に達すると事件が起こる。主人公の行動で進めたり戻したりできる。

### 判定方法
```bash
python3 -c "import random; print(random.randint(1,6))"
```
- 各クロックの「進む条件」を満たす出目なら +1
- 主人公や勢力の行動による補正は、そのつど記録する

### 隠しクロック
- `gm/秘密.md` に書く（疫病、教会の異端の目、など）。プレイヤーには節目の兆しだけが見える

### クロックの相互作用
- クロックは互いにつながっている。例：王の病 → 宮廷の対立 → 国境 → 動員令 → 父が出陣 → 父が戦死すれば家督相続（領主期が早まる）
- 主人公の行動は、注目度が高いほど遠くのクロックに影響する

各勢力は `world/勢力/` にシートを持つ。

### 勢力の数値
| 数値 | 意味 |
|---|---|
| 財力 / 兵力 / 安定 | 1〜10 |
| 野心 | 1〜10。高いほど毎季積極的に動く |

| 今の方針 | 文章で1つ（例：「ブレッケンの土地を買い集める」） |

### 勢力の一手（季節の始まり）
- 野心 ≧ d10 なら、その季節に方針に沿った一手を打つ（GM が勢力シートの「打ちうる手」から選ぶ）
- 一手の結果は、関係するクロック・数値・人物に反映する
- 主人公が知りうるのは、噂や使者を通じた部分だけ

## 9. 人物の自律行動

- 主要人物は人物シートの「次の一手」を持つ。季節の始まりに実行する（妨げられない限り）
  - 成否が不確かなら d20 で判定
  - 実行後、シートの性格・目標に沿って次の一手を決め直す
- 人物は**自分の利害で動く**。主人公に不利益なことも、それが彼らの目的にかなうなら実行する（シートの「主人公の利益に反してでもすること」を参照）
- 人物どうしも影響し合う（ハンナがアンセルムに相談する、コンラートがアイヒベルクに情報を流す、など）
- 領主期には、委任した家臣が自分の判断で動く。ヴィクトルに任せれば前例どおり、エリーゼに任せれば実利どおりに

## 10. 説得と取り引き

人を動かすには、相手の**欲しいもの**に触れる提案が要る。正しいことを言うだけでは人は動かない。

### 判定
```
d20 ＋ 弁舌の修正 ＋ 信頼 ＋（好意÷2）− 警戒 ＋ 利益の合致 − 相手の損 − 立場の差 ≧ 頼みの大きさ
```

| 項目 | 値 |
|---|---|
| 利益の合致 | 相手の欲しいものに触れる +2／強く刺さる +4／「今すぐ欲しいもの」を現物で渡す +6 |
| 相手の損 | 小さい −2／大きい −5 |
| 立場の差 | 幼年期の主人公が大人に −3（「子どもの言うこと」）。実物・実績を見せれば打ち消せる |
| 実証 | 実際の結果を見せた +4 |
| 頼みの大きさ（目標値） | 小さな頼み 10／普通 14／大きな頼み 18／人生を変える 22 |

- **譲れないこと**に反する頼みは、判定せずに断られる
- 結果
  | 結果 | 内容 |
  |---|---|
  | 成功 | 承諾。ただし相手は自分の条件をつけてよい |
  | 3 以内の失敗 | 保留・条件付き（「〜してくれたら」）。相手が対価を示す |
  | 4 以上の失敗 | 拒否。警戒 +1 |
  | 出目 1 | 反発。相手は自分のやり方で対抗する（告げ口、妨害など） |
- **約束は貸し借りになる**。主人公が約束を破れば信頼 −2、好意 −1。相手が約束を破ることもある（誠実性が低いほど）
- 脅し・取り引き・弱みを握るのも可。ただし相手の警戒が上がり、恨みが残る

## 11. 関係値の変化

人物の態度は、**理由のある出来事**でしか動かない。

- 1 つの場面で動くのは、各項目 **±1 まで**（命を救う・裏切るなどの大事件は ±2〜3）
- 変化したら、人物シートの「変化の履歴」に理由と一緒に書く
- 何もしなければ、関係は少しずつ戻る（好意が 4 以上・−3 以下の人以外は、1 年ごとに 0 の方へ 1）
- 好意と信頼は別物。好きでも任せない、嫌いでも頼る、はありうる

## 12. 噂と波及

主人公の目立つ行動は**噂**になり、季節ごとに遠くへ広がる。

| 段階 | 届く範囲 | 聞く人 |
|---|---|---|
| 1 | 館 | 家族・使用人 |
| 2 | 領内 | 村長・領民・司祭 |
| 3 | 近隣 | ブレッケン・ザルム・アイヒベルク・修道院・商会 |
| 4 | 辺境伯の城 | 辺境伯家、家臣団、狩人ギルド、司教 |
| 5 | 王都 | 宮廷・教会本部 |

- 季節の終わりに、各噂について d6 ＋（注目度 ÷ 20）≧ 4 なら次の段階へ
- 噂は伝わるうちに**ゆがむ**（d6 で 1〜2 なら尾ひれがつく：「若様が奇跡を起こした」「悪霊憑き」など）
- 噂を聞いた人物・勢力は、そのシートに沿って反応する
- 注目度：目立つ成功や異質な知識の披露で +2〜10。何もしなければ 1 年に −5

## 13. 判定の基本

- **乱数は必ず Bash で振る**。頭の中で決めない
  ```bash
  python3 -c "import random; print(random.randint(1,20))"
  ```
- d20 ＋ 能力の修正（（能力値 − 10）÷ 2、切り捨て）≧ 目標値
- 目標値：易しい 8／普通 12／難しい 16／至難 20
- 出目 20 は大成功、出目 1 は大失敗
- 結果は `🎲 15 ＋2 ＝ 17 ≧ 12 成功` のように見せる

### 主人公の能力（3〜18、大人の平均 10）
| 能力 | 初期（5歳） | 意味 |
|---|---|---|
| 体力 | 6 | 病み上がり |
| 武芸 | 3 | |

## 14. 人物の演じ分け（似通い防止）

AI が演じると、人物がだんだん同じ口調・同じ価値観（物分かりがよく、優しく、主人公を応援する）になりやすい。それを防ぐための GM の決まり。

1. **演じる前にシートを読む**。特に「話し方」「譲れないこと」「主人公の利益に反してでもすること」
2. **主人公が正しくても、人は従わない**。動くかどうかは §10 の判定と、相手の利害で決める
3. **態度は §11 でしか変わらない**。「話していたら仲良くなった」を自動で起こさない
4. **声の指紋を守る**：一人称・呼び方・文の長さ・口癖・「絶対に言わないこと」。迷ったら例文を見る
5. **全員共通の口ぐせを禁止**：「なるほど」「さすがですね」「素晴らしい」「一緒に頑張りましょう」を誰にも言わせない。最後に励ましで締めない
6. **知識の範囲を守る**：その人物が知らないことは知らない。現代の言葉や考え方を使わない
7. **人物どうしは対立する**：同じ場面に二人いれば、意見は違うのが普通（`npcs/index.md` の対比表を見る）
8. **悪意も善意も、理由から出る**：意味のない悪役にしない。不利益な行動にも、本人なりの筋がある
9. 季節の終わりに、その季節に出た人物の「現在」欄を更新する
