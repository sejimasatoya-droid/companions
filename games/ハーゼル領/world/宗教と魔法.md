# 宗教と魔法

## 光輪教会
- 王国の国教。唯一神「**光の主**」と、その使いである**七聖人**を崇める
- 象徴は金色の輪（光輪）。聖印は指で輪を作るしぐさ
- 七聖人と守護分野
  | 聖人 | 守護 |
  |---|---|
  | 聖ルミナ | 光・始まり（教会の開祖） |
  | 聖ハルトムート | 農耕・収穫 |
  | 聖イルザ | 癒し・出産 |
  | 聖ベルトラム | 戦い・騎士 |
  | 聖マルガ | 商い・旅 |
  | 聖オズヴィン | 学問・記録 |
  | 聖ディートリンデ | 死・冬 |
- 組織：大司教（王都）→ 司教（各地）→ 司祭（教区）→ 助祭・修道士
- 収入：**十分の一税**（収穫の1割）を領民から直接取る。領主の年貢とは別
- 教会の考え
  - 祝福（ギフト）は光の主からの授かりもの。教会の洗礼でのみ「正しく」目覚める
  - 洗礼を受けずに魔法を使う者は「**野良（のら）**」と呼ばれ、異端の疑いをかけられる
  - **転生**の教義は無い。むしろ「死者の魂は冬の聖人のもとで眠る」とされ、前世の記憶を語るのは**悪霊憑き**を疑われる危険がある
- 修道院は学問・医療・醸造の中心。字が読める人の多くは聖職者

## 祝福（ギフト）＝魔法
- この世界の魔法は「祝福」と呼ばれる。人口の **およそ 1/30** に宿る
- **7 歳の洗礼式**で教会の聖水と祈りによって目覚め、系統が判明する
- 貴族の家系ほど祝福を持つ割合が高い（1/5 ほど）。これが貴族の権威の一つになっている
- 系統
  | 系統 | できること（初歩→熟練） |
  |---|---|
  | 火 | ろうそくを灯す → 鍛冶の炉を高温に保つ → 戦場で火球 |
  | 水 | 露を集める → 井戸の水脈を探す → 小規模な雨 |
  | 土 | 土の良し悪しがわかる → 土を締める・崩す → 堀や土塁を短時間で作る |
  | 風 | 煙を払う → 風車を回す程度の風 → 矢をそらす |
  | 癒し | 傷の治りを早める → 熱を下げる → 骨をつなぐ（病気そのものは治せないことが多い） |
  | 見識（けんしき） | まれ。物の性質がわかる、嘘を見抜く等。教会が囲い込みたがる |
- 制約
  - 魔力（体力に近い）を使い、使いすぎると倒れる
  - 魔法で物を無から作ることはできない。あるものを動かし、変える力
  - 大魔法は数人がかりで儀式をする必要がある。戦争の勝敗を一人で決めるほどの魔法使いは伝説の中だけ
- 祝福持ちの扱い：平民でも祝福が強いと、教会か大貴族に召し抱えられる。王立学院には祝福学の科がある

## 固有魔法（伝承）
- 六系統に当てはまらない祝福は、記録の上では数百年に一度しか現れない。教会は「聖人の再来」として祀るか、「悪魔の業」として焼くかのどちらかで扱ってきた
- 旧エルデン帝国の伝承には「**刻（とき）の司**」と呼ばれた魔法使いたちが出てくる。帝国の塔は彼らが建てた、と吟遊詩人は歌う。学者の多くは作り話だと考えている

## 魔獣
- 人の手が入らない深い森・山には**魔獣**が棲む。体内に「**魔石**」を持つ獣
- 魔石は灯り・保温・魔法の補助に使われ、高値で売れる（小粒で銀貨 10 枚〜）
- 主な魔獣
  | 名前 | 特徴 | 危険度 |
  |---|---|---|
  | 角兎（つのうさぎ） | 額に角。畑を荒らす | 低 |
  | 灰狼（はいおおかみ） | 群れで行動。冬に村へ降りてくる | 中 |
  | 森猪（もりいのしし） | 牛ほどの大きさ。突進で柵を壊す | 中 |
  | 樹蜘蛛（きぐも） | 木の上から糸を垂らす。毒は弱いが麻痺する | 中 |
  | 黒熊（くろぐま） | 魔石が大きい。猟師数人でも危ない | 高 |
  | 森の主 | ハーゼル領の黒の森の奥にいると伝わるもの。正体不明 | ？ |
- 魔獣狩りは猟師と、流れの**狩人ギルド**の仕事。領主は狩猟権を持ち、魔石の一部を税として取れる
