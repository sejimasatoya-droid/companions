# アルヴェン王国

## 概要
- 大陸西部の中規模の王国。人口およそ 280 万
- 王都：**ヴァルトブルク**（人口約 6 万。大河ルーネ川の中流）
- 国王：**オトマール三世**（58歳）。温厚だが優柔不断。病がち
- 王家：**ヴェルナー家**。建国から約 340 年
- 気候：冷涼で湿潤。北は針葉樹の森と山、南はぶどうの丘陵、西は海
- 地形の印象：北のフランス〜ドイツあたりに似た、森と川と丘の国

## 歴史（ざっくり）
| 年（聖暦） | 出来事 |
|---|---|
| 0 | 聖ルミナが「光の輪」を受けたとされる年。光輪教会の暦の起点 |
| 約300 | 旧帝国（**エルデン帝国**）が衰退し、各地に諸侯が自立 |
| 472 | 初代王アルヴェン一世が東部諸侯を束ねて建国 |
| 530〜610 | 「森の時代」。魔獣の大発生が繰り返され、北部の開拓が進まない |
| 641 | 北の山岳地帯を征して辺境伯領を設置。**ローゼンハイム家**が初代辺境伯に |
| 703〜711 | **七年戦争**（対 東のカルディア公国）。引き分けに近い講和 |
| 755 | 黒死病に似た疫病「灰咳（はいせき）」が流行。人口の 1/5 が死亡 |
| 788 | ハーゼル家が功により男爵に叙される（それまでは騎士家） |
| 806 | 北部で凶作。各地で小規模な一揆 |
| **812** | **ゲーム開始**。主人公 5 歳 |

## 政治の仕組み
- **封建制**。国王 → 大諸侯（公爵・辺境伯・伯爵） → 中小貴族（子爵・男爵・騎士）の主従関係
- 王の直轄地は全土の 2 割ほど。王権は強くない
- 中小貴族は国王ではなく**直接の主君（寄親）**に忠誠を誓うのが普通。ハーゼル男爵家の寄親はローゼンハイム辺境伯
- **王国議会（諸侯会議）**：課税や戦争の際に招集。中小貴族は寄親を通じてしか意見を言えない
- 現在の政局
  - 国王に男子が一人（**王太子ジークベルト**、24歳、武断派）、王女が二人
  - 王太子派（武断・東方強硬）と宰相派（**宰相グリューネヴァルト侯**、文治・商業重視）が対立
  - ローゼンハイム辺境伯は中立を装っているが、内心は王太子派寄り

## 身分
| 身分 | 内容 |
|---|---|
| 王族 | ヴェルナー家 |
| 上級貴族 | 公爵（3家）・辺境伯（2家）・伯爵（約20家） |
| 下級貴族 | 子爵・男爵（約120家）、騎士（数百家。世襲だが領地は小さいか無い） |
| 聖職者 | 光輪教会。司教以上は貴族の次男三男が多い |
| 自由民 | 都市の市民（商人・職人）、自由農民 |
| 農奴 | 土地に縛られた農民。移動・結婚に領主の許可が要る。ハーゼル領の農民の約6割 |

- 貴族の名前は「名・フォン・家名」。例：レオポルト・フォン・ハーゼル
- 長子相続が原則。ただし男子がいなければ娘婿が継げる
- 貴族の子は 12 歳前後で寄親の城に**小姓**として出仕し、15〜16 歳で**従士**、武功や儀式を経て**騎士叙任**される
- 文官志望の子は王都の**王立学院**（13〜18歳）に行く道もある。学費は高い（年 30 金貨）

## 法と裁判
- 領内の軽い罪（窃盗・喧嘩・境界争い）は**領主が裁く**（下級裁判権）
- 殺人・反逆など重罪は寄親の辺境伯の法廷へ（ハーゼル男爵家には上級裁判権がない）
- 慣習法が強い。「昔からそうだった」が一番の根拠になる
- 決闘裁判は貴族同士では今も残っている（めったに行われない）

## 軍事
- 常備軍はほとんどない。戦時に諸侯が兵を率いて集まる
- 男爵家の義務：戦時に **騎士1名＋兵12名** を40日間、自費で辺境伯に供出（軍役）。代わりに**軍役代納金**（年 25 金貨）で済ますこともできる
- 主力は重装騎兵。歩兵は槍と弩。長弓はまだ普及していない
- 火薬は存在しない（少なくとも知られていない）
