# エルデン学院（魔法学院）

> 第五章「学院編」（ライが 15〜18 歳、聖暦 821 年秋〜824 年夏の見こみ）の舞台。プレイヤーが読んでよい表の設定。裏の設定は `gm/学院編.md`。

## あらまし
- 大陸のあちこちの国と領から、**祝福（魔法）を持つ 15〜18 歳の若者**が集まって学ぶ学院
- 場所：**自由都市アルトハイム**。旧エルデン帝国の都の跡に建つ、どの王にも属さない都市。アルヴェン王国の南西、三つの国の境の、ルーネ川とその支流が出会うところ（ハーゼル領から馬で十二日ほど）
- 創立：聖暦 312 年。帝国が滅びたあと、焼け残った帝国の書物を守った学者たちと、光輪教会の大修道院が、ともに建てた
- **学院の誓い**：「学院の門の内では、国も身分も問わず、祝福を学ぶ者は等しい」。門の内で剣を抜くこと、国どうしの争いを持ちこむことは禁じられている。……建前としては
- 学院を支えているのは、各国の王家と大貴族の寄進、教会、自由都市の商人。どの国も「自分の国の若者が学院でいちばん」と見せたがる

## 学院のしくみ
- **入学**：15 歳前後。洗礼で祝福が認められていること。国の王家、大貴族、教会、または学院の師の**推挙**が要る
- **学費**：年 40 金貨（寮と食事を含む）。推挙した家や国が出すことが多い。平民の祝福持ちには、学院や教会の**給費生**の枠がある
- **年限**：三年。一年目は六系統すべての基礎と、読み書き・算術・古エルデン語。二年目から、自分の系統の師について学ぶ。三年目の終わりに**修了の試し**がある
- **師**：六系統それぞれに師がいる。ほかに古エルデン語、魔石学、薬草学、祝福の法（教会の法）の師
- **学寮**：学生は四つの学寮に分かれて住む。国ではなく、入学の順にくじで決まる。だから、敵どうしの国の子が同じ屋根の下で寝起きする
  | 学寮 | 由来 | 気風 |
  |---|---|---|
  | 灰の塔（アッシュ） | 帝国の書物を守った学者たち | 学問好き。書庫に入りびたる |
  | 鐘楼（グロッケ） | 教会の大修道院 | 信心と規律。祈りの刻を守る |
  | 川門（フルス） | 自由都市の商人 | 金と取引に明るい。賭けごとも |
  | 古城（ブルク） | 帝国の騎士の館の跡 | 武芸と馬。騎士の家の子が多い |
- **学院での評判**（0〜100）：師と学生からの見られ方。修了の試しと、その先の道に効く
- **長い休み**：夏に六週、冬に二週。夏はハーゼルへ帰れる（往復で三週半かかる）

## 学院に来る国と土地
| 国・土地 | どんな所か | 学院での立場 |
|---|---|---|
| **アルヴェン王国** | ライの国。いまは摂政と王太子に割れている | 学生がいちばん多い。王国の中の争いが、学院の中にまで持ちこまれている |
| **カルディア公国** | 東の隣国。鉄鉱山。七年戦争の相手で、いまも戦の気配 | 火の祝福に強い。アルヴェンの学生とは犬猿の仲 |
| **ルーネ河口の都市同盟** | 南の河港リーベンなど、商人の自由都市の集まり | 学院の金の出どころの一つ。商人の子の給費生が多い |
| **セルヴィア諸島** | 西の海の島々。船乗りと海の祈り女の国 | 風と水の祝福。風変わりで、王も貴族も嫌う |
| **ヤスガル草原** | 東の果ての騎馬の民。獣と話す者がいるという | 学院では珍しい。今の代に、初めて王子が来た |
| **メリディア帝国** | 南の大きな帝国。旧エルデン帝国の後継ぎを名のる | 学院にいちばん多く寄進する。いちばん多く口も出す |
| **聖座（教会）** | 光輪教会の大修道院と聖職者 | 学院の半分の持ち主。祝福の法と「野良」の取り締まりを担う |
| **北の山（ヴァルク）** | 学院に山の民が来たことは、一度もない | ― |

## 学院での一年
| 時期 | 出来事 |
|---|---|
| 葡萄月（10月） | 入学の儀。くじで学寮が決まる |
| 屠月〜聖月 | 基礎の講義。学寮どうしの対抗戦（祝福を使わない、棒術と馬） |
| 聖月の終わり | 冬の休み（二週） |
| 灯月〜花月 | 系統の講義。古エルデン語の試し |
| 緑月 | **学寮対抗の祝福の競い**（各学寮から代表。見物に各国の使節が来る） |
| 草月〜陽月 | 夏の休み（六週） |
| 三年目の麦月 | **修了の試し** |

## 学院の外：自由都市アルトハイム
- 人口およそ 3 万。旧帝国の都の、崩れた城壁と円柱の上に、新しい町が建っている
- 市参事会が治める。各国の使節館がある。**スパイと商人と学者の町**
- 旧帝国の都の地下には、まだ掘られていない回廊と書庫が眠っていると言われる
