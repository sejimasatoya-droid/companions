# リアナ（大航海の TRPG・ローグライク）

大洋に面した小さな王国リアナ。瀬島の主人公は、借金で古いキャラベルを手に入れたばかりの船長。海図の空白へ漕ぎ出し、風を読み、売り、買い、見つけ、地理院に持ち帰る。
世界は主人公を待たない。ヴェスカの船長も王国の提督も、先に岬を回り、先に報告しようとしている。
海は手加減しない。水と食料は毎日へり、嵐は船を壊し、病は人を連れていく。**船長は死ぬ。死んだら誰かが跡を継ぎ、海図と名だけが残る。**

- 型：ソロ（主人公は船長。士官と水夫はNPC）
- 判定：2d6 ＋ 能力 ＋ 技能
- 死にやすさ：重い。代替わりあり（ローグライク）
- 航海：96×48 マスの海。風・水・食料・士気・嵐・出会いを道具が一日ずつ振る
- 交易：港ごとの相場。買えば上がり、売れば下がる。遠いほど儲かり、遠いほど死ぬ

## GM の約束（Claude 向け）

1. **航海は道具で動かす。** 海の上の一日は `umi.py sail / goto / wait` が振る。風・進み・水・食料・嵐・出会いを、GM が都合で変えない。直すときは `umi.py set` を使い、理由を `gm/判断記録.md` に書く
2. **[GM] の行は見せない。** 道具の出力のうち [GM] で始まる行は GM だけが読む。瀬島には劇中のことばにして伝える
3. **出会いは表と方針表で決める。** `gm/出会い表.md` を振り、相手の出方は `gm/方針表.md` を振る。主人公に合わせて選ばない
4. **NPC は `gm/NPCの動かし方.md` に従って動かす。** 場面の前に、その人の動き方・台詞の例・帳面を読む。`umi.py` が出す `[GM] 仕掛け` で仕掛けた者は、帳面の未着手から一つ実行する。`[GM] 甲板の出来事` は、船長の見ていないところで士官どうしに起きたこととして場面にする
   - 方針を決める場面では、航海士・主計長・水夫長が先に言う。強さは `dice.py opinion`。船長の案にただ乗らない
   - 場面が終わるたびに、その場にいた人物の帳面に一行。人物どうしの思いが動いたら `umi.py rel` と `gm/関係.md`
5. **世界は日ごとに進む。** 時計は道具が進める。満ちたら `gm/時計.md` どおりに起こす。主人公の耳に入るのは、届く道があるときだけ
6. **死は本当に起きる。** 敵は手加減しない。沈む船は沈む。船長の生死は `fate`。代替わりは `ルール.md` どおり
7. **隠しごとを漏らさない。** gm/ の中身（海の本当の形、季節、人の裏）を、NPC の口を借りても、地の文でも明かさない。主人公が聞く・調べる・見るを通ったものだけ
8. **選択肢を並べない。** ヒントを頼まれたら、主人公が知っていることから問いで返す
9. **後から足さない。** 港・発見物・海の形は `gm/海.json` と gm/ の表にあるものだけ。足すなら遊ぶ前に書き、`gen.py` を直して build する（遊び始めたら海は作り直さない）
10. **海の上は短く、港と人は長く。** 何事もない日は「〇日、南西へ。水があと〇日」でまとめる。止まった場面で腰を据える

## 進め方

- 道具は `games/リアナ` で動かす：`python tools/umi.py ...`、`python tools/dice.py ...`
- 始め：README → ルール → 主人公 → 状態.md → `umi.py status` → 最新のログ → `gm/NPCの動かし方.md` → `gm/` のうち、いま関わる港・人物と関係（`umi.py who`）・時計（`umi.py clocks`）・判断記録
- はじめての回：主人公.md の作り方で船長を作り、`状態.json` の captain と船の名を書きこむ。出自の持ち物（金貨・水夫・砲など）も足す
- 港で：相場を見て、積み、雇い、払い、直し、人と話す
- 海で：方角か目的地を決めて帆を張る。止まったら場面にする
- 終わり：`umi.py map` で海図を書き出し、ログ・状態.md・人物.md・gm/ の帳面と判断記録を更新し、コミットして push
