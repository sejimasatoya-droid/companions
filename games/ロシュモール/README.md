# ロシュモール年代記 ― 霧と誓いの港町

中世ヨーロッパ風の、霧の濃い海辺の公国。塩と毛織物の港町ロシュモールの**守り手**（城と兵と裁きを預かる者）になって、
一週ずつ町を治めていくシミュレーションゲーム。ハーゼル領とは別の世界。

Claude がゲームマスター（GM）と、登場人物の全員を演じる。

## このゲームの芯
- **人物は主人公を待たない。** 町の人はそれぞれ自分の欲で**企て**を持ち、毎週それを進める。企てが進むたびに、主人公は巻き込まれる（頼まれる・板挟みになる・秘密を知る・濡れ衣を裁く・誓いを求められる）
- **同じ出来事は繰り返さない。** 出来事は季節ごとの山札から引く。引いた札は戻らない。段のある筋は、段ごとに違うことが起きて、最後に閉じる
- **筋はいくつも並んでいる。** 一人の恋や借金から、町の組合の争い、公都の跡目争い、帝国と海の向こうの戦まで、大きさの違う筋が、互いにほとんど関係なく同時に動く
- **主人公の得意は一つだけ。** ほかのことは、町の人に頼む。頼めば借りができる
- **誓いは魔法。** 名を賭けた約束は糸になって人を結ぶ。破れば体に痕が浮く

## 遊び方（プレイヤー向け）
- 「ロシュモールを始めよう」「ロシュモールの続き」と言えば始まる
- はじめの回は、主人公を作る（出自を三つから選び、名前・年齢・譲れないことを決める）
- 週の過ごし方をざっと決めると、一週ずつ進む。誰かが主人公を巻き込んでくると止まって、場面になる
- 「今の状況は？」で数値、「4 週進める」「次の出来事まで」でまとめて進める
- 「今日はここまで」で記録して終わる
