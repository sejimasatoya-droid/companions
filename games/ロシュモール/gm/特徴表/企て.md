# 企ての表（1d10）

企ての型。人物の欲から、どの型で動くかを選ぶ（engine/data/scheme_types.json に段がある）

| 目 | 中身 |
|---|---|
| 1 | 手に入れる：欲しいものを、金か力か口で手に入れる |
| 2 | 守る：脅かされているものを守る。守るためなら、ほかを壊す |
| 3 | 取り戻す：奪われたものを取り返す |
| 4 | 仕返し：相手に、同じだけの痛みを返す |
| 5 | 隠す：秘密が露れないように、手を打ち続ける |
| 6 | 逃げる：何かから逃げる。町を出る、追っ手をまく |
| 7 | 証す：自分（か誰か）が正しかったと、人に示す |
| 8 | 結ぶ：誰かと添う、手を組む、縁を作る |
| 9 | のし上がる：今の頭を下ろして、自分が頭になる |
| 10 | 償う：昔の過ちを、自分なりのやり方で償う |
