# 層の表（1d6）

その人の悩みが、どの層にあるか。1d6：1〜3 個人、4〜5 町、6 公国か世界。ほとんどの人は、自分の暮らしの問題を生きている

| 目 | 中身 |
|---|---|
| 1 | 個人：家族・恋・金・体・仕事の悩み。町の大事とは関係がない |
| 2 | 個人：家族・恋・金・体・仕事の悩み。町の大事とは関係がない |
| 3 | 個人：昔のことを抱えている。今の暮らしを守りたい |
| 4 | 町：組合・教会・参事会・浜のどこかの争いの中にいる |
| 5 | 町：町の昔のこと（大火・沈んだ村・前の守り手）を知っている |
| 6 | 公国か世界：公都の跡目争い、帝国、アルモール、遠い戦。知らせと使いでつながる |
