# 巻き込み方の表（1d24）

この人が、主人公をどう自分の事情に引きこむか。企ての段の［巻き込み］の好みになる

| 目 | 中身 |
|---|---|
| 1 | 頼み：まっすぐ頭を下げて頼む。断られると、二度は頼まない |
| 2 | 頼み：頼みごとを、取り引きの形にして持ってくる（「あんたにも得がある」） |
| 3 | 頼み：頼んだつもりはないのに、気づくと主人公がやることになっている |
| 4 | 板挟み：対立している相手と同じ日に、同じことを頼みに来る |
| 5 | 板挟み：主人公の味方と、主人公の利益のどちらかを選ばせる |
| 6 | 巻き添え：自分の企ての余波で、主人公の町や家の者が困る |
| 7 | 巻き添え：主人公の名を勝手に使う（「守り手さまもご承知だ」） |
| 8 | 秘密：主人公だけに秘密を打ち明け、黙っていることを求める |
| 9 | 秘密：主人公がたまたま秘密を見てしまう |
| 10 | 取り立て：前の恩・貸しを、いちばん困る時に取り立てに来る |
| 11 | 取り立て：前の守り手への貸しを、主人公に払えと言ってくる |
| 12 | 濡れ衣：自分の罪を、主人公（か主人公の身内）に着せようとする |
| 13 | 濡れ衣：主人公に着せられた濡れ衣を、晴らす代わりに条件を出す |
| 14 | 誘い：企ての仲間に誘う。分け前と危険を、正直に言う |
| 15 | 誘い：企ての仲間に誘う。危険のほうは言わない |
| 16 | 打ち明け：弱っているところを見せて、助けを求めずに去る（主人公が追うかどうか） |
| 17 | 打ち明け：酒の席で、うっかり本音を漏らす |
| 18 | 対決：主人公のやり方に、正面から異を唱える。人前で |
| 19 | 対決：主人公を試す（勝負、問い、贈り物） |
| 20 | 誓い：主人公に、名を賭けた誓いを求める |
| 21 | 誓い：主人公に、自分の名を賭けて誓ってみせる。重すぎる誓いを |
| 22 | 逃げ込み：追われて、主人公の城に転がりこんでくる |
| 23 | 置き土産：姿を消し、主人公に何か（手紙・子・借り・鍵）を残していく |
| 24 | 噂：主人公についての噂を流し、主人公が来るのを待つ |
