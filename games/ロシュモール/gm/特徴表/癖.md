# 癖の表（1d40）

目に見える、耳に聞こえる小さなこと。場面に出るたびに一つ見せると、人物が立つ

| 目 | 中身 |
|---|---|
| 1 | 考えるとき、指で塩をつまんで舐める |
| 2 | 話すとき、相手の目ではなく口元を見る |
| 3 | 嘘をつくとき、袖を直す |
| 4 | 笑うとき、口を手で隠す |
| 5 | 何か食べていないと落ち着かない |
| 6 | 人の名を、必ず二度くり返して覚える |
| 7 | 歩くとき、敷石の継ぎ目を踏まない |
| 8 | 古い歌をいつも鼻で歌っている。いつも同じ節 |
| 9 | 怒ると、丁寧な言葉になる |
| 10 | 返事の前に、必ず一拍おく |
| 11 | 指の関節を鳴らす |
| 12 | 人の服のほつれが気になって直したがる |
| 13 | 窓のある部屋では、必ず窓の近くに立つ |
| 14 | 扉に背を向けて座らない |
| 15 | 話の途中で急に黙り、海の方を見る |
| 16 | 数を数えるくせ（階段、鐘の数、相手のまばたき） |
| 17 | 金貨を指の上で転がす |
| 18 | 人と別れるとき、必ず「灯の守りを」と言う |
| 19 | 笑い声が大きすぎて、隣の部屋まで聞こえる |
| 20 | 人の言葉を最後の一語だけくり返す |
| 21 | いつも少し、潮と煙の匂いがする |
| 22 | 左手だけ手袋をしている |
| 23 | 眠そうな目をしているが、何も見逃さない |
| 24 | 褒め言葉を受け流して、必ず話をそらす |
| 25 | 怖いとき、小声で数を数える |
| 26 | 物を必ず左右そろえて置く |
| 27 | 相手の名を呼ばず、あだ名で呼ぶ |
| 28 | 話の締めに、必ずことわざを言う。たまに間違っている |
| 29 | 誓いを口にしそうになると、言いなおす |
| 30 | 歩くのがやけに速い |
| 31 | 食べ方がやけにきれい |
| 32 | 寒くても窓を開ける |
| 33 | 犬にはやたらと好かれ、猫には嫌われる（逆でもよい） |
| 34 | 大事な話は、必ず外を歩きながらする |
| 35 | 小さな帳面に何でも書きつける |
| 36 | 口笛が下手で、鳴らない |
| 37 | 人の話を聞くとき、目を閉じる |
| 38 | 酒を飲むと、昔の言葉（田舎の訛り）に戻る |
| 39 | 鐘が鳴るたびに、立ち止まって数える |
| 40 | 贈り物を受け取ると、その場で開けずにはいられない |
