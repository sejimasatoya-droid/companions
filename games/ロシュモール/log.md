# 記録

- 公国暦311年 種月（3月・春）第1週：公都の塩商の家の子である主人公は、家の借金のかたに、公から守り手の役を買い取った。父は言った『三年で元を取れ』。町は、主人公を金で役を買った者として見ている
- 公国暦311年 種月（3月・春）第1週：レンダ（14）が守り手として丘の城に入った。門で家令オーギュストが迎えた
- 公国暦311年 種月（3月・春）第1週：オーギュストに城を案内された。台所で、前の守り手ジェルヴェのことを尋ねた
- 公国暦311年 種月（3月・春）第1週：オーギュストに前の守り手の借りのまとめを頼み、翌朝、書庫の帳面と照らし合わせた（知 成功）。両替屋への支払いの記録がなく、銀器の目録に新しい線があるのに気づいた
- 公国暦311年 種月（3月・春）第1週：帳面の食い違いをオーギュストに尋ねた。オーギュストは蓄えから払った、銀器は修繕に出したと答えた（袖を直した）。レンダは問い詰めずに引き、借りを返す順を相談した
- 公国暦311年 種月（3月・春）第1週：前の守り手の借りのうち、網干し浜の寡婦七軒への麦（二袋ずつ、蔵から 1 週分）と、鍛冶屋ゴーティエへの銀 12 をすぐ返すと決めた。町に、新しい守り手が前の主の借りを返すと知らせる（町の声 +3）
- 公国暦311年 種月（3月・春）第1週：レンダが鍛冶屋ゴーティエに、前の守り手の借り銀 12 を自分で届けた。ゴーティエは受け取りを書いた
- 公国暦311年 種月（3月・春）第1週：ゴーティエに城の槍三十本の手入れを頼んだ（錆びた十五本の打ち直し 銀 10、残り十五本の研ぎ 銀 2。二週間。払いは仕上がって兵が確かめた日）
- 公国暦311年 種月（3月・春）第1週：網干し浜で寡婦たちに麦が届いた。ジャンヌから、去年の冬に誰からともなく届いた麦の袋（塩結び、塩袋）を借りた。城で一人で縫い目の塩を舐めると、北の一番塩田（ヴェイユ家）の、去年の長日月の塩だった
- 公国暦311年 種月（3月・春）第1週：塔の屋上で、霧よけの浜塩の線（半年前、葡萄酒と蝋が混じる）を見つけた。線は新しい漆喰の胸壁の前でだけ途切れていた。胸壁を調べたが、どう崩れたかまではわからなかった（技 失敗）
- 公国暦311年 種月（3月・春）第1週：オーギュストから、塩の線は網干し浜の霧よけのしきたりで、前の守り手が終わりのころ浜塩を取り寄せていたと聞いた。霧が来る前に塔を下りた
- 公国暦311年 種月（3月・春）第1週：《門番の恋 1/3・個人》城の若い門番ジルが、夜番のたびにぼんやりしている。錨亭の下働きの娘に恋をしているらしい
- 公国暦311年 種月（3月・春）第1週：〔オーギュスト〕古い礼服を、虫干ししていた。前の守り手のものだ
- 公国暦311年 種月（3月・春）第2週：〔暦〕種まき。守り手が城の畑に最初の種をまく古いしきたりがある
- 公国暦311年 種月（3月・春）第2週：《出来事・町》染め場から流れた青い水で、川下の牛が腹をこわした。牛飼いが参事会に怒鳴りこんだ
- 公国暦311年 種月（3月・春）第2週：〔アデル〕霧の朝、浜に一人で座り、何かを聞いているようだった
- 公国暦311年 種月（3月・春）第2週：計画「槍の手入れ（ゴーティエ）」が仕上がった
- 公国暦311年 種月（3月・春）第3週：ゴーティエの槍三十本が仕上がり、ロランが一本ずつ確かめた。銀 12 を払った（治安 +2）
- 公国暦311年 種月（3月・春）第3週：力「味」を使った（0 点、人前で）
- 公国暦311年 種月（3月・春）第3週：染め場の水の訴え：エミールが、裏の小桶で霧の岬の苔と銅の緑青を使った新しい青を試し、その水を川へ流していたと認めた。レンダが布と浅瀬の水を舐めて確かめた（人前だが、噂にはならなかった）
- 公国暦311年 種月（3月・春）第3週：染め場の裁き：①やり方を変えるときは川下に知らせる ②新しい染めは川下に害のない場所で試す ③賠償 銀 8 はエミール個人が負い、城が立て替えてバルテルミーに払う。エミールは月ごとに利子をつけて返し、滞れば残りを組合に請求する
- 公国暦311年 種月（3月・春）第3週：エミールへの貸し 銀 8：月に銀 2 ずつ、利子は月 3 分。少しでも遅れたら、残りを織り手の組合への貸しに替える
- 公国暦311年 種月（3月・春）第3週：《門番の恋 2/3・個人》ジルが夜番の最中に持ち場を離れて、娘に会いに行っていた。そのあいだに厩の馬が一頭逃げた
- 公国暦311年 種月（3月・春）第3週：〔トマ〕霧が出そうな夕方、戸口に塩を撒く年寄りを手伝って回っていた
