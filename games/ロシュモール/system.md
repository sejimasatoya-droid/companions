# システム（v0.3）

> 週単位で進む、町の守り手のシミュレーション ＋ 人物の TRPG。
> 世界は主人公と関係なく**毎週**動く。人物は**自分の欲で企てを進め**、その企てに主人公を巻き込んでくる。
> 数値・乱数・時間・山札は**エンジン**（`engine/rm.py`）が扱う。GM（Claude）は物語・人物・判断を担う。

---

## 0. ハーゼル領から直したところ
| ハーゼル領で起きたこと | ロシュモールでの直し |
|---|---|
| 勢力の手の数が少なく、文が決まっていて、同じ文が年に何度も出た（「鉄の輸出を絞っている」が数百回） | 出来事は**山札**。引いた札は戻らない。決まった文の繰り返しは出ない（§6） |
| 出来事が出ても、話が先に進まない | 出来事は段のある**筋**。段ごとに違うことが起き、最後の段で閉じる（§6） |
| クロックが下がって上がると、同じ節目の文がまた出た | 節目は**一周に一度**。下がって戻ったときは「再燃」として、別の形で描く（§6） |
| 片づいた問題がまた出てきた | 問題に**タグ**をつけ、片づいたら `thread tag` で閉じる。そのタグの札は二度と山に入らない（§6） |
| 人物が、主人公の働きかけを待っていた | 人物は**企て**を持ち、自分で進める。段が進むたびに主人公を**巻き込む**（§5） |
| 人物がだんだん似てきた、魅力が薄い | 人物シートに**ギャップ・見せ場・変わり方・本当に要るもの**を書き、**日常の一手**で暮らしを見せる（§7） |
| 人物を作る手がかりがなかった | この世界用の**特徴表**（18 表）で引く（§9） |
| 一つの謎に、町の全員が結びついていく | 筋を**個人・町・公国・世界**の層に分け、互いに関係のない筋をいくつも並べる。謎に深く関わるのは三人まで（§6.1） |
| 主人公が何でもできるようになり、発明で世界を変えていった | 能力値は凡人並み。主人公の強さは、ランダムに決まる**一字の力（しるし）**だけ。技術革新・前世の知識の要素は入れない（§3、§12） |

## 1. 時間の進み方
- **1 週単位**。1 か月 ＝ 4 週、1 年 ＝ 48 週。1 週は 6 日（第 7 日は灯の日で休み）
- プレイヤーは**週の過ごし方**をざっと決める（`routine`）。エンジンが 1 週ずつ進め、**巻き込み・判断の要る出来事で止まる**
- 止まったら、GM が場面を描き、人物を演じ、判定をし、プレイヤーが決める。決まったら、また進める
- 「4 週進める」「次の出来事まで」とまとめて進めてもよい
- **選択肢を示すとき、GM のおすすめは書かない**。プレイヤーが「ヒント」と言ったときだけ示す

### 1 週のなかで起こること（エンジンの順）
1. 暦の行事
2. 収支（週の入りと出、月末の帳面、冬の蔵、刈り入れ）
3. 情勢クロック
4. **人物の企て**（語り手が、一週に多くて一人を進める）
5. **出来事**（開いている筋の次の段、または山札から一枚）
6. **日常の一手**（誰か一人の暮らし。止まらない）
7. **町のざわめき**（月末。止まらない）
8. 計画の進み、主人公の伸びと疲れ

### 主人公の週の過ごし方
| 過ごし方 | 伸びる能力 | 中身 |
|---|---|---|
| 稽古／馬と狩り | 体 | 城の兵と、森で |
| 手仕事／弩 | 技 | 鍛冶場・舟・染め場。弩兵と |
| 書庫／帳面 | 知 | 前の守り手たちの記録。町と城の銀 |
| 人と話す／町を歩く／裁き | 話 | 錨亭・市・参事会。城の広間で訴えを聞く |
| 祈り／誓約師の塔 | 心 | 灯台と礼拝室。誓い糸の見方（ベネディクトの許しが要る） |
| 休む | ― | 疲れを取る |

- 裁きを週に 1 日もしないと、訴えがたまる（GM が治安を少しずつ下げる）
- 場面の中でする特別な行動（塔に登る、錨亭で張りこむ）は、過ごし方とは別に場面として扱う

## 2. 町と城
`world/ロシュモール.md` にくわしく書いてある。

| 値 | 意味 |
|---|---|
| 金庫（銀） | 守り手の金。週の入り（季節で変わる）− 週の出 9。何もしないと年に −20 ほど |
| 蔵 | 城の麦の蓄え（週分）。冬に減り、刈月の終わりに入る |
| 治安・町の声・公の覚え | 0〜100。§4 の判定の修正にもなる（GM 判断で ±1〜2） |
| 霧の満ち（クロック 8） | 秋と冬に進む。満ちると霧の者が町に入る |
| 後継争い（クロック 8） | 公都の跡目争い。満ちると老公が死ぬ |
| 公都の目・霧の取り立て（隠しクロック） | GM が場面の結果で進める。`gm/秘密.md` |

- 計画（堤を直す、秤を作り直す、道を直す）は `project add "<名>" <週> <銀>`。仕上がったら GM が効き目を `add` で入れる

## 3. 判定
- **2d6 ＋ 能力の修正 ＋ 状況の修正 ≧ 目標**
- 能力の修正：10〜11 で ±0、12〜13 で +1、14〜15 で +2、8〜9 で −1、6〜7 で −2
- 目標の目安：ふつう 8、難しい 10、とても難しい 12
- 目標より 1〜2 足りないときは**条件つき**（できるが、代わりに何かを払う。相手が条件を出す）
- 2 は大失敗、12 は大成功
- `python3 engine/rm.py check 話 10 +1`（疲れ 3 以上なら −2 が自動で入る）
- 主人公の能力：**体**（力・武芸）・**技**（手先・弩・舟）・**知**（書・帳面・覚え）・**話**（説得・裁き・駆け引き）・**心**（祈り・誓い糸・霧に負けない気持ち）

### 一字の力（しるし）
- 主人公の強さは、能力値ではなく、**しるし**（一字の力）にある。能力値は凡人並み（9〜10 から始まり、**13 で止まる**）
- はじめの回に、`new <出自>` で**ランダムに一字**が決まる（66 字の候補は `engine/data/kanji.json`）。表には、その字の「できること」「伸びた先」「代価」「知られると」の芽がある
- GM とプレイヤーで、字から**力の形**を決める。表の芽は叩き台で、読みかえてよい。決めたら `power set 名 "<力の名>"`、`power set できること "<…>"`、`power set 決めごと "<使えないこと・限り>"`
- **一つの物事にしか効かない**。「塩」なら塩と塩にまつわることだけ。字の外のことは、人に頼む

| 値 | 中身 |
|---|---|
| 段 1〜5 | 熟れ具合。上がるたびに、できることを一つ広げる（「伸びた先」を手がかりに GM が書き直す）。段 5 まで、毎週使っておよそ 1 年半 |
| 力の点 | 上限は 4＋2×段。毎週、上限の半分＋休んだ日数だけ戻る |
| 怪しさ | 人前で使うたびに +1。月末に −1 |
| 力の噂（クロック 6） | 気づかれると進む。2 で町の噂、4 でその力を欲しがる者・恐れる者が来る、6 で公都に届く |

- 使い方：`power use <点> [人前]`。小さな使い方 1、ふつう 2〜3、大きな使い方 4 以上（段 3 から）。代価が毎回出る。GM は、代価を場面で描く
- 人前で使うか、4 点以上使うと、**気づかれるか**を振る（2d6＋怪しさ＋人前 3＋点の半分 ≧ 13 で噂）
- 力は強いが、**一字ぶんしかない**。力で町の問題が全部片づくことはない。力で知ったこと・できたことを、人に信じさせ、人を動かすのは、主人公の言葉と借りである
- しるしの由来を、謎の軸（霧と最初の誓い）に結びつけない

### 技術革新は入れない
- 前世の知識や、新しい発明で町を変える要素は、このゲームには無い
- 計画（`project`）は、堤・秤・道・屋根の直しなど、この時代にあるものだけ
- 新しいもの（エミールの深い青など）を作るのは、人物のほう。主人公は後ろ盾になれるだけ

### 説得
- 人は、正しいことでは動かない。**相手の欲に触れる**か、**借り**か、**誓い**で動く
- 頼みの判定の修正：相手の欲に触れる +2／借りを返す・作る +1／誓いを差し出す +2（破れば痕）／相手の譲れないことに触れる −3／好意・信頼がマイナス −1
- 判定の前に、プレイヤーには**何を差し出すか**を言ってもらう

## 4. 誓い
`world/世界.md` §2。
- 主人公が名を賭けて誓えば、相手は強く動く（説得 +2）。結んだ誓いは `state.md` の「誓い」に書く
- 誓いを果たせばほどける。破れば**誓い痕**（判定 −1、重なる。人に見える。町の声 −3）
- 人物も誓う。人物が誓いを破るのは、その人の芯が折れるときだけ
- 主人公の肩には、はじめから**古い糸**が一本ついている（GM：`gm/秘密.md`）

## 5. 人物の企てと巻き込み（このゲームの芯）

人物は主人公を待たない。**自分の欲で、自分の企てを進める**。主人公は、その企てに巻き込まれる。

### 企て
- 名のある人物は、**企てを一つ**持つ。企ては 4 段。段が進むたびに、主人公を巻き込む**フック**が出る
- 企ての中身は `engine/data/schemes.json`（はじめの 11 人ぶん）。`python3 engine/rm.py scheme <人物> show` で見る
- 企ては主人公と関係なく進む。**語り手**は、一週に多くて一人の企てを進める（`economy.企ての率`、既定 0.35。同じ人は 3〜4 週あける）
- 4 段を越えると**成る**。主人公が止めれば**潰れる**（`scheme <人物> fail`）。主人公が手を貸して決着がつけば `scheme <人物> done`
- 主人公が手を貸すと `scheme <人物> help`（進みが速くなる）、邪魔すると `hinder`（遅くなる）

### 巻き込みの種類（企ての段の［　］）
| 巻き込み | 中身 |
|---|---|
| 頼み | 人物が頭を下げる。受ける・断る・条件をつける |
| 誘い | 企ての仲間に誘われる。分け前と危険 |
| 板挟み | 二人の企てが同じものを取り合う。片方につけば、もう片方の好意が下がる |
| 巻き添え | 企ての余波が、町や城の者に来る |
| 秘密 | 主人公が秘密を知る。黙るか、言うか、使うか |
| 取り立て | 前の借り（主人公か前の守り手の）を返せと来る |
| 濡れ衣 | 誰かに疑いがかかる。裁くのは主人公 |
| 打ち明け | 人物が弱みを見せる。追うか、そっとしておくか |
| 対決 | 正面から異を唱える、試す、迫る |
| 誓い | 名を賭けた誓いを求められる（立ててみせられる） |
| 逃げ込み | 人物が城に転がりこむ |
| 置き土産 | 人物が姿を消し、何かを残す。次の筋になる |

- くわしい扱いは `engine/data/hooks.json`。エンジンが止まったとき、注記に出る
- **ぶつかり**：企ての段に「ぶつかる」ものが書いてあり、別の人の企ても十二週のうちに同じものに手をかけていれば、エンジンが**板挟み**を出す（例：鐘楼の鍵をめぐるマルグリットとエミール、大鐘をめぐるランベールとセレスト）

### 企てが終わったら
1. 結果を人物シートの「いま」に書く。**成っても潰れても、人は変わる**（シートの「変わり方」の段を進めるか、戻す）
2. 次の企てを決める。シートの「欲」と、今の結果から。`python3 engine/trait.py 企て` で型を引いてもよい
3. `scheme <人物> new <型> "<名>" "<狙い>"` で作る。段の文は型のままなので、**その人の言葉と町の具体で書き直す**（`save/state.json` の `npcs.<人物>.企て.def.段`）
- 企ては、ほかの人物の企てと**ぶつかるように**作る。ぶつかる相手のない企ては、物語にならない

### 関係
- **好意**（−5〜+5）：好きか嫌いか　**信頼**（−5〜+5）：任せられるか　**借り**（＋は主人公が負っている）
- 態度は、場面の結果でしか変わらない。「話していたら仲良くなった」を自動で起こさない
- 人物は主人公のしたことを**覚えている**。印象に残ることがあったら `memory <人物> "<文>"`。エンジンが、その人の企てが動くときに注記で出すので、場面で持ち出す（「あの冬、あんたは断った」）

## 6. 出来事：山札・筋・日常・ざわめき（繰り返さないしくみ）

### 山札
- 季節の初め（種月・長日月・霧月・長夜月の第 1 週）に、エンジンがその季節の**山札を切る**
- 山札に入るのは、**筋の始まり**（`data/threads.json`）と**一度きりの札**（`data/cards.json`）。条件と季節が合うものだけ
- 週に一度、25% ほどで一枚めくる。**めくった札は戻らない**。同じ札は二度と出ない
- 山が尽きたら、その季節は静か。GM は、今の町に合う札を `data/cards.json` に足してよい（そのときも、前に出た札と同じ形にしない）

### 筋（何段かで進む出来事）
- 筋は 3 段。始まりの札がめくられると**開き**、そのあとは自分の間合いで次の段へ進む（一週に進む筋は一つ）
- 開いている筋は**三つまで**。それより多いと、新しい筋は始まらない
- 段に「種」（seed）があれば、そこが**判断の場面**。止まる。種のない段は、流れとして描く
- 段に「関わる人」が書いてあれば、**その人の企て・欲と結びつけて**描く（例：堤の筋で、マルグリットの見せ場を起こす）
- 決着がついたら `thread close <id>`。最後の段まで来れば、エンジンが閉じる

### 蒸し返さない
- **片づいた問題は、同じ形では蒸し返さない**。筋と札には**タグ**がある（堤・偽金・盗賊…）。プレイヤーが根っこから片づけたら `thread tag <タグ>` で閉じる。そのタグの札は、山にも入らない
- 新しい問題を起こすなら、**前とは別のもと**から起こし、前もって兆しを見せる

### クロックの節目
- 節目は**一周に一度**だけ鳴る
- クロックが下がって、またその節目に戻ったら、エンジンは「再び戻った」とだけ出す。**GM は、前と違うきっかけ・違う人物から、再燃として描く**。同じ文を繰り返さない

### 日常の一手
- 毎週、誰か一人が、**主人公と関係なく暮らしの一手**を打つ（「塩田の端で塩を舐めていた」「子どもの木剣にわざと負けていた」）。止まらない
- 人物が生きて見えるためのもの。ギャップや癖を見せる
- 一度出た一手は消える。人物ごとに尽きたら、エンジンが言うので、**いまのその人らしい一手**を `daily add` で 3〜5 つ足す（前と同じ形にしない。企ての進みや、主人公との出来事を映す）

### 6.1 筋の層（一本の軸に全員を絡めない）
- 筋と札には**層**がある。エンジンの出力の《　》の中に出る

| 層 | 中身 | 例 | 2 年に出るおよその数 |
|---|---|---|---|
| 個人 | 一人か一家の暮らしの悩み。町の大事とは関係がない | 門番の恋、台所の娘の縁談、老兵の息子、二つの粉屋 | 9 |
| 町 | 町の中の争い・災い・昔のこと | 塩田の堤、組合の争い、冬の咳、大火、霧と最初の誓い | 11 |
| 公国 | 公都の跡目争い、交易、隣の守り | 公女の巡幸、南の安い塩、難破船 | 3 |
| 世界 | 帝国・アルモール・遠い国。知らせと遠い人々で動く | 帝国の監察官、沖の私掠船、東の難民、皇帝の死 | 3 |

- 人物の企ても、多くは**個人の層**（娘の縁談、賭けの借り、南へ出た母、土地と名）
- **町の謎（霧と最初の誓い）は、町の層の筋の一つにすぎない**。深く関わるのは、ベネディクト・オーギュスト・トマの三人だけ
- GM は、ほかの人物や筋を謎に結びつけたくなっても、**結ばない**。新しい人物は特徴表の「謎の軸」で 1d6 を振り、1 のときだけ浅く関わらせる
- 謎が解けても、ほかの筋は続く。別々の筋が、たまたま同じ週に重なるのはよい（それが町の暮らし）。だが、裏で一つにつながっていた、とはしない
- 筋の地図は `gm/秘密.md` のはじめ。人物ごとの層は `npcs/index.md`

### 町のざわめき
- 月末に、町の小さな人々の噂が二つ出る（人 × 場所 × こと の組み合わせ。それぞれ使い切るまで繰り返さない）
- 背景である。主人公が拾えば場面にしてよく、拾わなければ流れる

## 7. 人物の魅力（GM の決まり）

人物の魅力は、**「この人には、この人の人生がある」と感じられること**から来る。そのための決まり。

1. **ギャップを一度は見せる**。シートの「ギャップ」は、その人の芯。冷たい人の温かい一瞬、強い人の弱い一瞬。最初の二、三回の登場で、どこか一回にちらりと見せる。全部は見せない
2. **見せ場を一つ、取っておく**。シートの「見せ場」は、まだ起きていないこと。筋や企ての山場で、主人公の目の前で一度だけ起こす。起きたら「いま」に書き、新しい見せ場を決める
3. **欲しいものと、本当に要るものは違う**。人物は「欲」を追う。だが、心を動かされるのは「本当に要るもの」に触れられたとき。主人公がそこに触れたら、好意か信頼が大きく動いてよい（±2）
4. **癖と持ち物で場面に立たせる**。登場のたびに、癖か持ち物を一つ描く。台詞だけで人物を出さない
5. **人物には、人物の得意がある**。主人公より上手なことを、一人一つ以上持つ（帳簿・舟・剣・噂・祈り・誓い糸）。主人公にできないことを、その人がやってみせる場面を作る
6. **人物は、主人公に反対する**。主人公が正しくても。理由は、その人の欲と傷から出す。主人公の顔色をうかがって折れない
7. **人物は、主人公を覚えている**。前の場面で主人公がしたこと・言ったことを、後で持ち出す（`memory`）。よかったことも、悪かったことも
8. **人物どうしの仲を見せる**。主人公のいないところで、人物は喧嘩し、助け合い、好き合っている。シートの「もつれ」を、日常の一手や筋の中で見せる
9. **ユーモア**。重い人物にも、笑える一面がある（ベネディクトの猫、ルーセルの敬語、オーギュストの長い作法）。深刻な場面の前後に、ひとつ置く
10. **変わる**。人物は、主人公との出来事と企ての成否で変わる。シートの「変わり方」は三段（閉じている → 揺れる → 変わる／頑なになる）。条件を満たしたら次の段へ。**変わらない人物は、だんだん飾りになる**
11. **人物は、主人公を好きにならなくていい**。全員が主人公を慕う世界は、魅力がない。嫌う人・無関心な人・利用する人がいて、だからこそ味方が光る

---

## 8. 人物の演じ分け（似通い防止）
1. **演じる前にシートを読む**。とくに「声の指紋」「譲れないこと」「主人公の利益に反してでもすること」「主人公への印象」
2. **声の指紋を守る**：一人称・呼び方・文の長さ・口癖・絶対に言わないこと。迷ったら例文を見る。`npcs/index.md` の声の早見表で、隣の人物と違うか確かめる
3. **全員共通の口ぐせを禁止**：「なるほど」「さすがですね」「素晴らしい」「一緒に頑張りましょう」を誰にも言わせない。最後に励ましで締めない
4. **知識の範囲を守る**：その人が知らないことは知らない。主人公について知らないことで、主人公を評価させない。現代の言葉と考え方を使わない
5. **同じ場面に二人いれば、意見は違う**のが普通（`npcs/index.md` の対比表）
6. **悪意も善意も、理由から出る**。意味のない悪役にしない

## 9. 特徴表
- 表は `gm/特徴表/`（層・謎の軸・性格・欲・傷・ギャップ・癖・持ち物・好き・嫌い・秘密・話し方・巻き込み方・最初の態度・見せ場・もつれ・突飛・企て の 18 表）。もとは `engine/trait.py` の中
- `python3 engine/trait.py`：ふつうの人物（名のある脇役）。1d10 で 1 なら突飛
- `python3 engine/trait.py 特別`：物語の要。欲・ギャップ・秘密・見せ場が二つずつ、突飛を必ず一つ。**二つの欲はぶつかり合うように読む**
- `python3 engine/trait.py 端役`：一場面だけの人。性格・癖・欲
- `python3 engine/trait.py 欲 2` のように、表を一つだけ引くこともできる

### 新しい人物の作り方
1. 特徴表を引く。まず層と謎の軸（ほとんどは個人の層で、謎に関わらない）。合わないものは一つまで引き直してよい
2. **理由をつける**。それぞれ「なぜこの人がこれを持っているのか」を一行で。町の具体（場所・人・霧・誓い・塩）につなぐ。矛盾は捨てずに、魅力の芯にする
3. **もつれ**で、すでにいる人物の誰か一人とつなぐ
4. `npcs/_template.md` からシートを作り、`npcs/index.md` の対比表と声の早見表に足す（似た人物でないか確かめる）
5. 企てを作る（§5）。**ほかの誰かの企てとぶつかるように**
6. 日常の一手を 3〜5 つ `daily add` で足す

## 12. 主人公の作り方（はじめの回）
1. **出自**を選ぶ（`engine/data/origins.json`）
   - **跡取り**：三十年前に町を追われたルヴェル家の跡取り。年寄りは祖父を覚えている（町の声 +、公の覚え −、心 +1）
   - **代官**：公都から送られたよそ者。任じ状はあるが、町に知る人がいない（公の覚え +、町の声 −、知 +1）
   - **塩商の子**：家の借金のかたに、守り手の役を買い取った（銀 +40、町の声 −、話 +1）
2. 名前・年齢・見た目・性別を決める
3. **譲れないこと**を一つ（主人公の芯。人物たちは、ここを試してくる）
4. `python3 engine/rm.py new <出自>` で始める。**しるしの字がランダムに決まる**
5. 字から、力の形を一緒に決める（§3「一字の力」）。しるしが体のどこに、どんな形で浮かんでいるか、いつ浮かんだか、誰が知っているか
6. `set hero.名 …`、`power set …`。`state.md` に書く
6. 最初の場面：丘の城に入る日。オーギュストが門で待っている
