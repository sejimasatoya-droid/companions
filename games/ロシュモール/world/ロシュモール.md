# ロシュモール ― 塩と霧の港町

## あらまし
- 公国の西のはし、**ロシュ川の河口**の町。人口およそ 2400。周りの村を合わせて 3500
- 町を支えるのは**塩**（河口の塩田）・**毛織物**（町の中の織り場と染め場）・**漁**
- 町の真ん中に**鐘楼**がある。町の誓いの鐘が吊られていて、参事会の決めごとも商いの大きな取り決めも、この鐘の前で誓う
- 岬の先に**灯台**（七灯教会の聖所）。灯台の火は三百年絶えたことがない、ということになっている
- 丘の上に**守り手の城**（古い石の砦。広間・塔・中庭・厩・礼拝室）。主人公が住む

## 力の分かれ方
| 力 | 中身 | 主人公との関係 |
|---|---|---|
| 守り手（主人公） | 公に任じられて城と兵（槍兵 20・弩兵 10）と裁きと税の取り立てを預かる | ― |
| 市参事会 | 町の大商人と職人の長、12 人。町の中の決めごと・市・門の税 | 守り手と、権の境目でいつも揉める |
| 塩の組合 | 塩田の持ち主と塩商人。町でいちばん金がある。長はマルグリット | 参事会に 5 席 |
| 織り手の組合 | 毛織物の職人。数が多い。若手のエミールが率いる | 参事会に 4 席 |
| 漁師の講 | 漁師の寄り合い。参事会の席は無い | 霧の者と、いちばんつながっている |
| 七灯教会 | 灯台と、町の三つの教会と、施療院 | 公都の司教座が口を出してくる |
| 誓約師 | 町の誓いを見る老人。どこにも属さない | 町の誓いの鐘のことは、この人がいちばん知っている |

## 町の場所
| 場所 | 中身 |
|---|---|
| 鐘楼広場 | 市が立つ。参事会の館、両替屋、絞首台 |
| 沈まぬ錨亭 | 港の宿屋・酒場。女将イザボー。よそ者と噂が集まる |
| 塩田 | 河口の南に広がる。夏は白く光る。堤が崩れると海が入る |
| 染め場通り | 川沿い。水が青や赤に染まる。臭い |
| 網干し浜 | 漁師の家々。霧の夜には戸に塩を撒く |
| 灯台の岬 | 灯台と、施療院と、古い墓地 |
| 誓約師の塔 | 町の北の古い見張り塔。猫が多い |
| 守り手の城 | 丘の上。前の守り手が死んで半年、空いていた |
| 泥の道 | 公都へ続く街道。雨月は通れなくなる |

## 財政（守り手の側。エンジンの「町」）
- 週の入り：冬 6・春 8・夏 14・秋 9（塩と市の税、裁きの科料、城の土地の小作料）
- 週の出：9（兵 30 人の給金、役人、城の維持、公への上納の積み立て）
- 夏に稼いで、冬に減らす。何もしなければ、年でおよそ銀 −20。**放っておくと少しずつ痩せていく**
- 始めの金庫：銀 140。蔵（城の麦の蓄え）：12 週分

## 町の指標
| 指標 | 意味 |
|---|---|
| 治安 | 盗み・喧嘩・密輸の少なさ。低いと出来事が荒れる |
| 町の声 | 町の人が守り手をどう見ているか。低いと参事会が強気になる |
| 公の覚え | 公都が守り手をどう見ているか。低いと解任の噂が立つ |
| 霧の満ち（クロック） | 今年の霧の濃さ。満ちると霧の者が町に入ってくる |
