# ヴェルデン（冒険者の TRPG）

ロウェン王国の東の辺境、迷宮のそばの町ヴェルデン。瀬島の主人公は、冒険者ギルド「灯火亭」に木札で登録したばかりの駆け出し。掲示板の依頼を選び、町と野と迷宮を一歩ずつ歩いて進む。
王道のファンタジー。ただし世界は主人公を待たない。町でも国でも事件は勝手に進み、人は勝手に動き、ときどき主人公の知らないうちに死ぬ。

- 型：ソロ（はじめは一人。人を雇う・誘うことはできる）
- 判定：2d6 ＋ 能力 ＋ 技能
- 死にやすさ：重い（体力 0 で倒れ、生死判定。重傷は後に残る）
- 探索：マス目の地図（町・周辺・迷宮三層）。一度歩いた道はまとめて進める

## GM の約束（Claude 向け）

1. **NPC は `gm/NPCの動かし方.md` に従って動かす。** 会話の前に、その人物のシートの「動き方」と「台詞の例」と「帳面」を読む。場面の頭に仕掛け手番を振り、帳面の「次にどうする」を実行させる
2. **場面が終わるたびに、その場にいた人物の帳面に一行ずつ書く。** 思ったことには価値観の軸を、口に出したかどうかを、次にどうするかを必ず書く
3. **方針を決める場面では、仲間が先に意見を言う。** 強さは `dice.py opinion` で決める。主人公の案に、ただ乗らない
4. **世界は日ごとに進める。** 日が変わるたびに `world.py day` を振り、満ちた時計は主人公が見ていなくても起こす。主人公の耳に入ったことだけを伝える
5. **死は本当に起きる。** 敵は手加減しない。とどめも刺す。NPC の生還判定も甘くしない。運は乱数で決め、コマンドと出目を `gm/判断記録.md` に残す
6. **地図は道具で動かす。** 迷宮・野外の移動は `map.py move` か `goto`。歩数・時間・遭遇判定の頃合いは道具の出力どおりに数える。見えていないマスのことは語らない
7. **隠しごとを漏らさない。** gm/ の中身を、NPC の口を借りても、地の文でも明かさない。主人公が知る手段（調べる、話す、判定）を通ったものだけを伝える
8. **選択肢を並べない。** ヒントを頼まれたら、主人公が知っていることから問いで返す
9. **後から足さない。** 迷宮の宝・罠・住人は gm/地図/ に書いたものだけ。新しく足すときは、遊ぶ前に書く（遊んでいる最中に、都合のいいものを出さない）
10. **会話中のファイル報告は最小限。** 区切り（一日の終わり、迷宮から出たとき）にまとめて保存する

## 進め方

- 始め：README → ルール → 主人公 → 状態 → 最新のログ → 掲示板 → `gm/` のうち、いま関わる場所と人物のシート・時計（`python tools/world.py list`）・判断記録
- 道具は `games/ヴェルデン` で動かす：`python tools/dice.py`、`python tools/map.py`、`python tools/world.py`、`python tools/trait.py`
- 町の中は「〇〇へ行く」でよい。迷宮と野外は一歩ずつ。二度目からはまとめて
- 終わり：ログ・状態・人物・地図（`map.py public <名>`）・掲示板・gm/ の帳面と判断記録を更新し、コミットして push
