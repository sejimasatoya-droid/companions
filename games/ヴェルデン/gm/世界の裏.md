# 世界の裏（GM 専用）

主人公が知らないこと。世界の時計（gm/時計.json）は、ここに書いた筋で進む。主人公が関わらなければ、そのまま進む。関われば、曲がる。

## 一、鐘と楔（物語の芯）
- 三百年前、五人の英雄は霜の王を討ったが、魂は滅ぼせなかった。聖鐘修道院の大鐘**エルミナ**の音で魂を眠らせ、凍土の底（実はヴェルデンの地の底まで続く）に**封印の楔**を打った。鐘と楔は一つの仕掛け。**鐘が眠っていれば、王も眠る**
- 二百年前、修道院長マティアスは「眠らせるのではなく、砕く」ために鐘を打った。鐘は割れ、修道院は沈んだ。王は砕けなかった
- 弟の騎士ゲルハルトは、割れた鐘を守るために残った。鐘の呪い（眠りの力の裏返し）で、死ねないまま二百年
- 割れた鐘は、ときどき勝手に鳴る（時計 t2）。鳴るたびに楔が緩み、霜の王が少し目を開ける（時計 w1）

### 鐘をどうすると何が起きるか
| すること | 起きること |
|---|---|
| 欠片を持ち出す（一つごとに） | t2 が 1 進む。持ち出した者は、夜ごと寒い夢を見る |
| 三つの欠片を鐘にはめ戻す | 鐘のひびがふさがる。t2 が 0 に戻り、止まる。w1 の速さが 0 になる（ここで止まる） |
| 欠片を戻したうえで、鐘の舌を鐘に戻し、正しい祈り（B の写本・亡霊の言葉）で一度だけ打つ | 鐘が**眠りの音**を鳴らす。w1 が 3 戻り、止まる。ゲルハルトの呪いが解け、彼は灰になって休む（あるいは、旅支度をして地上へ出る。好感度と、兄の言葉を伝えたかどうかしだい） |
| 欠片をそろえずに、舌で鐘を打つ | 修道院長の過ちのくり返し。鐘は砕け、w1 が 4 進む。三層が崩れる（いる者は 敏捷 11 で逃げ出せなければ死ぬ） |
| 鐘を壊す・持ち去ろうとする | ゲルハルトが全力で止める。止められなければ、w1 が満ちる |
| 欠片を三つ、霜の王の使いに渡す | 白い使者が欠片を凍土へ持ち去る。w1 の速さが 3 になる |

## 二、霜の王（時計 w1）
- 北の凍土の底で目を覚ましつつある。まだ体はない。声と冷えと「眷属（影）」だけ
- 王は人と取引をする。楔に触れた者、夢を見た者に、「望みをかなえよう」と語りかける
- w1 が進むと：季節はずれの霜 → 北の部族が南へ追われる（赤い顎・鼻削ぎはこのせい）→ 白い使者が人の国へ来る → 楔が割れる → 北から冬そのものが攻めてくる
- **赤い顎も鼻削ぎも、悪ではなく、追われた者たち**。北の冷えから逃げてきた。人と話ができる者もいる（ズィグ、戦頭ウルガ）

## 三、学者アルバンの企み
- 王都の学者を名乗る。実は**北の奴隷商に囚われていた**過去があり、そのとき霜の王を祀る者たちの言葉を覚えた（魔物の言葉がわかる）
- 霜の王が目覚めるのは避けられない、と思いこんでいる。ならば、**王と話をつける人間**になれば、王国は滅びずにすむ、と。三つの欠片を手土産に、白い使者と取引するつもり
- 本人の中では正義。だが、金も欲しい（王都に借金がある）。英雄譚に名を残したい
- 時計 p_alban：主人公が欠片の依頼を受けなければ、銀の拍車を雇って集める

## 四、王位と国（時計 k1・k2）
- エドリク四世は長くない。第一王子カスパルは北征で手柄を立てて王位を固めたい。王妹イゾルデは教会と結び、カスパルを抑えたい
- k1 が進むと、北征の兵が募られる（ギルドに「兵役」の依頼。冒険者が町から減る）。教会の異端審問官が辺境に送られる（t6 が進む）
- ガルム帝国は、内乱の隙を狙っている。渡し場の村に密偵を置いている（k2）

## 五、町の闇
- **墓荒らし（t3）**：屍術師の弟子ヴェインが、二層のグールに死体を与え、屍術を学んでいる。ヴェインの師はもういない（ヴェインが殺した。ヴェインはそのことを覚えていない＝記憶をなくしている）
- **代官と盗賊（t5）**：代官オスヴィンは王都へ転任するための金を、山賊「ねじれ鎌」から受け取っている。見返りに、山賊の巣を見逃し、隊商の出発の日を流している。間を取り持つのは情報屋リース
- **神殿と薬屋**：神官長ベネディクトは、薬屋マーサの客を神殿の治療に取りこみたい。マーサの水薬に毒が入っているという噂を流そうとしている（時計 p_benedikt）
- **異端審問官（t6）**：王妹イゾルデの命で送られる審問官エーリヒ。魔術師、獣人、ノクティアの墓守、「魔物と話す者」を疑う。来れば町の空気が変わる

## 六、名のある冒険者たち
- **銀の拍車**（鉄の位、三人）：隊長レオナルト、魔術師フィオナ、斥候ジャック。二層の礼拝堂の「何か」を狙っている（レオナルトは鐘の欠片の噂を聞き、アルバンとも会った）。時計 p_ginnohakusha
- **三本角**（銅の位、四人→三人）：ハンナ、ガルド、ミロ、（トビアス）。四日前、一層でゴブリンに襲われ、トビアスを置いて逃げた。置いて逃げると決めたのはハンナ
