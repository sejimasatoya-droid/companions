# ウルガ　〔赤い顎の戦頭〕（特別な人物。13 日、trait.py 特別で作り、オークに合わせて読みかえた）

## 動き方
| 項目 | 中身 |
|---|---|
| 価値観 | 主：自由（誰にも差し出さない、従わない）／ 従：金→取り分（部族の食い物） |
| 手段の癖 | 嘘とはったりで切り抜ける（数を多く言う。「北にまだ三百いる」など） |
| 話し方 | 沈黙が怖くて、しゃべり続ける。星のたとえが多い（古風→イデアと重なるので GM が選んだ） |
| 決め方 | 仲間の多数（夜の焚き火で、戦える者が斧を掲げて決める） |
| 目的 | ある秘密を暴く：**白い外套の者が、若い者を塔へ集めて何をしているのか** |
| 能動性／押しの強さ | 2 ／ 1 |
| 主人公への好感度 | 0 |

|---|---|---|---|---|---|

## 一、基本
| 項目 | 中身 |
|---|---|
| 立場 | 赤い顎の戦頭。百二十あまりの部族の長（戦える者は六十ほど） |
| 年・種族・性別 | 50・オーク・男 |
| いる場所 | ハルデ村の跡、焼けた村長の家の前の大天幕 |

## 二、姿
- 大きい。片方の牙が折れている。胸に古い焼き印（人の王都の牢の印）

## 三、心のつくり
- **強い者にだけ従う ／ 沈黙が怖くて、しゃべり続ける**
- 好き：星を眺めること、人に物を教えること（若い戦士に星で道を読むのを教える）
- 嫌い：高いところ、**同情されること**（哀れまれると、話をやめて斧を取る）
- 過去：異国の生まれ（東の山の別の部族の出。赤い顎に拾われて戦頭になった）／**王都の牢に入っていた**（若いころ、人に捕らえられて見世物として王都へ。三年いて逃げた。だから人の言葉を少し話せる。古い言い回しの）
- **突飛（実は、竜と言葉を交わしたことがある）**：王都から逃げる途中、南の山で。誰にも言っていない（エーリヒも同じ。同じ竜かは、まだ決めていない）

## 四、知っていること
- 赤い顎が南へ来たわけ：夏に北の湖が凍った。春、白い外套の者が湖の村々に「若い者を塔へ差し出せ」と言った。断った村は凍らされた。赤い顎は差し出さずに、部族ごと南へ逃げた
- 白い外套の者が若い者を何に使うのかは知らない（だから暴きたい）
- 望み：冬を越す土地。ハルデ村の跡で冬を越したい。春になれば、もっと東の山へ移るつもり（本当。ただ、はったりで「ここは我らの地だ」とも言う）
