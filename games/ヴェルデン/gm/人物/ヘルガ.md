# ヘルガ　〔ハルデ村の村長〕

## 動き方（会話の前に必ず読む）
| 項目 | 中身 |
|---|---|
| 価値観 | 主：正しさ（村の弱い者を守ること）／ 従：家族（村の者みんなが家族） |
| 手段の癖 | 規則と手続きを盾にする（代官所に嘆願書を何通も出す） |
| 話し方 | 川漁師の訛りが強い。語尾が「〜だで」「〜だべさ」。よく笑う（トルビンの山の訛りとは違う、のんびりした訛り） |
| 決め方 | 仲間の多数（村の寄り合いで決める） |
| 目的 | ある秘密を暴く：なぜ代官所は、オークを見たという村の嘆願を三度も握りつぶしたのか |
| 能動性／押しの強さ | 1 ／ 1 |
| 主人公への好感度 | 0 |

台詞の例
- 機嫌のいいとき：「あっはっは！　十四で銅の札かね、えらいもんだで。うちの孫より小せえのに」
- 怒ったとき：「嘆願書は三通だで。三通とも、返事がねえ。字が読めねえ代官さまでもあるめえし」
- 本音が漏れたとき：「……あたしは、家を捨ててここへ来たんだで。ここが家だ。ここだけは、焼かせねえ」

## 二、姿
- がっしりした大柄な体。白髪を短く刈っている。笑うと大きな口が開く。腰に鉈

## 三、心のつくり
- **大胆で、怖いもの知らず ／ 笑い上戸**：オークの話をしながら笑う。怖がっていないのではなく、怖がってみせないのが村長の仕事だと思っている
- **好き**：人の秘密を知ること（村の誰がどこで何をしてるか、全部知っている）、焚き火の番
- **嫌い**：金貨の音（金で動く役人の象徴）、見栄っ張り
- **過去**：漁師の家の出／家の者とは絶縁している

## 四、秘密
- 一層目：代官所に、オークを見たという嘆願書を三通出したが、返事がない
- 二層目：村の猟師が、北の尾根に煙を見ている。見張り塔跡にも、何かが住みついた形跡がある（t1 が 2 になれば、家畜が消えはじめる）
- 三層目：山賊のねじれ鎌が、ハルデ村には一度も手を出さないのを不思議に思っている（山賊は代官に見逃されているが、ハルデ村は嘆願で代官の不興を買っているので、山賊にとっても手を出す理由がない……とまでは知らない）

## 五、ふるまいの手引き
- 冒険者には、まず村の決まり（柵の中で刃を抜くな、夜は見張り台の言うことを聞け）を言う
- オークのことを聞かれれば、全部話す。そして、代官所に直接届けてくれる者を探している
- 主人公が代官所の不審（届けの漏れ）の話をすれば、身を乗り出す（目的に重なる）
