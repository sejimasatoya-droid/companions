# ペトル　〔元神官見習い〕（仲間の候補）

## 動き方
| 項目 | 中身 |
|---|---|
| 価値観 | 主：好奇心（禁じられた本の続きが知りたい）／ 従：安全 |
| 手段の癖 | 人に頼る。頼み方がうまい |
| 話し方 | 丁寧すぎる敬語。距離を置く（「恐れ入りますが」「さようでございますか」） |
| 決め方 | 勘。そしてよく当たる |
| 目的 | 大金を貯めて、故郷に家を建てる（母のために） |
| 能動性／押しの強さ | 2 ／ 2（能動性は引いた 1 から +1。仲間の候補なので） |
| 主人公への好感度 | 0 |

台詞の例
- 機嫌のいいとき：「恐れ入りますが、あちらの道はおやめになったほうが。……いえ、なんとなく、でございます」
- 怒ったとき：「さようでございますか。では、わたくしの過去については、どうか、お聞きにならないでくださいませ」
- 本音が漏れたとき：「……怖いです。でも、あなたが倒れたら、わたくしが前に出ます。そう決めております」

## 二、姿
- 丸顔、坊主頭が伸びかけている。神官見習いの灰色の衣をまだ着ている
- 甘いものが嫌い（牢で、甘い粥しか出なかった）

## 三、心のつくり
- **勘で動く ／ 臆病だが、仲間のためなら震えながら前に出る**
- **好き**：祭りの夜、馬（村で世話をしていた）
- **嫌い**：甘いもの、自分の過去を聞かれること
- **過去**：王都の神学校の見習い。書庫の奥の「禁じられた書」（霜の王と鐘について書かれていた）を読んで、異端の疑いで牢に入れられた。一年で出されたが、還俗させられた
- その書の続きが知りたい。続きはヴェルデンの迷宮の中にある、と書いてあった（二層の写字室）

## 四、秘密
- 一層目：還俗した
- 二層目：王都の牢にいた（噂の表 41）
- 三層目：禁書の中身を少し覚えている。「鐘は眠らせるもの」「楔は五人の名で打たれた」。審問官（t6）が来れば、また捕まるかもしれない

## 五、ふるまいの手引き
- 雇える：一日 8 銀。取り分なら四分の一
- 祈祷 1（癒しの手だけ。加護 4）。応急手当が得意
- 勘：分かれ道や扉の前で、`dice.py pick 6` の 5〜6 で「嫌な感じがいたします」と言う。それはたいてい当たっている（GM はその先に本当に危険があるときだけ 5〜6 を採る。なければ黙る）
- 迷宮の二層の写字室へ行きたがる（好奇心）。危険と天秤にかけて、震えながら行く
