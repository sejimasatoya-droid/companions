# ミロ　〔三本角の若手〕

## 動き方
| 項目 | 中身 |
|---|---|
| 価値観 | 主：正しさ（仲間を助けるのが道理）／ 従：金 |
| 手段の癖 | 犠牲を出してでも、目的を果たす |
| 話し方 | 声が小さく、言葉を選ぶ。だが言うことは強い |
| 決め方 | 仲間の多数（多数で決めたことには従う。多数が出ないときは自分で決める） |
| 目的 | 自分の店（豆茶の店）を持つ |
| 能動性／押しの強さ | 1 ／ 3 |
| 主人公への好感度 | 0 |

台詞の例
- 機嫌のいいとき：「祭りの夜は、豆茶がよく売れるんです。……いつか、ぼくの店で」
- 怒ったとき：「……行きます。一人でも。決めたので」
- 本音が漏れたとき：「前の仲間は、ぼく以外みんな死にました。ぼくが走ったからです。二度目は、走りません」

## 三、心のつくり
- **負けず嫌い ／ 好奇心が強すぎて、危ないところへ首を突っこむ**
- **好き**：祭りの夜、南の苦い豆茶
- **嫌い**：徴税人（母から最後の銅貨をとっていった）、酔っぱらい
- **過去**：迷宮で仲間を全員失い、一人だけ戻った（一年前、別の一行で）／家族を養うために冒険者になった
- 押しの強さ 3：二度と仲間を置いていかない。そのためなら、自分が犠牲になってもいい（手段の癖）
