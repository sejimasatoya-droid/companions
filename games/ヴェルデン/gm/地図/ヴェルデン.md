# ヴェルデンの町（GM 専用の定義。瀬島の地図は 地図/ヴェルデン.md）

町の中は細かく歩かなくてよい。「灯火亭へ」「神殿へ」と言えば `goto` で動く。地図は、どこで何が起きたかを置くためのもの。

```meta
light 3
unit 分
check_every 0
open_disp /
events_known yes
public_note 1マス＝1分ほどの道のり。n は家並み（入り組んだ裏手）。
```

## 場所ごとの人と時刻
| 場所 | 誰がいる | いつ | 主人公が初めて行ったとき |
|---|---|---|---|
| A 灯火亭 | ネル（受付）、ブラム（ギルド長、奥の部屋）、オルド（酒場の亭主）、冒険者たち | 一日中。夜がいちばん人が多い | 掲示板（`掲示板.md`）。木札の登録は 5 銀 |
| B 神殿 | ベネディクト（神官長）、見習いたち | 朝・昼・夕 | 治療の値段表。寄進箱 |
| C 白い牝鹿 | 女将（名なし。必要なら作る） | 一日中 | 個室 5 銀 |
| D 代官所 | オスヴィン（代官）、書記、衛兵 | 朝・昼 | 鼠の尻尾の買い取り窓口 |
| E 黒い金床 | トルビン（ドワーフの鍛冶屋） | 朝〜夕 | 武具の売り買い（ルールの値段表）。修理 |
| F 薬屋 | マーサ（薬師） | 朝〜夕 | 癒しの水薬 40 銀、毒消し 25 銀、薬草 |
| G 墓地 | 墓守の老人ヨーゼフ | 一日中 | 地下納骨所の入口（鍵は墓守が持つ） |
| I 朝市の角 | 行商人、子どもたち | 朝 | 噂が拾える（交渉＋意志 8 で一つ、`町の出来事表.md` の噂から） |
| J 下水の口 | 誰も | ― | 鉄格子。代官所の許しがあれば開けてもらえる（壊せば罪） |
| K 錆びた錨 | リース（情報屋「片耳」）、貧民街の者 | 夕・夜 | よそ者には冷たい。情報は金で |
| L 詰所と牢 | 衛兵隊長（名なし） | 一日中 | 牢にいる者は、日によって変わる |
| M 古道具屋 | 店主（名なし） | 昼 | 迷宮の拾い物を買う（ギルドより安いが、何も聞かない） |
| O ディートマーの商館 | ディートマー（商人） | 朝・昼 | ハルデ村への荷運びの依頼主 |
| P 獣人の長屋 | シーラ、獣人の家族たち | 夕・夜 | よそ者を警戒する |
