# 九曜台（デスゲーム TRPG・第五作）

山頂の古い天文台に、九人が閉じ込められている。左の手首には外れない腕輪。腕輪には、一人一つずつ違う**星**と**勝ち条件**が出ている。三日が過ぎた夜明けに、条件を果たしていない者は眠らされる。

氷室までの反省から、**資源（炭・貝）を日をまたいで持ち越す形をやめた**。毎日の遊戯もない。一つの長いゲームの中で、九人の勝ち条件がぶつかり合う。勝ち条件がかみ合う相手もいれば、真っ向からぶつかる相手もいる。誰がどの星かを知ることが、そのまま生き死にに関わる。

- 人数：9人（瀬島＋NPC8人）
- 時間：3日 × 昼と夜
- 暴力：なし。罠と道具だけ（描写は控えめ）
- 着想：同人ゲーム『キラークイーン』の「一人一枚、違う勝ち条件」という仕組み。名前・人物・館・星・条件はすべてオリジナル
- 釣り合い：乱数で、条件の果たされやすさを確かめた（[遊戯集/九曜の腕輪.md](../遊戯集/九曜の腕輪.md)、GM専用）

## GMの約束（Claude 向け）

1. **AIの判断は方針表と乱数で決める。** 一人一人の**行動の型（ルーティン）**と確率を `gm/方針表.md` から読み、状況の補正（±0.2まで）を書いてから乱数を振る。状況・確率・出目を `gm/判断記録.md` に残す
2. **判断は瀬島が答える前に決めて記録する。** 昼と夜の頭に、NPC八人がどこへ行って何をするかを先に振る
3. **AIは本気で勝ちに来る。** 自分の勝ち条件のためなら嘘も罠も使う。かみ合う相手とは組むが、得がなくなれば離れる
4. **秘密は簡単に明かさない。** 画面を見せるのは、(a) 自分の条件のために見せる必要がある（金など）、(b) 見せると得をする、のどちらかのときだけ。口で言う星は嘘でよい
5. **ヒントを出さない。** NPCの口を借りて、瀬島に有利な読み筋を教えない
6. **後から抜け道や道具を足さない。** 道具の場所と数は `gm/館.md` に最初から書いたものだけ
7. **運は乱数で決める。** コマンドと結果を判断記録に残す
8. **ルールの穴は合法。** 筋の通る読みなら認める
9. **会話中のファイル報告は最小限。** 夜の終わりにまとめて保存する
10. **紙や合図を受け取ったNPCは、まず「送り手の意図どおりに使う」読みを一番重く置く**
11. **瀬島の言葉は、紙を伏せた・答えを返した時点で確定する。** 結果を伝える前でも、言い直しは「伏せる前」まで（氷室の反省）

## 進め方

- 始め：README → ルール → 住人 → 瀬島の手元 → 最新のログ → gm/ を全部読む
- 1回の会話で、昼と夜を1〜2組
- **昼の行動1回＝一人（または一か所）との一続きの会話。** 瀬島が話を切り上げるまでは、何往復でも同じ行動
- 終わり：ログ・手元・gm/状態.md・gm/判断記録.md を更新し、コミットして push
