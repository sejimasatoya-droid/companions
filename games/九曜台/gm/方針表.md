# 【GM専用】方針表

> NPCは一人一人、**行動の型（ルーティン）**が違う。昼と夜の頭に、型の表から「どこへ行き、何をするか」を乱数で振る。そのうえで、自分の星の勝ち条件から補正（±0.2まで）をかける。理由を判断記録に一行で書く。
> 「話が面白くなるから」は補正の理由にしない。瀬島を特別扱いしない。

## 共通
- 昼は3回、夜は1回。昼の頭に、3回ぶんの予定を型の表から振る。瀬島が話しかけてきたら、その回の予定はその会話に置きかわる
- **自分の条件にかみ合う相手**（日と月、羅睺・計都の互いの敵、土と火など）が誰かわかったら、型より条件を優先してよい（+.2）
- 罠にかかった・隔離を言い出されたなど、身の危険が出たら、その日は型の「守り」の行に移る
- 画面を見せるか：基本 .15。自分の条件に必要なら（金）.8。相手が先に見せたなら +.2。水の星は 0
- 口で星を聞かれたら、嘘 の確率で別の星を名乗る

## 人物の基本の確率

| 人物 | 型 | 深読み | 嘘 | 約束 | 攻め |
|---|---|---|---|---|---|
| 神崎 | 探索屋 | .55 | .40 | .60 | .30 |
| 七瀬 | 交渉人 | .50 | .60 | .40 | .35 |
| 榊 | 罠師 | .60 | .35 | .65 | .60 |
| 小野寺 | 隠れる者 | .65 | .50 | .50 | .40 |
| 若林 | 調停者 | .45 | .45 | .70 | .25 |
| 黒田 | 疑う者 | .60 | .55 | .45 | .55 |
| 芦屋 | 追う者 | .50 | .40 | .55 | .45 |
| 戸塚 | 便乗者 | .35 | .50 | .50 | .35 |

- **深読み**：ルールの穴や、他人の条件どうしのからみ（「生き残りの数」が夜明けの確かめの前に数えられる、など）に気づく確率。第1日の昼に一度だけ振る
- **嘘・約束・攻め**：これまでの作品と同じ意味

## 行動の型（ルーティン）

各行の確率で、その回の行動を決める。合わない行（道具がない、部屋がない）は振り直す。

### 1. 探索屋（神崎）
部屋を一つずつ調べて回る。道具を見つけたら、まず持つ。人とはついでに話す。
| 昼の一回 | 確率 |
|---|---|
| まだ調べていない部屋を調べる | .60 |
| 調べた部屋をもう一度調べる（見落としを探す） | .10 |
| その部屋にいる者と話す | .25 |
| 道具を使う（罠を仕掛ける・鍵を開ける） | .05（攻めで補正） |
- 夜：鍵のかかった部屋・まだの部屋を調べる .5 ／ 眠る .5
- 守り：道具を手放さず、個室にこもる
- 癖：嘘をつくとき、**登山靴の紐を結び直す**

### 2. 交渉人（七瀬）
人に会い続ける。会うたびに「取引」を持ちかける（情報・道具・見せ合い）。部屋はほとんど調べない。
| 昼の一回 | 確率 |
|---|---|
| まだ話していない者のところへ行き、取引を持ちかける | .50 |
| 一度話した者ともう一度話し、話を詰める | .30 |
| 聞いた話を、別の者に売る | .15 |
| 部屋を調べる | .05 |
- 取引の中身：見せ合い（金なので本気）、道具と情報の交換、投票の約束
- 夜：誰かの個室を訪ねて話す .4 ／ 眠る .6
- 守り：一番強そうな者に取り入る
- 癖：嘘をつくとき、**名刺入れを指で弾く**

### 3. 罠師（榊）
罠の部品を集め、人が通る部屋に仕掛ける。仕掛けた部屋には、自分は近づかない。
| 昼の一回 | 確率 |
|---|---|
| 罠の部品がありそうな部屋（機械室・倉庫・食堂）を調べる | .40 |
| 部品があれば、人の多い部屋に仕掛ける | .35（攻めで補正） |
| 人の動きを見張る（廊下に立つ。誰がどこへ行ったかがわかる） | .20 |
| 話す | .05 |
- 夜：罠を仕掛ける .5 ／ 見張る .2 ／ 眠る .3
- 自分の条件が罠と関係ないときは、罠を「身を守る道具」として個室の前に仕掛ける
- 守り：自分の個室の前に罠
- 癖：嘘をつくとき、**指の関節を鳴らす**

### 4. 隠れる者（小野寺）
自分からはほとんど動かない。個室と、近くの部屋（資料室・医務室）だけ。話しかけられれば短く答える。見られていないときに動く。
| 昼の一回 | 確率 |
|---|---|
| 個室にいる（何もしない。訪ねてきた者とだけ話す） | .45 |
| 近くの部屋を調べる | .30 |
| 誰もいない部屋に、こっそり何かする（罠・道具を隠す） | .20（攻めで補正） |
| 自分から話す | .05 |
- 夜：**夜に一番よく動く**。こっそり調べる・仕掛ける .7 ／ 眠る .3
- 守り：個室から出ない
- 癖：嘘をつくとき、**パーカーのフードをかぶる**

### 5. 調停者（若林）
全員を食堂に集め、話し合いで決めようとする。隔離の投票を止めようとする。
| 昼の一回 | 確率 |
|---|---|
| 食堂にいて、来た者と話す（「みんなで条件を見せ合いましょう」） | .40 |
| 一人ずつ訪ねて、食堂に来るよう誘う | .35 |
| 揉めている二人の間に入る | .15 |
| 部屋を調べる | .10 |
- 夕：隔離の言い出しには、まず「待ちましょう」と言う。賛成するのは、罠を仕掛けたと割れた者だけ（自分の条件が羅睺なので、計都と割れた者にも賛成 .6）
- 夜：眠る .8 ／ 誰かを訪ねる .2
- 守り：人の多いところにいる
- 癖：嘘をつくとき、**眼鏡の鎖に触れる**

### 6. 疑う者（黒田）
人の言葉の食い違いを探し、夕の投票を主導する。記者らしく、誰がいつどこにいたかをメモする。
| 昼の一回 | 確率 |
|---|---|
| 誰かを問い詰める（どこにいた、何を持っている、星は何か） | .45 |
| 誰がどこへ行ったか聞き込む | .30 |
| 部屋を調べる | .15 |
| 誰かと組む話をする | .10 |
- 夕：一番怪しい者の隔離を言い出す .55（攻め）。怪しさは、罠・嘘の食い違い・画面を見せない
- 夜：メモを整理して眠る .6 ／ 誰かの部屋を見張る .4
- 守り：先に誰かの隔離を言い出す
- 癖：嘘をつくとき、**手帳を閉じる**

### 7. 追う者（芦屋）
一人に目をつけ、その者の後をついて回る。目をつける相手は、昼の頭に乱数（自分の条件に関わりそうな者に重み）。
| 昼の一回 | 確率 |
|---|---|
| 目をつけた者と同じ部屋へ行く | .55 |
| 目をつけた者と話す | .25 |
| 目をつけた者が調べたあとの部屋を調べる | .15 |
| ほかの者と話す | .05 |
- 目をつける相手：第1日は乱数。第2日からは、「日」だと思う者に重み3（月なので）
- 夜：目をつけた者の個室の前で見張る .5 ／ 眠る .5
- 守り：目をつけた者のそばにいる
- 癖：嘘をつくとき、**髪の先をいじる**

### 8. 便乗者（戸塚）
一番強そうな者（話をまとめている者、道具を持っていそうな者）について回り、その者の言うことに合わせる。強い者が変われば乗り換える。
| 昼の一回 | 確率 |
|---|---|
| 強そうな者のところへ行き、手伝いを申し出る | .50 |
| 強そうな者がいる部屋にいる | .25 |
| 聞いた話を強そうな者に伝える | .20 |
| 自分で何かする | .05 |
- 夕：強そうな者と同じ票を入れる .7
- 夜：眠る .7 ／ 強そうな者を訪ねる .3
- 守り：強そうな者の言うことを全部聞く
- 癖：嘘をつくとき、**帽子のつばを下げる**

## 星ごとの補正（型の上にかける）

| 星 | 補正 |
|---|---|
| 日 | 隔離に反対 +.3。罠を外して回る（罠を見つけたら解く）。全員の生き残りを呼びかける |
| 月 | 「日」を探す。日と思う者の言うことを信じる（+.2） |
| 火 | 罠を仕掛ける・隔離を言い出す（攻め +.2）。一人落とせば、あとは守りに回る |
| 水 | 画面を見せない（0）。夜は個室に罠（読み取り機を防ぐ）。人と長く話さない |
| 木 | 種を探す（調べる行動 +.3）。種を持つ者と取引する |
| 金 | 見せ合いを持ちかける（.8） |
| 土 | 隔離に賛成 +.3。罠を勧める。口では「日」や「月」を名乗る（嘘 +.2） |
| 羅睺 | 計都を探す。計都と割れたら、隔離を言い出す・罠を向ける |
| 計都 | 羅睺を探す。羅睺と割れたら、隔離を言い出す・罠を向ける |

## 隔離の投票
- 言い出す：その日の怪しさが一番高い者がいて、言い出す理由（星の補正・疑う者の型）があるとき、攻め の確率
- 賛成の確率：怪しさ（GMが根拠の数で 0〜3 と数える）× .2 ＋ 星の補正。日は −.3、土は +.3
- 自分が言い出された者は反対
