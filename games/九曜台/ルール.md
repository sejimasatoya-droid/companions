# ルール（全員が腕輪の画面で読めること）

## 館

山頂の古い天文台と研究棟「九曜台（くようだい）」。九人が、それぞれの個室で目を覚ます。外へ出る道は、雪崩で塞がれている。
左の手首に、外れない**腕輪**がついている。腕輪の小さな画面に、このルールと、**自分の星**と、**自分の勝ち条件**が表示される。

## 時間

- **三日間。** 第1日の昼から第3日の夜まで、昼と夜が三回ずつ
- **昼**：一人**3回**行動できる（誰かと話す、どこかの部屋へ行って調べる、道具を使う、罠を仕掛ける）
- **夕**：食堂の放送のあと、**隔離の投票**（下記）
- **夜**：一人**1回**だけ、こっそり行動できる。行動しなければ個室で眠る
- **第4日の夜明け**：腕輪が勝ち条件を確かめる。**果たしていない者の腕輪は、その者を眠らせる（脱落）**

## 星と勝ち条件

九人の腕輪には、九つの星が一つずつ割り当てられている。誰がどの星かは、自分の画面にしか出ない。
条件の「生き残る」は、第4日の夜明けに、腕輪に眠らされていないこと。「生き残りの数」は、夜明けの確かめの**前**の数（それまでに脱落していない者の数）。

| 星 | 勝ち条件 |
|---|---|
| **日** | 生き残りが**6人以上**で、自分も生き残る |
| **月** | 「日」の者と自分が、二人とも生き残る |
| **火** | 自分が仕掛けた罠か、自分が言い出した隔離で、**一人以上**が脱落し、自分も生き残る |
| **水** | 最後まで、誰にも自分の腕輪の画面を見られずに、生き残る |
| **木** | 館にある**種を三つ**集め、第3日の夜までに温室の鉢に植えて、生き残る |
| **金** | **二人以上**と、互いに腕輪の画面を見せ合って、生き残る |
| **土** | 生き残りが**5人以下**で、自分も生き残る |
| **羅睺**（らごう） | 「計都」の者が脱落し、自分は生き残る |
| **計都**（けいと） | 「羅睺」の者が脱落し、自分は生き残る |

## 腕輪
- 画面は、持ち主が手首を差し出せば、相手に見せられる。**見せた画面は偽れない**
- 腕輪は外れない。他人の腕輪をこじ開けようとした者は、**警告**を二つ受ける
- 腕輪に**警告**が二つたまった者は、その場で眠らされる（脱落）

## 部屋と道具
- 部屋：個室（九つ）、食堂、観測ドーム、資料室、温室、医務室、機械室、屋上、地下倉庫（鍵がかかっている）
- 部屋を調べると、そこに置かれた道具を見つけられる。見つけた道具は持って行ける
- 道具は次の五種類。誰がいくつ持っているかは、本人しか知らない

| 道具 | 使い方 |
|---|---|
| **種** | 木の星の者が、温室の鉢に植える。誰でも持ち運べる |
| **罠の部品** | 1回の行動で、どこかの部屋に罠を仕掛ける。仕掛けた者のほかで、次にその部屋に入った者が罠にかかり、**警告を一つ**受ける。罠はそこでなくなる |
| **読み取り機** | 夜の行動で、眠っている者の個室に入り、その者の腕輪の画面を読む。読まれた者は気づかない |
| **解毒剤** | 自分か、誰かの警告を一つ消す |
| **地下倉庫の鍵** | 地下倉庫を開けられる |

## 隔離の投票（毎日の夕）
- 誰か一人が「〈誰それ〉を隔離する」と言い出せる（一日一回、早い者勝ち）
- 生き残っている全員が、同時に賛成か反対を書く。**過半数が賛成**なら、その者は隔離室に閉じ込められる（脱落）
- 誰が言い出したかは全員が見ている。誰が賛成したかは発表されない（数だけ）

## 放送
- 朝と夕に、食堂の放送が、**脱落した者の名前**だけを告げる。星は告げない

## 掟
1. 他人に暴力をふるった者は、警告を二つ受ける
2. 嘘をついてはならない、という掟はない
3. ルールに書かれていないことは、禁じられていない
