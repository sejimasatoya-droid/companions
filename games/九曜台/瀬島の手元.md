# 瀬島の手元

## 腕輪の画面

> 星：**日**
> 勝ち条件：第4日の夜明けに、生き残りが**6人以上**で、あなたも生き残っていること。

- 警告：0
- 道具：なし
- 画面を見せた相手：七瀬、黒田、（第1日の夕に）全員

## わかっている星
| 人物 | 星 | どうやって |
|---|---|---|
| 七瀬 | **金** | 画面（見せ合い）。組んでいる |
| 黒田 | **計都** | 画面（見せ合い）。「羅睺を探している。お互い黙っておこう」 |
| 神崎 | 「月」 | 口だけ。画面は断った |
| 小野寺 | 「火」？「月」？ | 七瀬には「火」、瀬島には「月」と口で言った |
| 戸塚 | 「土」 | 温室で皆の前で口で言った。最後の夜に「本当だ」と打ち明けた |
| 若林 | ― | 「計都の人を探している」と皆の前で言った |

## メモ
- 組：二の組（瀬島・戸塚・若林）。一の組は榊・七瀬・芦屋
- 七瀬との約束：隔離には反対、聞いた話は回す、七瀬の二人目の見せ合い相手を紹介する
- 第1日の夜、七瀬が榊の部屋へ、神崎が資料室へ入るのを見た
- 第2日：黒田の小野寺隔離に反対（否決）。若林と「黒田の言い出しには反対」と約束
- 第3日：若林と黒田が食堂の罠で警告1ずつ。小野寺の黒田隔離に反対（否決）

## 結果
**第4日の夜明け、生還。**（生還：瀬島・芦屋・神崎・七瀬）
