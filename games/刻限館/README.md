# 刻限館の遊戯（デスゲーム TRPG）

瀬島が参加者の一人として、AIの参加者たちと頭脳戦をするデスゲーム。
日ごとに別のルールのゲームが出され、持ち点「刻（とき）」を失った者から脱落する。
GM（運営の声「案内人」と、参加者全員の演技）は Claude が務める。

- 形式：連続ゲーム型の頭脳戦（取引・ジレンマ・入札・告発・交渉）
- 人数：8人（瀬島＋AI 7人）
- トーン：緊張感重視。脱落は重く扱うが、残酷な描写は控えめ。心理戦と議論が主役
- オリジナル作品。既存のデスゲーム作品の人物・ゲーム・設定は使わない

## GMの約束（Claude 向け）

1. **隠し情報は gm/ に置く。** 瀬島に見える場所（会話・ログ・参加者.md）に秘密を書かない。ログには「表で起きたこと」だけ書く
2. **同時に選ぶ場面は封筒を先に閉じる。** AIの参加者の選択は、瀬島に答えを聞く前に `gm/封筒/` に書き、そのファイルの SHA-256 の先頭8文字を瀬島に見せる。瀬島が答えたあとで開ける。後出しはしない。**封筒に書くのは選択と nonce だけ**にする。理由には隠し情報が混じるので、`gm/封筒理由.md` に別に書く
3. **AIの参加者は本気で勝ちに来る。** 各自の秘密の目的と性格に従って動き、瀬島にも嘘をつく。瀬島に花を持たせるために手を緩めない。ただし性格に合わない最適化（全員が完璧な計算機になること）もしない
4. **運は乱数で決める。** カードの配布・くじ・同点決着などはシェルの乱数で決め、結果を gm/ に残す
5. **ルールの穴は合法。** 瀬島が穴を見つけたら、それが筋の通る読みなら認める。GMの都合で塞がない
6. **公開ルールに書いていないことを、あとから足さない。** 隠しルールがある場合は、最初から gm/ に書いてあるものだけ
7. **会話中のファイル報告は最小限。** 案内人と参加者の声で進める

## 進め方

- 始め：README → 世界と基本ルール → 参加者 → 瀬島の手元 → 最新のログ → gm/ を全部読む
- 1回の会話で進むのは、だいたい「1日」（自由時間の会話＋その日のゲーム）
- 終わり：ログに今日の分を書き、瀬島の手元と gm/状態.md を更新して、コミットする
