# 宵送り（ループもの TRPG ＋ マーダーミステリー・第六作）

八月十三日の朝、瀬島は本土からの船で、瀬戸内の小さな島 **篝島（かがりじま）** に着く。民宿「汐見荘」の住み込みのアルバイトとして、お盆の四日間を過ごすはずだった。
十六日の夜は、島の祭り **宵送り**。死者を乗せた灯籠を、舟で沖へ還す夜。
その四日のどこかで、島は惨事に沈む。そして瀬島は、**また十三日の朝の船の上で目を覚ます。**

覚えているのは瀬島だけ。島の人は毎回、初めて会う顔で瀬島を迎える。
事件は、瀬島が何もしなければ、毎回同じ時刻に、同じ場所で起こる。その記憶を武器に、惨事を防ぎ、誰が糸を引いているのかを突き止める。

- 人数：瀬島＋島の人6人（NPC）
- 時間：4日 × 4刻（朝・昼・夕・夜）＝16刻。**ループは三周まで**
- 勝ち負け：三周のうちに一度でも惨事なく十六日の夜を越えれば生還。さらに、**糸を引く者を止め、真相を言い当てれば本当の結末**
- 暴力：あり（死はある）。描写は控えめ
- 判定：2d6 ＋ 能力
- 着想：ボードゲーム『惨劇RoopeR』の「ループの記憶を武器に、決まった時刻の事件を防ぐ」という仕組み。島・人物・役・事件・判定はすべてオリジナル
- 釣り合い：乱数で、打ち方ごとの生還の見込みを確かめた（`gm/釣り合い.md`、GM専用）

## GMの約束（Claude 向け）

1. **真相と筋書きは、始める前に決めたものだけ。** 会話の中で事件・手がかり・抜け道を足さない。変えない
2. **筋書きは、瀬島が動かなければ毎周同じに起こる。** ずれと確率は、刻の頭に方針表どおり乱数で振り、判断記録に残してから瀬島の行動を聞く
3. **糸引きは本気で勝ちに来る。** 邪魔に気づけば筋書きを変え、瀬島も狙う。甘くしない
4. **ヒントを出さない。** NPCの口を借りて、正しい読み筋を教えない。判定も、瀬島が宣言した行動にだけ振る
5. **瀬島に見えるものだけを語る。** その場にいなかった事件は、音・噂・翌刻に見える跡としてだけ届く
6. **島の人は前の周を覚えていない。** 信頼は周ごとに0に戻る。瀬島がループの知識を口にしたときの反応は方針表で振る
7. **ルールの穴は合法。** 筋の通る手なら認める
8. **瀬島の言葉は、行動を宣言した時点で確定する**（刻の結果を伝える前でも、言い直しは宣言の前まで）
9. **gm/ の中身を、会話・ログ・公開ファイルに漏らさない**
10. **会話中のファイル報告は最小限。** 日の終わりにまとめて保存する

## 進め方

- 始め：README → ルール → 島の人々 → 島の地図 → 瀬島の手元 → 最新のログ → gm/ を全部読む
- 最初の一回だけ：瀬島が能力を振り分ける（ルール.md）
- 1回の会話で、1〜2日ぶん（4〜8刻）
- **一刻の行動＝一か所での一続きの会話や調べもの。** 瀬島が切り上げるまでは、何往復でも同じ刻
- 惨事が起きたら、その場面で周を閉じ、ログに「周の終わり」を書いて、次の周の1朝から始める
- 終わり：ログ・手元・gm/状態.md・gm/判断記録.md を更新し、コミットして push
