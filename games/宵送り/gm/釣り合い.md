# 【GM専用】釣り合い

> `gm/釣り合い.py` の簡略モデル（筋書きの事件・判定・ずれ・警戒を入れたもの）を、一つの打ち方につき2万回。能力は 観る2・話す2・忍ぶ1・動く1 で測った。seed 7 と 8 でほぼ同じ。

| 打ち方 | 惨事 | 生還 | 暴いた |
|---|---|---|---|
| 何も知らない（毎刻、行き先を乱数） | .80 | .20 | 0 |
| 一周目の記憶だけ（4夜に凪に付き添い、3夜に社を張る） | .44 | .56 | 0 |
| 全部を防ぐ（筋書きを知り尽くして、事件を一つずつ潰す） | .24 | .76 | 0 |
| 暴く（荷物と手紙で証を二つ集め、人前で問う） | .17 | .83 | .35 |

## ここから決めたこと

- **ループは三周まで。** 四周にすると、二周目の「張るだけ」でも通りやすく、甘い
- 三周を素直に進めた見込み：一周目 .2、二周目 .5 前後、三周目 .75 前後 → 三周とも惨事 ≈ .1。ただし実際の会話では、知り尽くしの打ち方には届かない（何が起きているか、一周目で見えるのは一部だけ）。数よりは厳しい
- 生還そのものより、**紗英を暴いて、真相を言い当てる**方を本当のゴールにする。知り尽くしても、暴けるのは三回に一回ほど
- 張り込みは目立つ（紗英が .35 で警戒）。警戒されると凪の事件が早まり、夜にひとりでいる瀬島が狙われる。「全部の現場に立つ」だけでは勝てない
- 調整の履歴：最初は「凪と社だけ張る」が .89 で通った → 付き添いで凪の信頼が上がらないようにし、凪がこっそり抜ける形にし、張り込みに警戒を足し、社で止められた一真の二度目（4夕）を足した
