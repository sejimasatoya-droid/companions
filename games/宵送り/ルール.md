# ルール（瀬島が知っていること）

## ループ

- 瀬島は、**8月13日の朝**、本土から篝島への船の上で始まる
- その周の中で**惨事**（下記）が起きると、灯台の鐘の音が聞こえ、瀬島は**また13日の朝の船の上で目を覚ます**
- 戻ってくるのは、瀬島の**記憶だけ**。持ち物・手に入れた物・島の人との信頼は、すべて最初に戻る。島の人は前の周を覚えていない
- **三周まで。** 三周目でも惨事が起きたら、ループはそこで止まる（敗北）
- 三周のうち、どの周でも、惨事なく **8月16日の夜（宵送り）を越えれば**、ループは止まる（生還）

## 時間

- 4日 × 4刻（**朝・昼・夕・夜**）。1日目＝13日、4日目＝16日
- 瀬島は、一刻に**一回だけ行動**できる：島の七か所のどこか一つへ行き、そこにいる人と話す／調べる／見張る／付き添う／何かを持ち出す、など
- 一刻の行動は、一か所での一続きの場面。瀬島が切り上げるまで、何往復話してもよい
- 島は小さい。どこへでも、一刻のうちに行ける。ただし同じ刻に二か所にはいられない
- 瀬島がいない場所でも、時間は進む。見ていないところで起きたことは、音や噂、次の刻に見える跡でしか知らない
- 島の人は、それぞれいつもの暮らしの通りに動いている。ときどき、いつもと違う所にいる

## 判定

- 瀬島には四つの**能力**がある。最初の周の前に、**6点**を振り分ける（一つにつき0〜3）。周が変わっても能力は変わらない

| 能力 | 使うとき |
|---|---|
| **観る** | 気づく、見つける、読み取る、見張る |
| **話す** | 打ち解ける、頼む、説き伏せる、問い詰める |
| **忍ぶ** | こっそり入る、持ち出す、つける |
| **動く** | 止める、かばう、駆けつける、取り押さえる |

- むずかしいことをするとき、**2d6 ＋ 能力 が 8以上**で成功。むずかしさで目標が上下することがある
- 判定は、瀬島が「〜する」と言ったことにだけ振る

## 信頼

- 島の人一人ごとに **0〜3**。話す判定に通る、困りごとを助ける、などで上がる。うそがばれる、盗みを見られる、などで下がる
- 信頼が上がると、その人は、より深いことを話し、頼みを聞いてくれる
- 周が変わると、全員 0 に戻る
- 前の周で知ったことを口にすると、相手は驚く。信じるか、気味悪がるかは、相手しだい

## 役

島の六人には、それぞれ**一つの役**がある。誰がどの役かは、隠されている。**下の七つのうち、一つは使われていない。**

| 役 | どういう者か |
|---|---|
| **要**（かなめ） | この者が死ぬと、その周は惨事になる |
| **糸引き** | 事件の多くを仕掛ける。人を動かし、自分の手はなるべく汚さない。邪魔に気づけば、手を変える |
| **仇討ち** | 恨む相手がわかれば、手を下す |
| **口封じ** | 隠したいことが漏れそうになれば、それを消しにかかる |
| **証人** | 事件の鍵になる物か話を持っている。本人は、その値打ちに気づいていないことがある |
| **守り手** | ある一人のそばにいるかぎり、その者を守る |
| **火付け** | 夜に火を放つ |

## 惨事

次のどれか一つが起きたら、その周は惨事。そこで周が閉じる。

1. **要が死ぬ**
2. **一つの周で、島の人が二人死ぬ**
3. **瀬島が死ぬ**

## 結末

| 結末 | 条件 |
|---|---|
| 敗北 | 三周とも惨事 |
| 宵が明ける | 惨事なく16日の夜を越える |
| 送り火 | 上に加えて、その周のうちに糸引きを人前で暴き、止める |
| **灯を還す**（本当の結末） | 上に加えて、**真相の宣言**をすべて言い当てる |

### 真相の宣言
惨事なく16日の夜を越えたあと、一度だけ宣言する。
1. 六人それぞれの役
2. 糸引きの名と、その者がねらっていたこと
3. この島で、昔なにがあったか（誰が、何をして、誰が隠したか）

## 掟
1. 嘘をついてはならない、という掟はない
2. ルールに書かれていないことは、禁じられていない
