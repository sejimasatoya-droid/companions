# 篝島の地図

周囲4キロほどの小さな島。人口は百人に足りない。本土との船は、朝に一便だけ（16日は祭りで欠航）。

```
              灯台 ── 灯台下の岩場
               │
   分校跡 ── 篝神社
     │         │
    浜 ──── 汐見荘 ── 診療所
               │
              港
```

| 場所 | どういう所 |
|---|---|
| **港** | 船着き場と、漁師の舟。一真の舟もここ。小さな売店がある |
| **汐見荘** | 民宿。一階に台所と食堂、二階に客間（「浜木綿の間」ほか）と、女将の部屋。瀬島は一階の奥の小部屋に寝起きする |
| **篝神社** | 島の高みにある神社。社務所と、祭りの道具を入れる蔵。宵送りの灯籠はここで作る |
| **診療所** | 平屋。診察室と、奥に古いカルテを置いた書庫 |
| **分校跡** | 十年前に閉じた小学校の分校。木造の校舎が残っている |
| **灯台** | 島の北の端。灯台の下には岩場があり、潮が速い |
| **浜** | 島の西の砂浜。16日の夜、ここから灯籠を流す |
