# 巡り湯（ループもの・推理ボードゲーム）

大正の終わり、山あいの温泉町・鳴沢。四つの場所に分かれた小さな町で、四日のうちに惨劇が起きる。
主人公は、惨劇のたびに一日目の朝へ戻る。黒幕は、町の人の気分を荒らし、人を動かして、事件を起こそうとする。主人公は、手札で人を動かし、気分を和ませ、逗留客の駒で人目を作って、それを防ぐ。
そのあいだに、**誰がどの役で、どの事件の犯人なのか**を読む。

- 人数：二人（黒幕＝Claude、主人公＝瀬島）
- 盤：四つの場所を2×2に並べる
- 着想：ボードゲーム『惨劇RoopeR』の「四つの場所の盤」「黒幕と主人公が札を伏せて置く」「ループの記憶で事件を防ぐ」という型。町・人物・役・札・事件・解き方はすべてオリジナル
- 釣り合い：黒幕を方針表どおりに打たせ、主人公の知識を三段に変えて乱数で確かめた（`gm/釣り合い.md`、GM専用）

## GMの約束（Claude 向け）

1. **黒幕の札は、方針表と乱数で決める。** 瀬島が伏せる前に決め、判断記録に書く。あとから変えない
2. **黒幕は本気で勝ちに来る。** 甘くしない。瀬島を特別扱いしない
3. **ルールは文言どおり。** 効かなかった札は「効かなかった」とだけ言う。理由・役・犯人を漏らさない
4. **役の力は正直に使い、告げる。** 糸引きの −1 は、「誰の気分が下がったか」を言う（どの役の力かは言わない）
5. **ヒントを出さない。** 瀬島が聞いたことには、ルールの文言どおりにだけ答える
6. **gm/ の中身を、会話・ログ・公開ファイルに漏らさない**

## 進め方

- 始め：README → ルール → 第一話 → 盤面.html の STATE → 瀬島の手元 → 最新のログ → gm/ を全部読む
- 一日ごとに：①瀬島が逗留客を動かす → ②黒幕が伏せる（判断記録へ）→ ③瀬島が札を3枚言う → ④開いて解き、盤面を見せる
- 盤面は、毎日の解決のあと、`盤面.html` の `STATE`（「ここだけを書き換える」の間）を書き換える。**公開の情報だけ**を入れる（役・犯人・黒幕がまだ開いていない札は入れない）。履歴には、開いたあとの両者の札と起きたことを書く
- チャットでも、盤を短い表で示す
- 1回の会話で、一周か二周くらい
- 終わり：盤面.html・手元・ログ・gm/状態.md・gm/判断記録.md を更新し、コミットして push
