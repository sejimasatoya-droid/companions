# 【GM専用】第一話「写真の中の女」の真相

> **瀬島は読まない。** 役と犯人は、ここに書いたものだけ。会話の中で変えない。

## 役

| 人物 | 役 |
|---|---|
| たえ | **要** |
| 三条 鷹之 | **糸引き** |
| 室井 清彦 | **刃** |
| 篠 | **守り手** |
| 有馬 惣介 | **迷い子** |
| 坂巻 源治 | **ただの人** |

## 犯人

| 日 | 事件 | 犯人 | 値 |
|---|---|---|---|
| 二日目 | 失踪 | **源治** | −1 |
| 三日目 | 火事 | **有馬** | −2 |
| 四日目 | 殺め | **清彦** | −1 |

## 話の筋（エンディングで語る）

- 三条は東京で、女の写真を売りさばいていた男。鳴沢で、たえを「町一番の器量よし」として撮り、写真を東京の客に回した。客の一人が清彦の友人で、清彦は写真を見て、たえに執着する
- 源治は、写真が町に出回ったのを恥じて、篠に「たえを湯屋に匿え」と言われても聞かず、たえを町から逃がそうとする（二日目の失踪：連れ出された者が、山向こうの村へ送られて戻らない）
- 有馬は、三条に借金がある。三条に追い詰められると、停車場の古い倉庫に火を放ち、帳簿ごと町を焼く（三日目の火事）
- 清彦は、たえを自分のものにできないと知ると、四日目にたえを手にかけようとする（四日目の殺め）
- 篠は、たえを妹のように見ている。同じ場所にいれば、たえを守る

## 解き筋（瀬島が読める跡）

- 糸引きの −1 は、毎日、三条のいる場所で起きる → 誰のそばで気分が下がるかを見れば、糸引きが絞れる
- 「和ませる」が効かない人物がいる（逗留客がいないとき）→ 迷い子
- 失踪・殺めの「二人きり」が起きた場所と顔ぶれ → 犯人が絞れる
- 火事は、二人きりでなくても起きる → 気分が −2 以下の者が犯人
- 篠とたえが同じ場所にいる日は、殺めも失踪もたえには起きない → 守り手
- 清彦は最初から −1。四日目の殺めの犯人で、−3 になると刃の力でも殺める
