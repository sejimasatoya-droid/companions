# 【GM専用】釣り合い（第一話）

> `gm/釣り合い.py`。黒幕は方針表どおり（乱数つき）。主人公の打ち方を三つに変えて、一つにつき2万回。seed 3 と 5 でほぼ同じ。

| 主人公 | 一周を越える | おもな負け |
|---|---|---|
| 乱数で打つ | .06 | 火事 .67、失踪 .13、刃が逗留客を .10 |
| 事件の日だけ知る（たえに足止め、気分の低い者を見守る） | .22 | 火事 .75 |
| 役と犯人を知り尽くす（犯人を和ませ、迷い子を見守る、逗留客でたえと犯人に付く） | .46 | 火事 .47、刃が逗留客を .06 |

## 決めたこと

- **三周**。一周目 ほぼ負け、二周目 .2 前後、三周目 .4〜.5。知り尽くしの打ち方はまだ最善ではない（迷い子に逗留客を付けて和ませる、など）ので、人の読みで .5〜.6 まで上がる見込み
- 火事が一番の壁。犯人は迷い子なので、和ませるが逗留客なしでは効かない。これに気づくのが第一話の山
- 調整の履歴
  - 最初は、迷い子を「上げる札が一切効かない」にした → 火事が止められず、知り尽くしても 0。迷い子を「逗留客がいるときだけ効く」に変え、「見守る」を足した
  - 見守るを毎日1枚にしたら、知り尽くしで .91 → 一周に2枚に減らした
  - 黒幕が二日先まで見て犯人を下げるようにした（.91 → .46）
- 簡略にしたところ：黒幕の「〜へ」が同じ行き先で二枚になることがある（本番では、同じ札は一枚まで）
