# 巡り湯　ルール

大正の終わり、山あいの温泉町・鳴沢（なるさわ）。この町の四日間は、惨劇で終わる。
主人公（逗留客の二人）は、惨劇が起きるたびに、一日目の朝へ戻る。黒幕は、それを知っていて、毎回同じ糸を引く。

- **黒幕**：Claude。町の人の役と、どの事件の犯人が誰かを知っている
- **主人公**：瀬島。役も犯人も知らない。知っているのは、何日目にどんな事件が起きるかだけ

## 盤

町は四つの場所に分かれている。**縦と横は隣。斜めは隣ではない。**

```
 ┌──────────┬──────────┐
 │  湯屋    │  停車場  │
 ├──────────┼──────────┤
 │  写真館  │  製糸場  │
 └──────────┴──────────┘
```

- 湯屋 ⇔ 停車場、湯屋 ⇔ 写真館、停車場 ⇔ 製糸場、写真館 ⇔ 製糸場
- 湯屋 ⇔ 製糸場、停車場 ⇔ 写真館 は、一度には行けない

## 人物

- 町の人一人一人に、**いる場所**と**気分**（−3〜+3）がある。どちらも全員に見えている
- 人によっては、**入れない場所**がある。入れない場所へは、どの札でも動かない
- 町の人一人一人に、隠された**役**がある（下記）

## 逗留客（主人公の駒）

- 主人公は**逗留客の駒を二つ**持つ。町の人ではないので、気分も役もない
- 逗留客は、**人目**になる。逗留客がいる場所では、「二人きり」の事件は起きない
- 逗留客が殺されると、惨劇

## 手札

両者とも、**毎日、手札が全部戻る**。ただし「一周に〜」と書いた札は、その周で使い切ったら、次の周まで戻らない。

### 黒幕の札
| 札 | 枚数 | 効き目 |
|---|---|---|
| 湯屋へ／停車場へ／写真館へ／製糸場へ | 各1 | その人物を、名を書いた場所へ動かす（隣のときだけ） |
| 荒らす | 2 | 気分 −1 |
| 煽る | 一周に1 | 気分 −2 |
| 呼び出す | 一周に1 | その人物を、黒幕が指名した別の人物のいる場所へ動かす（**隣でなくてもよい**） |

### 主人公の札
| 札 | 枚数 | 効き目 |
|---|---|---|
| 湯屋へ／停車場へ／写真館へ／製糸場へ | 各1 | その人物を、名を書いた場所へ動かす（隣のときだけ） |
| 和ませる | 2 | 気分 +1 |
| 足止め | 1 | その日、その人物への「〜へ」「呼び出す」を、すべて打ち消す |
| 励ます | 一周に1 | 気分 +2 |
| 見守る | 一周に2 | その日、その人物の気分を下げる効き目（札・役の力）を、すべて打ち消す |

## 一日の流れ

1. **朝・逗留客**：主人公は、逗留客の駒をそれぞれ、隣の場所へ一つ動かすか、そのままにする（公開）
2. **朝・黒幕が伏せる**：黒幕は札を**3枚**、それぞれ**別の町の人**に伏せて置く
3. **朝・主人公が伏せる**：主人公も札を**3枚**、それぞれ**別の町の人**に伏せて置く
4. **昼・開く**：全部を表にして、次の順に解く
   1. 足止め
   2. 「〜へ」：同じ人物に「〜へ」が二枚（どちらの側でも）置かれたら、**両方とも効かない**。一枚だけなら、隣のときだけ動く
   3. 呼び出す
   4. 気分の上げ下げ（見守るを先に見る）。−3より下、+3より上にはならない
5. **昼・役の力**：役の力を使う（下記。黒幕は使ったことを告げる）
6. **夕・事件**：その日の事件の条件を見る。条件がそろえば起きる
7. **夜**：次の日へ。四日目の夜を惨劇なしに越えたら、主人公の勝ち

- 黒幕は、伏せた札を、開く前に判断記録へ書く（あとから変えないため）
- 効き目が出なかった札は、黒幕が「効かなかった」とだけ言う（理由は言わない）

## 役

町の人一人一人に、次の六つの役が**一つずつ**割り当てられている（第一話では六人とも違う役）。

| 役 | 力 |
|---|---|
| **要**（かなめ） | この者が死ぬか、失踪したら、惨劇 |
| **糸引き** | 毎日の昼、**同じ場所にいる町の人一人**の気分を −1 する |
| **刃**（やいば） | 夕に、自分の気分が **−3** なら、同じ場所にいる誰か一人を殺める（逗留客も含む）。事件とは別に起こる |
| **守り手** | 同じ場所にいる要は、殺められず、失踪もしない |
| **迷い子** | 気分を上げる札が、**同じ場所に逗留客がいるとき**しか効かない |
| **ただの人** | 力はない |

## 事件

筋書きには、**何日目に、どんな事件が起きるか**が書いてある（公開）。**犯人が誰かは伏せられている。** 犯人の気分が、事件ごとに決まった値**以下**のとき、条件を見る。

| 事件 | 条件 | 起きると |
|---|---|---|
| **失踪** | 犯人と、ほかに町の人がちょうど一人だけの「二人きり」（逗留客がいたら起きない） | その一人が町から消える |
| **殺め** | 失踪と同じ「二人きり」 | その一人が死ぬ |
| **火事** | 犯人の気分が値以下なら、それだけで | 町が焼ける。**惨劇** |

犯人が先に死ぬか失踪していたら、その事件は起きない。

## 惨劇とループ

次のどれかで、**その周は惨劇**。主人公は一日目の朝へ戻る。

1. 要が死ぬか、失踪する
2. 火事が起きる
3. 逗留客が殺される

- 戻ると、盤・気分・手札は、すべて最初に戻る。**主人公の記憶（瀬島の手元のメモ）だけ**が残る
- 周の数は、筋書きごとに決まっている。最後の周でも惨劇なら、**主人公の負け**

## 結末と推理

- 四日目の夜を惨劇なしに越えたら、**主人公の勝ち**
- 勝ったあと、主人公は一度だけ、**六人の役と、各事件の犯人**を言い当てられる。全部当たれば「本当の結末」
