# 月見座（デスゲーム TRPG・第七作）

山あいの湯治場に、閉じた芝居小屋「月見座（つきみざ）」がある。七人が楽屋で目を覚ます。めいめいの鏡台に、木の箱が一つずつ置かれている。中には**面**が一枚ずつ入っている。
天井のスピーカーから、**黒子**と名乗る声が言う。これから幕ごとに、皆で一人の名前を札に書く。一番多く書かれた者は**退場**する。舞台の奈落へ下りて、二度と上がってこない。

全員で協力しても、生きて小屋を出られるのは**多くても二人**。最後の二人になると、互いの名前を書くか、自分の名前を書くかの賭けになる。

- 人数：7人（瀬島＋NPC6人）
- 時間：最大五幕。一幕は 口上 → 楽屋 → 評定 → 札入れ → 開票
- 暴力：なし（掟で退場）。退場の描写は控えめ
- 着想：オープンソースのブラウザゲーム『AIデスゲーム』（MIT ライセンス）の骨組みを借りた。議論を二周して投票、最多票が退場、同数なら全員退場、最後の二人は囚人のジレンマ、黒子（司会者）の介入。小屋・人物・面・お題・形見はすべてオリジナル
- 第一回（2026-11-28）は第一版で遊び、葛西が一人で生還。そのあとルールを第二版に直した（決選、般若は一人だけのとき、見せ合いの届け出、形見は一人一つ、二人札は第三幕から、客席の野次）
- 釣り合い：乱数で確かめた（[遊戯集/月見の面.md](../遊戯集/月見の面.md)、GM専用）

## GMの約束（Claude 向け）

1. **NPCの判断は方針表と乱数で決める。** `gm/方針表.md` の確率と札の点数表を読み、状況の補正（±0.2まで）を書いてから振る。状況・確率・出目を `gm/判断記録.md` に残す
2. **札は瀬島が書く前に決めて記録する。** 評定が終わったら、NPC六人の札を先に振って判断記録に書き、それから瀬島に聞く。瀬島の札を見てから変えない
3. **NPCは本気で生き残りに来る。** 最後の二人に残るために、嘘・裏切り・形見の取引を使う。組んだ相手でも、得がなくなれば札で切る
4. **面は簡単に見せない。** 見せるのは方針表の確率どおり。口で名乗る面は嘘でよい
5. **ヒントを出さない。** NPCや黒子の口を借りて、瀬島に有利な読み筋を教えない。黒子はルールを聞かれたら、ルール.md の文言どおりにだけ答える
6. **後から面・お題・抜け道を足さない。** 配りとお題の順は `gm/秘密.md` に最初から書いたものだけ
7. **ルールの穴は合法。** 筋の通る読みなら認める
8. **瀬島の札は、箱に入れた時点で確定する。** 言い直しは入れる前まで
9. **会話中のファイル報告は最小限。** 幕の終わりにまとめて保存する
10. **紙や合図を受け取ったNPCは、まず「送り手の意図どおりに使う」読みを一番重く置く**

## 進め方

- 始め：README → ルール → 座員 → 瀬島の手元 → 最新のログ → gm/ を全部読む
- 1回の会話で、一〜二幕
- **楽屋の行動1回＝一人との一続きの会話。** 瀬島が話を切り上げるまでは、何往復でも同じ行動
- 評定は、くじの順に一人ずつ二周。NPCの発言は方針表の「評定で言うこと」から振る
- 終わり：ログ・手元・gm/状態.md・gm/判断記録.md を更新し、コミットして push
