# 【GM専用】秘密

> 作った日：2026-11-28。乱数 `random.Random(123554339)`（seed は `secrets.randbelow(10**9)`）。七枚を混ぜ、先頭の二枚を瀬島の箱、選ばなかった一枚の行き先を乱数、残り五枚を順に配った。

## 面の配り

| 人物 | 面 |
|---|---|
| 瀬島 | **天狗か素面**（二つの箱から選ぶ） |
| 鳴海 | 瀬島が選ばなかったほう（天狗か素面） |
| 白峰 | **般若** |
| 葛西 | **狐** |
| 桐生 | **素面** |
| 早瀬 | **小面** |
| 千鳥 | **翁** |

- 瀬島が天狗を選べば、素面は桐生と鳴海の二人。瀬島が素面を選べば、素面は瀬島と桐生
- 瀬島の二つの箱：天狗・素面。どちらも「受け身の能力だけ」ではない（天狗は自分から使う）。誓約と能力.md の8を満たす

## お題の順（引く順。使うのは先頭から五枚）

| 幕 | お題 |
|---|---|
| 第一幕 | **二人札** |
| 第二幕 | 平常 |
| 第三幕 | **逆さ札** |
| 第四幕 | 公開札 |
| 第五幕 | 平常 |
| （使われない） | 黙り札 |

- 生き残りが二人の幕では引かない。そのときは札を山に残し、次の幕で次の札を引く
- 狐（葛西）は、この順を知らない。お題は口上まで誰も知らない

## 評定の順
- 幕ごとに、口上のあとで乱数で決める（判断記録に書く）

## 瀬島には言わないこと
- 第一幕が二人札であること（口上で初めて読む）
- 誰がどの面か。選ばなかった箱の行き先
