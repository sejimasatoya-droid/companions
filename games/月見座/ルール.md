# ルール（黒子が最初の口上で読み上げること。楽屋の壁にも貼ってある）

## 小屋

閉じた芝居小屋「月見座」。舞台、客席、花道、楽屋（七つの鏡台）、奈落（舞台の下）。表の木戸は外から閉じられている。
天井のスピーカーから**黒子**が話す。黒子は姿を見せない。ルールを聞かれたら、この紙の文言どおりにだけ答える。

## 幕

幕は**五つまで**。一つの幕は、次の順に進む。

1. **口上**：黒子が、その幕の**お題**を読み上げる
2. **楽屋**：一人**二回**行動できる。誰か一人と楽屋で話す（面を見せる、約束する、形見の相談をする）。話は二人きりで、ほかの者には聞こえない
3. **評定**：全員が舞台に上がり、くじで決めた順に、一人ずつ話す。**二周**する
4. **札入れ**：一人一枚、札に**名前を一つ**書いて、箱に入れる。自分の名前を書いてもよい。ほかの者の札を見てはならない
5. **開票**：黒子が、名前ごとの**数だけ**を読み上げる。誰が誰の名前を書いたかは読み上げない
6. **退場**：退場する者が奈落へ下りる。黒子が、その者の**面**を披露する

## 数え方

1. 自分の名前を書いた札は、数えない
2. 書かれた数が最も多い者が、退場する。最も多い者が並んだら、並んだ全員が退場する
3. 最も多い数が零なら、その幕は誰も退場しない
4. 生き残りが一人になったら、その者が生還する
5. 生き残りが二人の幕で、誰も退場しなければ、二人とも生還する
6. 第五幕が終わったとき、生き残りが三人以上なら、全員が退場する。二人以下なら、その者が生還する

## 面

七つの箱に、次の七枚が一枚ずつ入っている。誰がどの面かは、自分の箱を開けた者しか知らない。

| 面 | 枚数 | 力 |
|---|---|---|
| **翁**（おきな） | 1 | 自分が書いた札は、二つに数える |
| **小面**（こおもて） | 1 | 自分の名前が書かれた数は、一つ少なく数える |
| **般若**（はんにゃ） | 1 | 退場するとき、黒子がその幕で自分の名前を書いた者を耳打ちする。その中から一人を選び、道連れにする。道連れにされた者も退場する（道連れは一幕に一人まで） |
| **天狗**（てんぐ） | 1 | 一度だけ、札を二枚書ける。名前は別々の二人にする。使えば、開票のとき黒子が「天狗が二枚書いた」と告げる |
| **狐**（きつね） | 1 | 三回まで（一幕に一回まで）、札入れのあと開票の前に、一人がだれの名前を書いたかを黒子から聞ける。使えば、開票のとき黒子が「狐が耳をすませた」と告げる |
| **素面**（すめん） | 2 | 何の力もない |

- 面は、箱ごと相手に見せられる。**見せた面は偽れない**
- 口で名乗る面は、本当でも嘘でもよい
- 退場した者の面は、黒子が皆に披露する
- 面の力は、退場するまで、毎幕かならず働く（使うかどうかを選べるのは、天狗と狐だけ）

## 形見

- 退場した者は、奈落へ下りる前に、自分の面を**生き残りの一人に形見として渡せる**。渡さなくてもよい
- 黒子は「形見が渡された」か「渡されなかった」かだけを告げる。誰に渡ったかは告げない
- 形見を受け取った者は、**次の幕から**、自分の面と形見の面の**両方の力**を持つ。天狗と狐は、残りの回数ごと渡る
- 道連れにされた者も、形見を渡せる

## お題

お題の札は六枚。一幕ごとに一枚を引き、口上で読む。引いた札は戻さない（五幕なので、一枚は使われない）。

| お題 | 枚数 | この幕だけのルール |
|---|---|---|
| **平常** | 2 | 変わりなし |
| **公開札** | 1 | 開票のとき、誰が誰の名前を書いたかも読み上げる |
| **二人札** | 1 | 最も多い者に加えて、二番目に多い者も退場する。二番目が並んだら並んだ全員。二番目が零なら、二番目はなし |
| **逆さ札** | 1 | 最も多い者ではなく、**書かれた数が最も少ない者が退場する**。並んだら並んだ全員。数え方の3は使わない |
| **黙り札** | 1 | この幕は楽屋がない。口上のあと、すぐ評定 |

- 生き残りが二人の幕では、お題は引かない（平常）

## 掟

1. 他人に手を出した者は、その場で退場する
2. 嘘をついてはならない、という掟はない
3. 札を書くのは自分の手で。他人の札を書いたり、見たりしてはならない（狐の力のほかに）
4. ルールに書かれていないことは、禁じられていない
