# 楔国（くさびのくに）

王国暦812年。列強に挟まれた山の小国ノルヴァで、世界最大級の導石の鉱脈「白脈」が見つかった。国王は狩りの事故で亡くなり、十五歳の女王アデーレが即位した。議会は摂政をめぐって割れている。
瀬島は宰相として、割れた議会をまとめ、四つの列強をあしらい、**30年後までノルヴァの独立を保つ**。

- ジャンル：政治と外交の長期シミュレーション（帝国主義の時代に似た架空の世界、魔法＝体系化された術式）
- 人数：一人（瀬島＝宰相）。GM＝Claude。列強・国内の人物はすべてGMが動かす
- 長さ：**1ターン＝1週**。30年（約1,560週）。静かな週はまとめて進める
- 列強の動かし方：国ごとに派閥と首脳の性格を細かく決め、月に一度の閣議で、派閥の損得の綱引きから方針を確率で決める（`gm/楔国.py`）
- 瀬島の字：**聴**（乱数で決めた。[ルール](ルール.md#字)）

## GMの約束（Claude 向け）

1. **列強の方針は `gm/楔国.py` で決める。** 毎週の始めに `進める` を振り、確率表ごと判断記録に写す。あとから変えない
2. **列強は本気で国益を追う。** 甘くしない。瀬島を特別扱いしない。いい話も悪い話も、派閥の損得から来る
3. **列強は一枚岩ではない。** 使節の言葉には、本国の派閥の綱引きがにじむ。どの派閥かは、字か諜報で探るまで名指ししない
4. **提案の受け入れ・議会の採決・事件は、方針表の式と乱数で決める。** 確率と理由は、振る前に判断記録に書く
5. **人物は自分の本音で動く。** 党首は会談のたびに自分の用件を持ってくる。約束を破られたら覚えている
6. **ルールは文言どおり。** 数字は正直に動かす。公開してよい数字は国勢表に載せる
7. **gm/ の中身を、会話・ログ・公開ファイルに漏らさない。** 列強の認識・派閥の重み・密約・人物の秘密・まだ目覚めていない字
8. **会談はひと続きの会話。** 一往復で一回と数えない。相手は聞かれたことに全部は答えない
9. **瀬島の返答のあとの、相手の再返答を省略・要約しない。** 受け止め方と返事を「」の台詞としぐさで書く。数字の動きは新聞・報告・台詞で見せ、事務的な「判定」の箇条書きで済ませない。乱数を振る合図は書かない（812夏2、瀬島の指摘）
10. **宰相が内々に話したことは、ひとりでに新聞に出ない。** 外に出るのは、①政府が発表したとき、②相手が自分の得のために口外したとき（公使が本国向けに、党首が党内向けに、など。その動機を書く）、③漏れの乱数で漏れたとき（判断記録に確率を先に書く）だけ。新聞で数字の動きを見せるときも、この三つのどれかに当てはまる話だけを使う（812冬8、瀬島の指摘）
11. **年に一度、進め方を見直す。** 年越しの前後に、その年の指摘と抜けを [見直し.md](見直し.md) にまとめ、直すことを決めて README・方針表に入れる（813春2、瀬島の頼み）

## 進め方

- 始め：README → ルール → 世界 → 登場人物 → 国勢表 → 瀬島の手元 → 最新のログ → gm/ を全部読む（`python 楔国.py 見る` も）
- 一週ごとに：①`進める 1`（判断記録へ）→ ②新聞と報告を伝える → ③瀬島の行動3つを会話で → ④判定（`記す`・`返事`）→ ⑤国勢表・ログを書く
- 4週ごとにお金を回す。秋の会期で予算
- 静かな週は、瀬島の「当面の指示」で `進める N`（最大8週）。要求・通牒・採決・事件が出たらそこで止める
- 1回の会話で、数週〜数か月くらい
- 終わり：国勢表・手元・ログ・gm/状態.json・gm/判断記録.md を更新し、コミットして push
