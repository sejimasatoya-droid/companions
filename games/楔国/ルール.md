# ルール（公開）

## 目的
- **王国暦842年 春（30年後）まで、ノルヴァの独立を保つ**。これが最低線
- 次のどれかになったら、そこで負け
  - 他国の**保護国**になる（保護条約を受ける、首都を占領されたまま講和する）
  - **主権が40を下回ったまま**30年目を迎える
  - **領土が70を下回る**
- 結末の段

| 段 | 条件（842年春） |
|---|---|
| 独立を失った | 上の負け |
| 名ばかりの独立 | 主権 40〜69 |
| 自立した国 | 主権 70 以上、領土 100 |
| 列強の一角 | 主権 90 以上、近代化 70 以上、兵力 40 以上 |

- 宰相の座を失っても、ゲームは終わらない。国は瀬島抜きで進み（GMが「何もしない」打ち方で動かす）、瀬島は野に下って返り咲きを狙う

## 一週の流れ（1ターン＝1週）
1. **週の始め**：新聞と報告。列強の使節の動き、要求・通牒、議会の予定、国内の出来事。数字は [国勢表](国勢表.md)
2. **宰相の一週**：**行動を3つ**とる（下の表）。会談は、一人とのひと続きの会話。一往復では終わらせない
3. **週の終わり**：判定。数字を動かし、国勢表とログを書く

| 行動 | 中身 |
|---|---|
| **会談** | 一人と会う（国内の要人、使節、女王）。提案・取引・説得・探り |
| **議会** | 党首と根回し、演説、法案を出す、採決にかける |
| **政策** | 省への命令。予算の付け替え、事業の開始、法令、任免 |
| **諜報** | 外務省・陸軍の情報部への命令。一つの問いを調べさせる（1〜4週かかる） |
| **女王** | 女王と過ごす。進講・相談・同席。女王の信頼が動く |

- 何も起きない週は、「当面の指示」を決めて**まとめて進めて**よい（最大8週）。要求・通牒・採決・事件が来たら、そこで止める

## 国勢（数字）
| 数字 | 意味 | 始め |
|---|---|---|
| 国庫 | 手元の金（M） | 12 |
| 債務 | 国債の残り（M）。利払いは年 債務×5% | 180 |
| 兵力 | 陸軍の力（0〜100。列強の陸軍は80〜100相当） | 12 |
| 要塞 | 国境の要塞（0〜100） | 5 |
| 近代化 | 工業・鉄道・教育・術式・行政の平均（0〜100） | 25 |
| 安定 | 国内のまとまり（0〜100） | 48 |
| 主権 | 外国に譲らずに決められる範囲（0〜100） | 100 |
| 領土 | 812年の領土を100とする | 100 |
| 守り | **（兵力×0.6＋要塞×0.5＋10）÷100**。山国の地の利で10 | .20 |
| 傾き | 列強それぞれへのノルヴァの傾き（−100〜100）。列強は、これを少し遅れて見る | |
| 党の支持 | 各党の、宰相への支持（0〜100） | |
| 女王の信頼 | 女王の、宰相への信頼（0〜100） | 50 |

## お金（4週に一度）
- 入り：**4.0＋近代化×0.02**（M／4週）＋鉱山の取り分
- 出：**3.6＋債務×0.004**（M／4週）。軍・役所・利払いの決まった費用
- 余りを、兵力・要塞・近代化（分野ごと）・その他の事業に振る

| 買い物 | 値段 |
|---|---|
| 兵力 +1 | 2M ÷（1−兵力/60） |
| 要塞 +1 | 3M ÷（1−要塞/50） |
| 近代化の一分野 +5（平均 +1） | 6M ÷（1−近代化/90） |
| 国債（借りる） | セレス・グラウ・オルネアの銀行から。貸した国への傾き +2〜5、条件は交渉 |

- 予算は秋の会期で通す。通らなければ、前の年の予算のまま（新しい事業は始められない）

## 議会
- 200議席、過半数101で通る。党ごとにまとまって投票する（無所属は3つの塊で）
- 党が賛成する確率＝**支持÷100＋その法案の損得**（−.4〜＋.4。党の立場からGMが決め、採決の前に判断記録に書く）
- 宰相への**不信任案**は、反対の党が合わせて101議席を超えそうなら出される。通れば、宰相は辞める（女王か摂政が引き止める道はある）
- 演説・根回しで、党の支持は動く。約束を破れば大きく下がる

## 外交
- 列強は、月に一度ほどの閣議で方針を見直す。国の中の派閥の綱引きで決まる（中身は見えない。使節の言葉と新聞から読む）
- 使節が持ってくるもの

| 来るもの | 中身 | 期限 |
|---|---|---|
| 申し出 | 借款・利権・友好・保障の話 | なし |
| **要求** | 具体的な一項目（利権・権利・人事など） | 4週 |
| **最後通牒** | 拒めば兵を動かすという要求 | 2週 |

- 期限までに返事をしなければ、拒んだとみなす
- 要求をのむと主権が少し下がり（−1）、その国への傾きと関係が上がる。最後通牒をのむと主権が大きく下がる（−12）
- 瀬島から持ちかけられるもの：通商条約、借款、利権、中立宣言、保障条約（第三国に守ってもらう）、同盟、不可侵、秘密協定、国際会議の提唱
- 相手が受けるかどうかは、相手の国の派閥の損得と、会談の出来で決まる

## 白脈（鉱山）
| 道 | 中身 | 掘れるまで | 取り分（4週ごと） |
|---|---|---|---|
| 一国に利権 | その国の資本で掘る | 2年 | 1.0M。その国への傾き +25 |
| 共同（二国以上） | 交渉で比率を決める | 2年 | 1.2M。各国への傾き +12 |
| 国の手で（カール鉱業） | 30Mを2年かけて出す | 2年 | 2.2M。近代化 +5 |

- 掘れるようになると、列強の関心が一段上がる

## 戦
- 侵攻されると、毎週、首都が落ちるかを判定する：**落ちる確率＝0.14−0.20×守り（最小.01）**。大戦中なら×0.7、他国の援軍が着いていればさらに×0.5
- 他国は、侵攻があった週に介入するかどうかを決める。保障条約・同盟・侵攻した国との敵対で、介入しやすくなる。援軍は3〜6週で着く
- 援軍が着いたら、侵攻した国は引くか、大戦にするかを選ぶ
- 援軍なしで首都が落ちたら、保護国にされる（負け）。援軍なしで16週持ちこたえたら、講和（領土−10、主権−10）
- **大戦**：列強どうしの大きな戦。中立を宣言していても、通り道を求められることがある。占領した国が講和で勝てば併合、負ければノルヴァは戻る
- 講和会議では、勝った国が弱い国の領土を削ろうとする

## 国内の危機
- 安定が15を下回って3か月続くと**内乱**。列強が「秩序の回復」を口実に兵を入れられるようになる
- ストライキ・暴動・政変・暗殺の企ては、数字と人物の動きから起きる（GMが表と乱数で）

## 字
- 字持ちは、漢字一字の異能を持つ。体系化された術式とは別のもので、学んでも身につかない
- **回数制**：字ごとに年の回数が決まっている（年は春第1週で戻る）。一週に一回まで
- 字が使われると、同じ部屋にいる字持ちには「字が動いた気配」がわかる。どの字かはわからない

### 瀬島の字：**聴**（ちょう）
> 会談の相手の、いちばん重い関心事を二つ、重さの順に聞き取る。
- 回数：**年4回**
- 国内の人物なら、その人の本音の優先順位の上から二つがわかる（例：「土地改革を止めたい」＞「ルドヴィク公を摂政に」）
- 列強の使節なら、**その国の派閥のうち、いまいちばん重い二つと、それぞれがノルヴァにいちばん望むこと**がわかる。使節自身の本音の一番も、一つだけ聞こえる

### 字の目録（この世界に現れる字）
> 812年の始めに、ここから乱数で瀬島の字を選んだ。ほかの字持ちも、この中のどれかを持つ。

## 判定
- 確率で決めるものは、GMが乱数（0〜1）を振って、値が確率より小さければ成功とする。確率は振る前に判断記録に書く
- 会談の出来は、話の中身でGMが −.2〜＋.2 をつける。根拠（相手の関心に触れたか、約束の重さ、嘘の有無）を判断記録に書く
