# 進め方の見直し

年に一度（年越しの前後）、GMと瀬島で進め方を見直す。直したことは README・方針表に入れ、ここに一行ずつ残す。

## 812年の見直し（813春第2週）

### 812年に瀬島から指摘されて直したこと
| 時期 | 指摘 | 直したこと |
|---|---|---|
| 812春13 | 安定の表と裏がずれている | 4週の締めで安定の戻り・傾きの薄れ・主権の戻りを回す。国勢表は本当の値 |
| 812夏2 | 返答のあとの相手の返事が要約される、事務的 | GMの約束9（台詞としぐさで書く。判定の箇条書きにしない） |
| 812冬7 | ルドヴィク公の借金は借り換え済み | 聴の中身を直した |
| 812冬8 | 宰相の内々の話が新聞に漏れすぎ | GMの約束10（発表・相手の口外・漏れの乱数だけ） |
| 812冬8 | ヤドヴィガの字を表に書いた | 隠し情報の漏れ。取り消した |

### GMの側で見つけた抜け（812年）
- 侍従長を『ホルスト』と書いた（ホルストは国民党）→ 侍従長グレーフェを登場人物に足した
- `返事 オルネア 受諾` の効き目（安定 −2・主権 −1）を表に出し忘れた → 返事のあとは状態の差分を必ず見る
- 4週の締めで主権の戻り（+0.04）を冬第9・13週に回し忘れた → 813春2に足した（99→99.08）。戻る先の −0.25×(100−主権) も入れる
- 年越しの週を『冬第14週』と書いた（正しくは冬第13週）
- 国勢表の党の支持が冬のあいだ更新されていなかった → 813春2に更新

### 813年から変えること
1. **人物の話を書く前に、手元と判断記録をその人の名で引く**（借金・約束・知っていること）。聴の中身もそれに合わせる
2. **`返事` のあとは状態の差分を見て、安定・主権・関係の動きを新聞か報告で見せる**
3. **4週の締めの週を先に並べておく**：813年は 春4・春8・春12・夏3・夏7・夏11・秋2・秋6・秋10・冬1・冬5・冬9・冬13（週55から4週ごと）
4. **年の終わりにやること**：共同研究の術式 +0.6、女王の読を3回に、鉱山の月、留学生、予算の新しい年の出、この見直し
5. **党の支持は、動いた週に国勢表の議会の表を直す**
6. ヒントは表一つと短い前置きまで
