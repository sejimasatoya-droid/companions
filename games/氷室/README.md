# 氷室（デスゲーム TRPG・第四作）

雪に閉ざされた山の古い旅館「氷室荘」。8人が閉じ込められている。
暖を取れるのは、各自が持つ**炭**だけ。毎晩、雪が深くなる。夜明けに、**炭がいちばん少ない者が、地下の氷室へ移される**。
五日目の朝、雪上車が来る。席は二つ。

澪標の反省（誓約と能力がほとんど働かなかった）を受けて、誓約と能力を作り直した。作り直しの理由と約束は [遊戯集/誓約と能力.md](../遊戯集/誓約と能力.md)（GM専用）に書いた。

- 難易度：高。**毎日一人が落ちる**（8人 → 終着に4人 → 出られるのは多くて2人）
- 複雑さ：毎日の三層の遊戯 ＋ 隠れた番頭（運営側）＋ 告発 ＋ **毎晩の日課がある誓約** ＋ **三回使えて、使うと放送される能力** ＋ 遺品の競り ＋ 隠された炭の枚数
- トーン：緊張感重視。脱落は重く扱うが、描写は控えめ
- オリジナル作品
- **結果（2026-11-24）**：瀬島は第2日の夕、雪見の競りの二の箱で白石と4が並び、くじで外れて4を払い、炭0で脱落した
- **反省**：遊戯の中で炭の多さが効きすぎた（多く持つ者だけが強気に書けた）。第五作から、遊戯は「持ち札」で戦う（[遊戯集/README.md](../遊戯集/README.md) の約束7）

## GMの約束（Claude 向け）

澪標の約束を引き継ぎ、11〜13を足した。

1. **AIの判断は方針表と乱数で決める。** 同時に選ぶ場面・取引への返事・投票では、`gm/方針表.md` からその人物の確率を読み、状況の補正（±0.2まで）を書いてから乱数を振る。状況・確率・出目を `gm/判断記録.md` に残す
2. **判断は瀬島が答える前に決めて記録する**
3. **AIは本気で勝ちに来る。** リードしている者は削る。約束は自分に得なときだけ守る。最終日は裏切りが基本
4. **秘密は簡単に明かさない。** 本心・誓約・能力を話すのは、(a) 決定的な証拠を突きつけられた、(b) 話すことがその人物の得になる、のどちらかのときだけ。嘘の誓約・嘘の能力を語ってよい
5. **ヒントを出さない。** 遊戯の深い手を、NPCの口を借りて教えない。NPCが深い手に気づくかどうかは、方針表の「深読み」で振る。気づいたNPCは、それを黙って使う
6. **抜け道を後から作らない。** 遊戯の隠しルールは gm/ゲーム一覧.md に最初から書いたものだけ
7. **運は乱数で決める。** コマンドと結果を判断記録に残す
8. **ルールの穴は合法。** 筋の通る読みなら認める
9. **会話中のファイル報告は最小限。** 一日の終わりにまとめて保存する
10. **公開ルールは、深い一文も同じ調子で読む。** 強調しない。質問には文言どおりにだけ答える
11. **誓約は毎日動かす。** NPCは、会話のたびに自分の誓約に沿った用件を一つ持ってくる（方針表の「誓約ごとの動き」）。日課を果たせるかを毎晩確かめ、放送する
12. **能力は温存させない。** 方針表の「能力の使い方」の確率で毎日振る。使わなかったときは理由を判断記録に書く。使われた能力は放送する
13. **紙や合図を受け取ったNPCは、まず「送り手の意図どおりに使う」読みを一番重く置く。** その読みのときに何をするかを先に決めてから振る（澪標の反省）

## 進め方

- 始め：README → ルール → 住人 → 瀬島の手元 → 最新のログ → gm/ を全部読む
- 1回の会話で1〜2日ぶん
- **昼の行動1回＝一人（または一か所）との一続きの会話。** 瀬島が話を切り上げるか、別の相手へ移るまでは同じ行動のまま、何往復でも話せる
- **遊戯の途中の時間（交換の時間など）では、一続きの会話を1回できる。** 昼の行動の回数には数えない
- **紙を渡すのは、一方通行（返事なし）なら行動に数えない。** 渡すところを見られるかは乱数
- 終わり：ログ・手元・gm/状態.md・gm/判断記録.md を更新し、コミットして push
