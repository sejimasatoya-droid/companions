# ルール（住人全員が知っていること）

## 旅館

山の古い旅館「氷室荘」。雪に閉ざされている。上から「物見の間」「客室」「広間」「帳場」「氷室（地下）」。
館内の放送（「帳場の声」）が、ルールと結果だけを告げる。質問には、ルールに書かれていることしか答えない。

## 炭

- 全員、**炭7枚**から始まる（誓約「生還」の者だけ9枚）。炭は黒い札で、各自の巾着に入っている
- **自分の枚数は自分しか知らない。** 見せるのも、嘘の枚数を言うのも自由
- 炭は手渡しで他人に譲れる（昼と夕方のあいだだけ）
- **炭が0枚になった者は、その場で氷室へ移される（脱落）**

## 一日の流れ

1. **朝**：広間で、夜明けの結果と、その日の遊戯が放送される。遺品の競り（下記）があれば、このとき
2. **昼**：自由時間。**行動は3回**（誰かと話す、どこかを調べる）
3. **夕**：遊戯を行う。そのあと**告発**の時間
4. **夜**：各自が客室で、夜に使う能力を使う。誓約の日課（下記）を確かめる
5. **夜明け**：**炭がいちばん少ない者が、氷室へ移される（脱落）**。同数で並んだら、くじで一人

全5日。第1日〜第4日の夜明けに一人ずつ移される。**第5日の朝に雪上車が来る**（終着）。

### 夜明けの放送で告げること
- 氷室へ移された者の名前、炭の枚数、**誓約と能力**
- 前の日のうちに**使われた能力の名前**（誰が使ったかは告げない。同じ能力が二度使われたら二度読む）
- **日課を果たした者の人数**（誰かは告げない）

## 番頭（ばんとう）

- 住人の中に、**運営の側の「番頭」が一人**紛れている。誰かは知らされない
- 番頭は、**毎朝、その日の遊戯の秘密を一つ、こっそり知らされる**
- 番頭は、雪上車で旅館を出れば勝ち
- 番頭も、ほかの者と同じく能力を一つ持つ

## 告発（毎日、夕方の遊戯のあと）

- 誰か一人が「〈誰それ〉は番頭だ」と告発できる（一日一回まで、早い者勝ち）
- 全員で賛成か反対を投じる（告発した者も、された者も）。**過半数が賛成**すれば、帳場がその者の正体を告げる
  - **番頭だった**：その者はすぐに氷室へ移される。賛成した者はそれぞれ炭+2
  - **住人だった**：告発した者は炭−2、賛成した者は−1。告発された者は何も失わない
- 投票の結果は、賛成と反対の数だけが放送される

## 誓約

- 客室の枕元に、**誓約の封筒**が置いてある。誓約は人によって違い、果たせばその人の勝ち。誰が何を持つかは知らされない
- 誓約には**日課**がある。毎晩、日課を果たした者は**炭+1**
- 名前を書く誓約は、**第1日の夜に、封筒の裏に名前を書いて封をする**。一度書いた名前は変えられない
- 誓約は次の八つ。番頭のほかは、七つが一つずつ七人に配られている（連れだけ二通）

| 誓約 | 日課（毎晩、果たせば炭+1） | 勝ち |
|---|---|---|
| **連れ**（二通） | 名前を書いた「連れ」の炭が、その日の朝より増えている | 雪上車で、あなたと連れが二人とも出る（あなただけなら半分の勝ち） |
| **仇** | 名前を書いた「仇」の炭が、その日の朝より減っている | 仇が雪上車で出ず、あなたが第5日の朝まで残る（あなたが出なくてもよい） |
| **長者** | あなたの炭が、その日の朝より2枚以上増えている | 第5日の朝に残っていて、その場の誰よりも多くの炭を持つ |
| **抜け駆け** | その日の遊戯で得た炭が、場の誰よりも多い（並びは果たせない） | 雪上車で出て、一緒に出た者より多くの炭を持っている（一人で出てもよい） |
| **語り部** | 夜に、一人の名前とその者の誓約を書いて、帳場に出す。当たれば炭+2、外れれば−1（出さなくてもよい） | 第5日の朝まで残り、それまでに二回以上当てている |
| **生還** | なし（最初の炭が9枚） | 雪上車で出る |
| **番頭** | なし | 雪上車で出る |

## 能力

- 枕元に、**能力のカード**が一枚ある。八人に一つずつ、八種類（番頭も持つ）
- **どれも三回まで、一日に一回まで**使える
- **使われたことは、夜明けの放送で全員に知らされる**（能力の名前だけ。誰が使ったかは知らされない）

| 能力 | いつ | 効果 |
|---|---|---|
| **鏡** | 夜 | 一人を選び、その者の誓約の封筒を読む（書かれた名前も） |
| **帳簿** | 夜 | 全員の今の炭の枚数を知る |
| **審問** | 昼・夕 | その日に誰かが自分に言ったことを一つ選ぶ。それが本当か嘘かを、帳場が耳打ちする（事実についての言葉に限る） |
| **聞き耳** | 遊戯の中 | 全員が同時に書く・出す場面で、自分が書く前に、一人が書いたもの・出したものを見る |
| **証文** | 昼・夕 | 二人で交わした約束を紙に書き、封じる。帳場がその約束を守らせる（破る行動はできなかったことになる）。約束にできるのは、炭の受け渡し・遊戯での選択・投票・封筒の交換だけ |
| **内通** | 朝 | その朝に番頭が知らされた秘密を、自分も知る |
| **封じ** | 夜 | 一人を選ぶ。その者は次の日、能力を使えない。選ばれた者には、朝「あなたの能力は封じられた」と知らされる |
| **差し押さえ** | 夜 | 一人を選び、その者の炭を一枚、自分のものにする |

## 遺品の競り

- 氷室へ移された者の能力のカードは、**残りの回数ごと**、次の朝に競りにかけられる
- 全員が同時に、紙に炭の枚数を書く。いちばん多く書いた者が、その枚数を帳場に払ってカードを受け取る（並んだら、くじ）。0なら受け取らない
- 能力を二枚持つことになってもよい。それぞれ一日に一回まで

## 終着（第5日）

- 第5日の朝、雪上車が来る。遊戯の内容はその朝に放送される
- 雪上車で出られなかった者は、旅館に残る

## 掟

1. 他の住人に暴力をふるってはならない。破った者はすぐに氷室へ移される
2. 他人の巾着から、手で炭を取ってはならない
3. 嘘をついてはならない、という掟はない
4. ルールに書かれていないことは、禁じられていない
