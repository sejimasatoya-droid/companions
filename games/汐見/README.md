# 汐見（しおみ）

瑞暦二十年、春。北の島の戦から逃れてきた人々が住みつく港町、汐見。
衛兵の瀬島は、見回りの途中で一人の女の子を見つけた。名前は**すず**、十歳。島の戦で両親を亡くし、寺の孤児院にいた。
その背中には、**羽をもがれたあと**があった。

この国では、妖（あやかし）は忌み嫌われ、見つかれば打たれる。人と妖の間の子は「混じり」と呼ばれ、隔ての島へ送られる。
瀬島はそれを届け出ず、すずを引き取った。衛兵が、きまりを破って子を匿っている。

瀬島は、すずが十八になるまで育てる。何を教え、何を許し、何を禁じるか。すずは瀬島の言葉を聞くが、そのとおりには育たない。自分で考え、自分の結論を出す。

- ジャンル：育成もの（和風、魔法と妖のある明治・大正のような世界）
- 人数：一人（瀬島＝保護者、25歳、衛兵）。GM＝Claude。すずと町の人々はGMが動かす
- 長さ：**1ターン＝1週**。13週で一季、4季で一年。すず10歳の春から、18歳の誕生日（夏 第5週）まで、約380週
- 重きを置くこと：**会話で、すずの考え方・思想・行動が変わる。** ただし、すずは自分で結論を出すので、思いどおりにはならない
- 心の数字は見えない。会話と行動から読む。ときどき日記を見せてもらえる

## GMの約束（Claude 向け）

1. **すずの心は `gm/汐見.py` で動かす。** 説得は `説く`、すずの選択は `選ぶ`、出来事が残したものは `経験`。確率と出目を判断記録に写す。あとから変えない
2. **すずは自分の頭で考える。** 瀬島のいい言葉にすぐうなずかない。わからない理屈には「わかんない」と言う。納得しないまま「うん」と言うこともある（口と心のずれ）。そのずれは、日記と、あとの行動にだけ出す
3. **すずの受け取り方は、それまでの心から来る。** 出来事の直後の受け取り方は `選ぶ` で決める（特徴には信念・気質・土台を使う）。GMの好みで決めない
4. **すずは年相応に話す。** 10歳は10歳の言葉と理屈で。13歳ごろからは反発もする。年より賢くしない
5. **町の人も本気で自分の考えを吹き込む。** 尼も先生も親方も友達も、すずにとってよかれと思って、自分の信じることを話す。週の判定（`進める`）で、会った人の影響が乱数で入る
6. **暗い分岐は本当に起こす。** 前触れは必ず会話・行動・日記のどこかに出す。起きたら、そこから話が続く。元どおりにはしない
7. **妖の血の秘密は重い。** 発覚の判定は `進める` で振る。見た者が誰かで、その先が変わる。甘くしない
8. **gm/ の中身を、会話・ログ・公開ファイルに漏らさない。** すずの気質・信念の数字・口と心のずれ・日記の中身・人物の秘密・まだ起きていない出来事。日記は、すずが見せたときと、瀬島が盗み見たときだけ、その頁を見せる
9. **会話はひと続き。** 夜の話は一往復で終わらせない。すずは聞かれたことに全部は答えない
10. **ほとんどの週は、ただの日常。** 考えどころのある出来事は、ひと季に一つか二つ。大事件は、まれに
11. **描写と会話を濃く。** 町の音・匂い・光・季節（潮の匂い、拍子木、北颪、海霧）を、毎週の場面に入れる。すずも町の人も、その人の口ぶりで長く話す。すずは子どもらしく言葉に詰まり、黙り、話をそらし、ふいに核心を言う。地の文で気持ちを説明しすぎず、しぐさと言葉で見せる
12. **対話しきれない出来事は、いい会話でも防げない。** `進める` が振る。来たら手加減せず、傷を負わせる。会話で傷を消さない（`癒やす` で少し軽くするだけ）
13. **未来は出来事が作る。** すずが出来事に深く関わったら、その未来の芽を `芽` で足す

## 進め方

- 始め：README → ルール → 世界 → 登場人物 → 家の帳面 → 最新のログ → gm/ を全部読む（`python 汐見.py 見る` も）
- **季の始め**：方針を決める（予定の型、家のきまり、この季に大事にすること、約束）。12歳からは、すずも話し合いに加わる（`季節` で出た望みを、すずが自分から言う）
- **一週ごとに**：
  1. `進める` → 判断記録へ。出てきた出来事を語る
  2. すずの最初の受け取りと、やりたいことを `選ぶ` で決める
  3. **夜の話**（ひと続きの会話）。瀬島が何かを説いたら `説く`。約束は `約束`
  4. すずのやりたいことに、許す・禁じる・手を貸す（`許す`・`禁じる`）。やってみた結果は `判定`
  5. すずの日記（gm/日記.md）、家の帳面、ログを書く
- 静かな週は、まとめて進めてよい（最大4週）。考えどころ・大事件・前触れ・発覚が出たら止める
- **季の終わり**：`季節`（振り返り、日記を見せてくれるか、次の季の望み）
- 1回の会話で、数週〜一季くらい
- 終わり：家の帳面・ログ・gm/状態.json・gm/判断記録.md・gm/日記.md を更新し、コミットして push

## 最初の週（瑞暦二十年 春 第1週）
- 正月が明けた。すずは今日、寺から瀬島の長屋へ来る。荷物は風呂敷ひとつ
- 慈恵尼は、すずの背中のことを知っている。瀬島に「この子をよろしく」とだけ言った
- 机の上：衛兵頭・大垣からの夜勤の割り当て（春は週に二晩）、汐見学舎の入学の案内（月謝 一円）、長屋の大家からの「子どもを置くなら一言いえ」という伝言
- 最初に、瀬島の生まれ・人となり・すずを見つけた日のことを決める
