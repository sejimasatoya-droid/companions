# 【GM専用】出来事表

> `進める` が週の出来事を一つ出す（`汐見.py` の EVENTS・SPINE）。GMはそれを、その週の予定と人の縁に合わせて肉づけする。

## 割合
- **日常**：ほぼ毎週。楽しい日、悲しい日、ただの日。考えどころはない。それでも心に効く（喜び→安心と居場所、うまくできた→有能感。`判定` を使う）
- **考えどころ**：週に .12（ひと季に一つ二つ）。価値がぶつかる。正解はない
- **節目**：決まった週に来る（下）
- **町の大事件**：週に .025（年に一度ほど）。嵐、火事、難破、祭りの喧嘩、米の値上がり。GMが選ぶ
- **対話しきれない出来事**：週に .018（八年でおよそ七つ）。死別、妖打ち、裏切り、力の暴走、瀬島の大怪我、災い、島の知らせ。傷を残し、未来の芽を植える（`FATES`）。いちばん重く語る
- 発覚・暗い分岐・力の目覚めは、別に振られて割り込む
- **どの出来事も未来の芽を植える**（`EVENT_FUT`）。すずが深く関わったら `芽` で足す

## 肉づけの約束
1. **すずの予定と縁から作る。** 学舎に通っていないなら、学舎の出来事は起こさない。縁の深い人ほど出てくる
2. **最初の受け取りは `選ぶ` で決める。** すずの信念を特徴に使う。受け取りは二つか三つ用意する。ひとつは、瀬島が望まない受け取りにする
3. **すずのやりたいことも `選ぶ`。** 「どうしたいか」を、すずが自分から言う（言えない子なら、態度で出す）
4. **残ったものは `経験`。** 強さは、軽い出来事で .1〜.2、重い出来事で .3〜.5
5. **考えどころは、すっきり終わらせない。** 正しいことをすると、何かを失う。失わないこともある（たまにでいい）
