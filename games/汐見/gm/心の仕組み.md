# 【GM専用】心の仕組み

> すずの心の動かし方。数はすべて `汐見.py` にある。ここは、GMが会話を判定に落とすときの手引き。

## 層と、変わる速さ
| 層 | 持ち方 | 速さ | 主に動かすもの |
|---|---|---|---|
| 気質 | 活発・敏感・自制・好奇・情（0〜1） | 誕生日に少し | 安心（→敏感）、自制力（→自制）、思いやり（→情） |
| 土台 | 安心・信用・自己価値・有能・自律・居場所・世界 | 週ごとに「落ち着きどころ」へ寄る | 応え・一貫（扱われ方の積み重ね）、判定の成否、許す／禁じる |
| 愛着 | 応え（困ったときに応えたか）、一貫（約束・きまりが一貫しているか） | ゆっくり | `応える`、`守る`／`破る` |
| 価値 | 8つの輪。向かい（4つ先）が引っぱり合う。全体の高さはならす | 週に少し | 会う人、行い、信じていること |
| 信念 | s（−1〜1、心）、口（瀬島に見せている向き）、根、元、新 | 会話一回で動く | `説く`、`経験`、会う人 |
| 道徳 | 1〜6。年相応の上限（10歳1.8、14歳3.0、18歳4.5）。放っておくと上限より0.6下で止まる | 一段上の理屈で上がる | 「なぜ？」を考えさせた会話 |
| 自制力 | 0〜1 | ゆっくり | 家のきまり（`記す きまり 0.6`）、安心、疲れ |
| 自己 | 探る・定める・定める_権威 | 12歳半から | 予定の幅、許す、自分の根の信念、言われただけの信念 |

**安心の落ち着きどころ** ＝ .15 ＋ .7×（.55×応え ＋ .45×一貫）− .3×（敏感 − .5）− .1×（.4 − 世界）。一度の優しさより、積み重ねが効く。

## 説く（瀬島が何かを伝えようとしたとき）
夜の話で、瀬島が「こう考えてほしい」と思うことを伝えたら、信念ごとに一回振る。一晩に二、三回まで。

`python 汐見.py 説く 信念 +|- 段階 理由 受け止め 問い 押し [--言行 1]`

| 引数 | つけ方 |
|---|---|
| 信念 | 辞書の名（`見る` に出る）。新しい考えなら名をつけて `--文 "…" --値 "公正+1,しきたり-0.5"` |
| 段階 | 瀬島の理屈の段階。罰がこわいから(1)／得だから(2)／いい子だと思われる・人が悲しむから(3)／きまりだから・世の中が回らないから(4)／みんなで決めた約束だから・相手にも同じ権利があるから(5)／誰にとっても正しいから(6) |
| 理由 | 0＝命令・断言だけ／1＝理由を話した／2＝すずの経験とつながる理由（すずが見たこと、したことを使った） |
| 受け止め | 1＝先にすずの気持ちを言葉にして受け止めた |
| 問い | 1＝答えを言わずに問いかけ、すずが自分で言葉にした |
| 押し | 0＝なし／1＝強く言った、何度も言った／2＝脅した、罰をちらつかせた、怒鳴った |
| 言行 | 1＝瀬島自身がそれと食い違うことをしているのを、すずが知っている（例：きまりを守れと言う。だが瀬島は、すずを匿ってきまりを破っている。すずがそれに気づいたら） |

結果：
- **受け入れた**：心が動く。口も同じ
- **口では従った**：すずは「うん」と言う。心は動かない。**会話ではうなずかせる。** ずれは日記と行動に出す
- **反発した**：逆へ少し動く。年頃なら、言い返す・黙りこむ
- **保留**：「……わかんない」。次の週以降に、腑に落ちることがある（`進める` が振る）
- **聞き流した**：心に残らない

## 選ぶ（すずが何かを選ぶ、受け取る）
出来事の受け取り、やりたいこと、とっさの行動。選択肢ごとに、効く特徴と係数を書く。係数は ±0.5〜2。

例：港で妖の子が石を投げられている
```
python 汐見.py 選ぶ "かばう:思いやり+1.5,b:弱い者+1,度胸+1,b:妖-1,b:隠す-1" "見ないふりで去る:安全+1,b:隠す+1.5,敏感+1" "一緒に石を拾う:しきたり+1,b:妖+1.5,b:島の子+0.5"
```
- 特徴：価値の名（−0.45）、気質の名（−0.5）、土台の名（−0.5）、気分（そのまま）、能力の名（/100−0.3）、`b:信念`（s）、`縁:人`（−0.3）、`思春`、`自制力`、`疲れ`
- 受け取りを決めたら、それが残したものを `経験` で入れる（今週のうちは、話でまだ動く）
- すずが実際にしたことは `行い` で入れる（自分のしたことから自分を知る）。初めての種類のことなら `--新しい 1`

## 許す・禁じる
- `許す --望み 0.8`（どれくらいやりたがっていたか）：自律と「探る」が上がる。結果は `判定`
- `禁じる 理由あり --望み 0.8`：自律が下がる。隠れてやるかを振る。隠れてやったら、GMが何をしたかを決め、発覚は別に振る

## 応える
すずが瀬島を必要とした場面（泣いている、怖がっている、打ち明けようとしている、熱を出した）では、必ずどれかを入れる。
- 良：気づいて、そばにいて、受け止めた／悪：叱った、茶化した、取り合わなかった／不在：夜勤・見回りでいなかった

## 判定
`判定 能力 難しさ`。ちょうどいい難しさ（能力±30）ほど、成否が有能感に効く。

## 日記
毎週、gm/日記.md に、すずの言葉で数行書く。
- 書くもの：その週の出来事、**本当の気持ち**（口と心のずれがある信念は、心のほうを書く）、瀬島のこと、隠していること
- 10歳はひらがなが多い。年とともに字と考えが育つ
- `偽り` が立っていたら、瀬島に見られてもいい頁を別に書く（本当の日記は別の場所）

## 対話しきれない出来事と傷
- 育て方と関わりなく、週に .018（八年でおよそ七つ）来る。`進める` が振る（`FATES`）
  - 死別（喪失）／妖打ちを目の前で見る（恐怖）／裏切り（裏切り）／力の暴走（罪。目覚めてから）／瀬島の大怪我（失う怖さ）／災い（恐怖）／島の知らせ（喪失）
- 来たら**傷**が残る。傷には強さと**あと**（底）がある。強さは週ごとに少しずつ癒える（安心と居場所が高いほど速い）が、あとより下にはならない
- 傷は、ときどき疼いて気分を揺らす。世界への信頼を少しずつ削る。**暗い分岐を押す**（喪失・罪→心を閉ざす、恐怖・裏切り→過激化、裏切り・罪→家出、など）
- `癒やす 傷 受け止め 問い`：傷に寄りそう夜の話。届けば少し軽くなる。届かないこともある。**消すことはできない**
- すずは最初から喪失の傷（.5、あと .2）を持っている
- GMが話の流れで傷を負わせたいときは `傷 種類 強さ`（喪失・恐怖・裏切り・罪・失う怖さ）
- 対話しきれない出来事は、**いい会話でも防げない。** 会話でできるのは、受け取り方と、そのあとをどう生きるかを一緒に考えることだけ

## 暗い分岐
`進める` が週ごとの危うさを出す。.03 を超えたら**前触れ**（GMは会話・行動・日記のどれかに兆しを出す）、その先は乱数で起きる。起きたら大きな出来事として語る。

## 発覚
`進める` が振る。浜・銭湯・目覚めた力・妖改めの疑いで上がる。見た者は乱数。見た者の反応は、その人物の秘密と `選ぶ` で決める。

## 力の目覚め
12歳から、強い気持ちが重なると目覚める（十八までにおよそ半分）。かたちは、目覚めたときの心で決まる（`POWERS`）。
- 癒やしの風（思いやり・喜び・安心）／嵐（怒り・力）／隠れ風（不安・隠す・安全）／凪（寂しさ・我慢・自制）／遠音（好奇・冒険・公正）／翼（自由・飛ぶ・自己価値）
- 目覚めた力は、最初は抑えられない。強い気持ちのたびに漏れる。葛葉なら、抑え方を教えられる

## 未来
- **未来は、出来事が作る。** どの出来事にも、関わる未来がある（`EVENT_FUT`、`FATES` の fut）。出来事が起きると、その芽が自動で植わる（軽 .05／中 .1／重 .15、対話しきれない出来事は .1〜.2）
- すずがその出来事に深く関わったら（自分で動いた、誰かを助けた、心を決めた）、GMが `芽 未来 0.1〜0.3` で足す。関わらなかったら足さない
- 通うだけで育つ芽は .2 まで。放っておくと少しずつ枯れる
- `終わり`：芽（5倍）、価値の合い（2.5倍）、得意な能力（自分の平均との差、0.8倍）、本人の憧れ（初期化で決めた、本人にもまだわからない好み）で選ぶ。**芽がいちばん重い**
