# 【GM専用】釣り合い

> `python 汐見.py 釣り合い --n 150 --seed 11`。四つの育て方を、それぞれ150人の「すず」（気質・憧れは毎回乱数）で8年回した。出来事は抽象化してある（週に .3 で価値のぶつかる選択、.05 でつらい出来事、.03 で出会いが芽を植える、.15 ですずが瀬島を必要とする、衛兵の夜勤で .2 は不在）。

| 育て方 | 中身 |
|---|---|
| 押しつけ | 理由を言わずに命じる、強く言う。望みの6割を禁じる。予定は瀬島が決める。困ったときに応えるのは3割 |
| 対話 | 理由を話す、受け止める、ときどき問いかける。禁じるのは2割5分（理由つき）。予定は半々 |
| 甘やかし | 受け止めるが、きまりがない。ほとんど禁じない。予定はすずが決める |
| 放任 | あまり話さない。応えない。約束を守らない |

| | 押しつけ | 対話 | 甘やかし | 放任 |
|---|---|---|---|---|
| 愛着 | 回避 .92 | 安定 .99 | 安定 .97 | 回避 .89 |
| 自己 | 模索（定まらない） | 達成 .7 | 模索が多い | 模索 |
| 道徳の段階（18歳） | 2.8 | 4.5 | 3.2 | 2.9 |
| 自制力 | .54 | .40 | .28 | .04 |
| 安心／自己価値 | .33／.20 | .76／.56 | .68／.39 | .24／.10 |
| 瀬島の望む価値との相関 | .39 | .63 | .48 | .06 |
| 口と心のずれ（信念の数） | 2.2 | 0 | 0.3 | 1.0 |
| 暗い分岐が一つ以上 | .74（言いなり .62、家出 .29） | 0 | 0 | .97（家出 .96、悪い仲間 .75、心を閉ざす .29） |
| 瀬島との関係 | 手紙だけが多い | そばにいる .9 | ときどき帰ってくる .9 | 縁が切れる .76 |
| 進路の種類 | 16 | 15 | 14 | 22 |

- 力の目覚めは、どの育て方でも十八までにおよそ半分。妖改めに知られるのは 1〜7%（ただし本番では、予定に浜・銭湯を入れるほど上がる）

## 見えたこと
- 押しつけは、すずの考えを**口では**揃えられるが、心は揃わない（相関 .39、ずれ 2.2）。自制力は一番高い。言いなりと家出が多い
- 対話でも、すずの価値観は瀬島の望みと**半分ほどしか重ならない**（相関 .63）。すずは自分の結論を出す
- 甘やかしは安心は高いが、自制力が低く、自分が定まらない
- 放任は、進路の幅がいちばん広い。ただ、ほぼ全員が家を出る

## まだ甘いところ（話し合って直したい）
- **「対話」が安全すぎる。** 釣り合いの「対話」は、毎回ちょうどいい段階の理由を話し、約束を85%守る理想の親。本番では段階の読み違い、夜勤、言行の食い違い（瀬島自身がきまりを破っている）が入るので、これよりは崩れる。それでも、暗い分岐が0なのは易しすぎるかもしれない
- **進路が医者・先生・学者に寄る。** 釣り合いでは平日を学舎にすることが多く、思いやりを吹き込んでいるため。本番では出来事で植わる芽で散らばるはず
- 簡略にしたところ：秘密が知られたあとの話、目覚めた力の暴走、兄の手紙、町の大事件は入っていない
