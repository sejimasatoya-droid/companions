# 【GM専用】釣り合い

> `python 汐見.py 釣り合い --n 150 --seed 11`。四つの育て方を、それぞれ150人の「すず」（気質・憧れは毎回乱数）で8年回した。出来事は抽象化してある（週に .3 で価値のぶつかる選択、.05 でつらい出来事、.03 で出会いが芽を植える、.15 ですずが瀬島を必要とする、衛兵の夜勤で .2 は不在）。**対話しきれない出来事**（週 .018）と傷、ふだんの出来事が植える芽は、本番と同じ仕組みで入っている。

| 育て方 | 中身 |
|---|---|
| 押しつけ | 理由を言わずに命じる、強く言う。望みの6割を禁じる。予定は瀬島が決める。困ったときに応えるのは3割 |
| 対話 | 理由を話す、受け止める、ときどき問いかける。禁じるのは2割5分（理由つき）。予定は半々 |
| 甘やかし | 受け止めるが、きまりがない。ほとんど禁じない。予定はすずが決める |
| 放任 | あまり話さない。応えない。約束を守らない |

| | 押しつけ | 対話 | 甘やかし | 放任 |
|---|---|---|---|---|
| 愛着 | 回避 .89 | 安定 .98 | 安定 .95 | 回避 .90 |
| 自己 | 模索（定まらない）1.0 | 達成 .72 | 模索 .81 | 模索 1.0 |
| 道徳の段階（18歳） | 2.8 | 4.5 | 3.2 | 2.9 |
| 自制力 | .54 | .40 | .28 | .04 |
| 安心／自己価値 | .34／.15 | .76／.56 | .68／.40 | .24／.08 |
| 瀬島の望む価値との相関 | .40 | .61 | .47 | .08 |
| 暗い分岐が一つ以上 | .97（言いなり .92、家出 .50、心を閉ざす .43、過激化 .21） | **.14**（過激化 .14） | .10（過激化 .10） | .99（家出 .97、悪い仲間 .84、心を閉ざす .74） |
| 瀬島との関係 | 手紙だけ .68 | そばにいる .93 | ときどき帰ってくる .91 | 縁が切れる .83 |
| 進路（いちばん多い道の割合／種類） | .19／20種 | .16／18種 | .31／16種 | .20／19種 |

- 力の目覚めは十八までに .48〜.60。妖改めに知られるのは 2〜5%（予定に浜・銭湯を入れるほど上がる）

## 見えたこと
- 押しつけは、すずの考えを**口では**揃えられるが、心は揃わない。言いなりと家出が多い
- 対話は、いちばん健やかに育つ。それでも**七人に一人は暗い分岐に入る**。原因はほとんど、対話しきれない出来事（妖打ちを見る、裏切られる）の傷から来る過激化。いい会話では防げない
- 対話でも、すずの価値観は瀬島の望みと**六割ほどしか重ならない**
- 進路は、出来事が植える芽でばらける。どの育て方でも、いちばん多い道で二割前後

## 調整の履歴
1. 最初は、安心が1か0に張りついた → 安心・信用・自律に「落ち着きどころ」（応え・一貫の積み重ね）を入れ、一回ごとの増減を小さくした
2. 価値が全部上がっていった → 価値の全体の高さをならす（何を先に立てるか、として扱う）
3. 進路が医者・学者・先生に寄った → 通うだけで育つ芽を .2 までにし、出来事が芽を植えるようにし、芽の重みを上げ、能力の重みを下げた
4. 対話だと暗い分岐が0だった → 対話しきれない出来事と傷を入れた。最初は強すぎて、対話でも過激化 .70 → 傷の効きを半分に

## まだ簡略なところ
- 秘密が知られたあとの話、目覚めた力の使い方、兄の手紙のあと、は入っていない（本番はGMが語り、`選ぶ` で決める）
- 釣り合いの「対話」は、毎回ちょうどいい段階で話す理想の親。本番では段階の読み違い、夜勤、言行の食い違い（瀬島自身がきまりを破っている）が入る
