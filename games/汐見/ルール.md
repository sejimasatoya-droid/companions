# ルール

## 目的
すずが十八になるまで育てる。勝ち負けはない。
十八の夏、すずは自分で道を選ぶ。どんな仕事をして、どう生きるか、瀬島とどういう間柄でいるか。その答えは、八年の暮らしと会話から出てくる。瀬島が決めることはできない。

## 暦
- **1ターン＝1週**。13週で一季（春・夏・秋・冬）、4季で一年。正月は春 第1週
- すずの誕生日は夏 第5週。瑞暦二十年の春に10歳で来て、二十七年の夏に18歳になる

## 一季の流れ
1. **季の始め：方針**
   - **予定の型**：毎週の基本の過ごし方（下）
   - **家のきまり**：門限、小遣い、手伝い、浜で泳いでいいか、銭湯に行っていいか、など
   - **この季に大事にすること**：瀬島の心づもり（例：友達を作らせたい、算術を伸ばしたい）
   - **約束**：すずとの約束（守れば信頼が、破れば疑いが積もる）
   - 12歳ごろからは、すずも話し合いに加わり、「次の季は〇〇に行きたい」と自分から言う。どこまで聞き入れるかで、すずの心が動く
2. **毎週**：出来事 → 夜の話 → すずのやりたいことへの返事（下）
3. **季の終わり：振り返り**。能力の伸び、季の出来事、すずのようすをまとめる。すずが日記を一頁見せてくれることがある
- 大きな出来事があったら、季の途中でも方針を見直してよい。ふだんの週に変えていいのは、予定の一枠まで

## 予定
一週を四つの枠に分ける。**平日**（いちばん長い。重みは二倍）、**放課後**二枠、**休日**一枠。

- どこで過ごすかで、**誰の考えに触れるか**が決まる。会う人は、それぞれ自分の信じることをすずに話す

## 能力（瀬島に見える）
**学力・体力・芸事・話術・手わざ・品格・度胸**（0〜100）。予定で伸びる。生まれつきの向き不向きがある。
- 出来事で何かに挑むときは、能力で判定する。ちょうどいい難しさのことをやり遂げると、すずは自信をつける。難しすぎて失敗が続くと、自信をなくす
- 能力は、十八の進路の選び方にも効く

## 毎週
1. **出来事**：ほとんどはただの日常（祭り、風邪、けんかと仲直り、雨の留守番）。ひと季に一つか二つ、考えさせられることが起きる。年の節目にも決まった出来事がある。町の大事件はまれ
2. **夜の話**：すずと一続きの会話をする。すずが何を思ったか、これからどうしたいかを話し合う。話すのは一晩に一度。ふだんの短いやりとりはいつでもいい
3. **すずのやりたいことへの返事**：
   - **許す**：すずは自分で決めたと感じる。うまくいけば自信に、失敗すれば学びになる
   - **禁じる**：すずを守れるが、自分で決める感覚は削れる。理由を話したかどうかで削れ方が違う。年が上がるほど、隠れてやることがある
   - **手を貸す**：一緒にやる。ただし、手を出しすぎると、すずのものではなくなる
4. 瀬島が夜勤や見回りで家にいない夜もある（衛兵の割り当て）

## すずの心の育ち方
数字は見えない。でも、心がどう育つかの仕組みは、ここに書いておく。

### 心の層
| 層 | 中身 | 何で変わるか |
|---|---|---|
| **気質** | 生まれつき。活発さ、敏感さ、こらえる力、好奇心、情の深さ | ほとんど変わらない。誕生日に、育ち方の分だけ少し動く |
| **心の土台** | 瀬島といて安心か、瀬島の言葉を信じられるか、自分に値打ちがあると思えるか、できると思えるか、自分で決めていると感じるか、居場所があるか、世界は安全か | 言葉より**扱われ方**。困ったときに応えたか、約束を守ったか、選ばせたか |
| **価値** | 自由・冒険・成功・力・安全・しきたり・思いやり・公正。輪に並んでいて、向かい合う価値は引っぱり合う | 人の影響、自分のしたこと、信じていること |
| **信念** | 「嘘はどんなときもいけない」のような、具体的な考え | 会話と出来事 |
| **道徳の理屈** | 罰をさける → 損と得 → よい子でいたい → きまりと秩序 → みんなで決めた約束 → 普遍の原理 | 年齢と、「なぜ？」を考えた経験 |
| **こらえる力** | 衝動をおさえて、先のために今を我慢する力 | 一貫したきまりと、安心 |
| **自分** | 「わたしはこういう人間だ」。いろいろ試したか、何かを自分のものとして選んだか | 13歳ごろから育つ |

### 話し合いで、信念はこう動く
- **信念には根がある。** 経験したこと／自分で考えたこと／納得したこと／言われたから（権威）／友達がそう言うから／怒られるのがこわいから。根が深いほど、崩れにくい
- **命令すると、口では従う。** 心が変わったかどうかは別。口と心がずれたままのことがある。そのずれは、あとの行動や日記にしか出てこない
- **「言われたから」の信念は、言った人を信じられなくなると、まとめて崩れる**
- **問いかけて、すず自身にたどり着かせた考えは、いちばん崩れにくい。** その場ではすぐ答えが出ず、何日かたってから腑に落ちることもある
- **すずの理屈より一段上の理屈が、いちばん届く。** 二段上だと、わからない。年より下の理屈は、子ども扱いされたと感じる
- **気持ちを受け止めてから話すと、聞いてもらいやすい**
- **瀬島の言うこととすることが食い違っていると、言葉の重みがなくなる**
- **怒っているとき、疲れているときは、届きにくい**
- **出来事の直後は、受け取り方がまだやわらかい。** 一週間たつと、経験として固まる
- **13歳ごろから**、押しつけには反発する。友達の言葉が重くなり、大人の言葉は軽くなる
- **すずは、自分のしたことから自分を知る。** 誰かをかばったら、「わたしは人をかばう人間だ」と思うようになる

## 日記
すずは日記をつけている。
- 季の終わりに、すずが一頁見せてくれることがある（瀬島への安心が高いほど。年頃になると減る）
- **盗み見ることはできる。** 気づかれると、安心も信用も大きく失う。すずは日記を隠すようになり、見られてもいい頁しか書かなくなるかもしれない

## 秘密
すずの背中の羽のあとは、誰にも知られてはいけない。銭湯、水遊び、病気で医者にかかること、着替え。見られる機会はどこにでもある。
見たのが誰かで、その先が変わる。妖改め方に知られれば、すずは隔ての島へ送られ、瀬島は罪に問われる。

## 暗い分岐
うまくいかないと、**家出・悪い仲間・過激化・心を閉ざす・言いなり**が起こりうる。必ず前触れがある。起きても終わりではないが、元どおりにはならない。そこから開ける未来もある。

## 十八の夏
すずは、それまでに芽生えた**未来の芽**の中から、自分の価値観で道を選ぶ。
- 芽は、通った場所、出会った人、やり遂げたことで植わり、育つ。放っておくと枯れる
- 道はたくさんある（学者、医者、産婆、尼、商人、船乗り、旅人、新聞記者、絵師、職人、衛兵、代言人、町会議員、組合の活動家、通訳、島へ帰る、寺を継ぐ……ほかにも）
- 同じ道でも、どう生きるかは、すずの価値と信念しだい
- 最後に、瀬島との間柄と、五年後・十年後の後日談を書く
