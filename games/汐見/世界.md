# 世界

## 時代
瑞暦（ずいれき）二十年。帝都では議会が開かれ、鉄道が延び、寺子屋が学舎に変わりつつある。港には蒸気船と帆船が並ぶ。洋装の役人と、着物の町人が同じ通りを歩く。

## 汐見（しおみ）
本州の北の端にある港町。人口はおよそ三万。北の島との船の行き来で栄えてきた。

| 町 | ようす |
|---|---|
| **本町** | 問屋と商家の通り。丸八はここ |
| **浜町** | 漁師と港の人夫の町。荒っぽいが、情に厚い |
| **寺町** | 浄光寺と孤児院、墓地、古道具屋の葛葉堂 |
| **島町** | 北の島から逃れてきた人々の町。長屋が密集し、島ことばが聞こえる |
| **山手** | 網元や役人の屋敷。学舎、町会所、妖改め方の出張所 |
| **番所** | 衛兵の詰所。瀬島の勤め先。長屋は番所から歩いて五分 |

- 汐見の人は、島の人を「島の者」と呼ぶ。仕事を奪う、汚い、と言う者もいる。かばう者もいる
- 町会は網元と大店の旦那衆が仕切っている。来年からは、町会の選挙に、税を納める男なら誰でも出られる

## 妖（あやかし）
- 人に化けて、あるいは人に混じって生きる、人でないもの。狐、狸、鳥、蛇、水の者……
- **妖は忌み嫌われ、見つかれば打たれる。** 子どもは「妖を見たら石を投げろ」と教わる。病や不作や火事が起きると、妖のしわざだと噂が立つ
- **妖改め方（あらためかた）** が、帝都の命で妖を取り締まる。届けのない者の正体を暴き、捕らえる。人と妖の間の子は**「混じり」**と呼ばれ、**隔ての島**へ送られる。島から戻った者はいない
- 妖をかくまった者も罪に問われる

## 術
- 生まれつき素質のある者が、修業して使う力。傷を癒やす、火を起こす、風を読む、遠くを見る
- 術は**登録制**。帝都の術師寮で学び、鑑札を受けた者だけが使える。**無登録の術は罪**。それでも町には、こっそり傷薬の術を使う婆さんがいる
- 術と妖の力は、似ているが違う、とされている。違いは誰にもはっきり説明できない

## 北の島
- 海峡の向こうの大きな島。山深く、昔から妖が多いと言われてきた
- 五年前に戦が起きた。帝都の「妖狩り」の軍と、島の山の民がぶつかり、島の内でも人どうしが争った。いまも山のほうでは小競り合いが続く
- 逃れてきた島の人々が、汐見の島町に住みついた

## 暮らしの値段
- 衛兵の給金は月十五円ほど。長屋の店賃と二人分の暮らしで、月に十円少し
- 学舎の月謝 一円、稽古代 月一円前後、銭湯 一回二銭、駄菓子 一銭
