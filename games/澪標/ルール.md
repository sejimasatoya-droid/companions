# ルール（住人全員が知っていること）

## 島

人工島「澪標」。海に沈みかけた、古い海洋研究所。上から順に「灯室」「居住層」「食堂」「研究層」「最下層」。
島の放送（「放送」）が、ルールと結果だけを告げる。質問には、ルールに書かれていることしか答えない。

## 貝

- 全員、**貝7枚**から始まる。貝は白い陶器の札で、各自の小袋に入っている
- **自分の枚数は自分しか知らない。** 見せるのも、嘘の枚数を言うのも自由
- 貝は手渡しで他人に譲れる（昼と夕方のあいだだけ）
- **貝が0枚になった者は、その場で最下層へ移される（脱落）**

## 一日の流れ

1. **朝**：食堂で、その日の遊戯が放送される
2. **昼**：自由時間。**行動は3回**（誰かと話す、どこかを調べる）
3. **夕**：遊戯を行う。そのあと**告発**の時間（下記）
4. **夜**：各自が個室で、**見回り**（貝を1枚払い、一人を選んで、その者の今の貝の枚数を知る）か、**休む**かを選ぶ。能力を使うのもこのとき（夜に使う能力のみ）
5. **夜明け**：**貝がいちばん少ない者が、最下層へ移される（脱落）**。同数で並んだら、くじで一人。移された者の名前と、その者の貝の枚数だけが放送される

全5日。第1日〜第4日の夜明けに一人ずつ移される。**第5日の朝に救命艇が来る**（終着）。

## 灯守（とうもり）

- 住人の中に、**運営の側の「灯守」が一人**紛れている。誰かは知らされない
- 灯守は、**毎朝、その日の遊戯の秘密を一つ、こっそり知らされる**
- 灯守は、救命艇で島を出れば勝ち
- 灯守には能力がない（下記）

## 告発（毎日、夕方の遊戯のあと）

- 誰か一人が「〈誰それ〉は灯守だ」と告発できる（一日一回まで、早い者勝ち）
- 全員で賛成か反対を投じる（告発した者も、された者も）。**過半数が賛成**すれば、放送がその者の正体を告げる
  - **灯守だった**：その者はすぐに最下層へ移される。賛成した者はそれぞれ貝+2
  - **住人だった**：告発した者は貝−2、賛成した者は−1。告発された者は何も失わない
- 賛成が過半数に届かなければ、何も起きない
- 投票の結果は、賛成と反対の数だけが放送される（誰がどちらに入れたかは放送されない）

## 誓約と能力

- 個室の枕元に、**誓約**の封筒と、**能力**のカードが置いてある
- 誓約は人によって違う。自分の誓約を果たせば、その人の勝ち。誓約の中身は、誰にも知らせなくてよい
- 能力は、**灯守を除く七人に、一つずつ**。どれも**一度だけ**使える。能力は次の七種類で、誰が何を持っているかは知らされない

| 能力 | 効果 |
|---|---|
| **潮見** | 朝の放送のあとに使う。その日に灯守が知らされた秘密を、自分も知る |
| **帳簿** | 夜に、見回りの代わりに使う。全員の今の貝の枚数を知る |
| **身代わり** | 夜明けに、自分が移されるはずだったときに使う。二番目に少ない者が代わりに移される。**使われたことは放送される**（誰が使ったかは放送されない） |
| **証文** | 二人で交わした約束を紙に書き、この能力で封じる。放送がその約束を守らせる（破る行動は、できなかったことになる）。約束にできるのは、貝の受け渡し・遊戯での選択・投票だけ |
| **透視** | 遊戯の中で使う。一人の隠し情報を一つ見る（札一枚、硬貨一枚の真贋、など） |
| **二票** | 告発の投票で、二票を投じる。賛成と反対の合計が人数を超えるので、**使われたことは誰にでもわかる** |
| **聞き耳** | 全員が同時に選ぶ場面のあとに使う。一人を選び、その者が何を選んだか（書いたか）を知る |

## 終着（第5日）

- 第5日の朝、救命艇が来る。遊戯の内容はその朝に放送される
- 救命艇に乗れなかった者は、島に残る

## 掟

1. 他の住人に暴力をふるってはならない。破った者はすぐに最下層へ移される
2. 他人の小袋から、手で貝を取ってはならない
3. 嘘をついてはならない、という掟はない
4. ルールに書かれていないことは、禁じられていない
