# ミリアム・ソーン　〔二年生・書庫寮／「つぎはぎのミリアム」〕

## 一、基本
| 項目 | 中身 |
|---|---|
| 立場 | 二年生・書庫寮。成績は学年で一、二を争う。どちらの会にも入っていない |
| 年・性別 | 十六歳・女 |
| 出身・身分 | 都の下町、運河沿いの質屋の孫。平民の給費生（ということになっている） |
| 家族 | 両親は幼いころ流行り病で死んだ。育ての祖母（質屋の女主人）は去年死んだ |
| 陣営 | どちらでもない。どちらの会も「金持ちの遊び」だと思っている |
| 住まい | 書庫寮の屋根裏に近い、窓の大きい一人部屋（狭い部屋が嫌いで、わざわざ選んだ） |
| 主人公への好感度（はじめ） | 0 |

## 二、姿と話し方
- 背が低く痩せている。茶色の髪を肩で切りそろえている。制服は肘と裾につぎが当たっているが、つぎの布だけ妙に上等。目の色が薄く、笑うと細くなる
- 声はやわらかく、よくしゃべる。一人称は「あたし」。相手を「あなた」、年下には「ぼうや」「お嬢ちゃん」。口癖は「あら、いいのよ」「損はさせないわ」「……それ、いくらだった？」
- 台詞の例
  - 機嫌のいいとき：「あなたに似合う贈り物を考えてたの。……当ててあげようか、甘いもの好きでしょ」
  - 怒ったとき：「あら、そう。じゃあ、あなたとはここまでね」（笑ったまま、二度と話しかけない）
  - 本音が漏れたとき：「お金があっても、人は川から引き上げられないのよ」

## 三、表の顔と本当の顔
- 表の顔：口がうまく、人当たりのいい、つぎはぎの制服の給費生。一年生や、いじめられている子、怪我をした鳥にだけは本当にやさしい。上級生や名家の子には、にこにこしながら一歩も近づかせない
- 本当の顔：祖母から、都の質屋と、名家に貸した金の証文の束を継いだ。学院の誰よりも金持ち。それを隠して、つぎはぎの制服を着ている。人を「貸せる相手」「貸してはいけない相手」で見てしまう、冷たい目を持っている
- 噂
  - 本当：「ミリアムは、夕方になると一人で裏の川べりを歩いている」
  - 本当：「ミリアムに贈り物を選ばせると、外れたことがない」
  - 嘘：「ミリアムは、下級生から金を巻き上げている」（逆に、困っている下級生にこっそり貸している。利子なしで）
  - 嘘：「ミリアムは、泳ぎの達人」（泳げない）

## 四、心のつくり
- 性格
  - **弱い者にだけ優しい**：運河沿いの下町で、弱い子が強い子に食い物にされるのを見て育った。自分も弱かった
  - **口がうまいが、根は冷たい**：質屋の帳場で、祖母の隣に座って、泣きつく客を何百人も見てきた。同情していたら店は潰れる、と祖母に教わった
- 好きなもの
  - **一人で歩くこと**：歩いているあいだは、誰の値踏みもしなくていい
  - **贈り物を選ぶこと**：人に贈り物をするときだけ、損得を考えずにいられる
- 嫌いなもの
  - **狭いところ**：質屋の地下の金庫に、子どものころ閉じこめられたことがある（借金取りが来た夜、祖母に隠された）
  - **貧しさ**：貧しさが、人を川に沈める
- 信念：「借りたものは返す。貸したものは取り立てる。それが、人と人がつながる一番正直なやり方」
- 許せないもの：弱い者から取り上げる者。返せないとわかっている相手に貸す者
- 思想
  - 身分：古い家の名なんて、証文の上ではただの借り手の名前
  - 導機と精霊：導機は安い。安いものは、貧しい者の味方。……ただし、工場主には一銭も貸さない
  - 霊と死者：死んだら終わり。……そう思わないと、川を歩けない
  - 学院：下町から抜け出すための梯子。知恵で登る
  - 国：国も、借金で回っている
- 弱み・矛盾
  - 水が怖いのに、毎日わざわざ川べりを歩く
  - 貧しさを憎んでいるのに、大金を持ちながら、つぎはぎの服を着ている
  - 弱い者にやさしいのに、それ以外の人は、帳簿の数字のようにしか見られない

## 五、望みと恐れ
- 短い目標：学年一番をとる。冬までに、書庫寮の一年生三人の借りを、こっそり片づけてやる
- 長い目標：……祖母の証文を、どうするか決めること。燃やすか、取り立てるか
- 恐れていること：水。金のことが知られて、人が自分を「金」として見るようになること

## 六、ふるまいの手引き（GM 用）
- 頼みごとへの構え：弱い立場の者の頼みは、だいたい聞く（ただし「貸し」として帳面につける。取り立てはしない）。強い立場の者の頼みは、笑顔で断る
- 怒らせること：弱い者をいじめる。金で人を買おうとする。水に誘う
- 喜ばせること：贈り物の相談をする。一緒に黙って歩く。借りたものをきちんと返す
- 断るときの理由：「あなたのためよ。あたしに借りを作ると、高くつくわよ」
- 戦い方：光の精霊（光導 得意）に好かれている。光で目をくらませて逃げる。水の精霊（癒導 普通）で傷を塞ぐ。……水の精霊に好かれているのに、水が怖い
- 日々の過ごし方：朝は書庫。昼は授業。夕方に裏の川べりを一人で歩く（水際からは三歩離れて）。夜は部屋で、祖母の帳簿を一冊ずつ読む
- 主人公との接点：夕方の川べり。小柄で、心の弱いエルスを「弱い子」と見て、やさしくする。……それが、エルスにとって心地いいかどうかは別

## 七、過去の記録
- 都の下町の運河沿い、質屋「ソーン屋」の孫として育った。両親は三つのとき流行り病で死んだ
- 祖母は質屋の傍ら、ひそかに名家に金を貸していた。家名を守るために、表に出せない借金をする古い家は多かった
- 八つのとき、運河で、近所の年下の子（ネッド）が溺れた。ミリアムは岸にいた。泳げなかった。人を呼びに走ると約束して、走ったが、間に合わなかった（**誰かと、守れなかった約束がある**：「すぐ戻るから」）。それから水が怖い（**水が怖い（泳げない）**）
- 十のとき、借金取りの夜、祖母に金庫へ隠された。一晩、暗い狭い金庫の中で過ごした
- 光と水の精霊に好かれていたので、学院の給費生試験に受かった
- 去年、祖母が死んだ。店と、証文の束を継いだ（**実は、莫大な財産を隠し持っている**）。店は、祖母の古い番頭に任せている

## 八、秘密（GM）
- 一層目：ミリアムのつぎはぎの布は、妙に上等
- 二層目：ミリアムは、都の質屋の跡取り。学院の誰よりも金を持っている
- 三層目（突飛：**実は、莫大な財産を隠し持っている**）：祖母の証文の束には、名家の借金の証文がある。ヴァルモン家（工場の火事のあとの立て直しの金）、ペンドルトン家、そして十七年前の「度胸試し」の名家の子の家のうち一つ（第二章以降、度胸試しの者を作るときにつなぐ）。証文を取り立てれば、家が一つ二つ傾く
- 川べりを歩くのは、ネッドを探すため。……死んだら終わりと言いながら、川にネッドの霊がいないかと、どこかで思っている。ネッドは運河で死んだので、学院の川にはいない（エルスが「ここにはいない」と言えば、何かが変わる）
