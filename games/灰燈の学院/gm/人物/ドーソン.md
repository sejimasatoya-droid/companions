# マルグリット・ドーソン　〔書庫の司書／「剣の司書」〕

## 一、基本
| 項目 | 中身 |
|---|---|
| 立場 | 学院の書庫の司書（書庫長の下で、書庫の実務を一手に担う） |
| 年・性別 | 三十四歳・女 |
| 出身・身分 | 表向き：都の郊外の、小さな商家の娘。本当：ドーソン子爵家の長女。家から勘当されている（二層目） |
| 家族 | 父（子爵、血統主義の議員）、弟（跡取り）。勘当されてから、一度も会っていない |
| 陣営 | どちらでもない。どちらの会の生徒にも、同じように本を貸し、同じように叱る |
| 住まい | 書庫棟の三階の、司書の小部屋。壁に、古い稽古用の剣が二本 |

## 二、姿と話し方
- 背が高く、姿勢がいい。濃い栗色の髪をうしろで一本の三つ編みにしている。袖をまくった腕に、細い筋肉。眼鏡はかけない（目がいい）。書庫で、重い本の山を軽々と運ぶ
- 声は明るく、はきはきしている。一人称は「わたし」。生徒を「〜さん」「〜くん」。口癖は「はい、次！」「静かに！　ここは書庫です」「家のことは聞かないで」
- 台詞の例
  - 機嫌のいいとき：「はい、次！　……あら、新入生ね。何が読みたいの？　お姉さんが一冊ずつ探してあげる」
  - 怒ったとき：「本を投げたわね。……表へ出なさい。剣の稽古の相手をしてあげる」
  - 本音が漏れたとき（夜の書庫で、独り言）：「……また聞こえる。誰？　誰なの。わたし、おかしくなったの？」

## 三、表の顔と本当の顔
- 表の顔：明るく、てきぱきした書庫の司書。誰とでもすぐ打ち解ける。学院の祭りや市場の人混みが大好き。休みの日は、演習場で剣の稽古をしている。小さな子ども（教師の子や、厨房の子）の前でだけ、本当に柔らかく笑う
- 本当の顔：書庫の奥で、ときどき「声」が聞こえる。精霊の声なのか、何なのか、わからない。気が触れたと思われるのが怖くて、誰にも言っていない。幽霊の話が大嫌いなのは、自分の聞いている声が、幽霊のものかもしれないから
- 噂
  - 本当：「ドーソンさんは、剣がめっぽう強い」
  - 本当：「ドーソンさんに家のことを聞くと、急に冷たくなる」
  - 嘘：「ドーソンさんは、昔、軍にいた」
  - 嘘：「ドーソンさんは、書庫長の娘」

## 四、心のつくり
- 性格
  - **誰とでもすぐ打ち解けるが、深い仲にはならない**：家を追い出されたとき、親友だと思っていた令嬢たちが、皆、手のひらを返した。それから、深い仲を作らない
  - **頑固。一度決めたら曲げない**：家を捨てると決めたときも、そうだった
- 好きなもの
  - **剣の稽古**：家では、娘が剣を握ることを許されなかった。こっそり兄の剣を振っていた
  - **人混み**：人混みの中にいれば、「声」が聞こえない
- 嫌いなもの
  - **幽霊の話**：自分の聞いている声が、幽霊のものだったら、と思うと怖い
  - **家のことを聞かれること**：勘当された家のこと
- 信念：「本は、身分を選ばない。誰にでも、同じことを教える」
- 許せないもの：本を、身分や家柄で読む者を選ぶこと。書庫の本を、一部の家の者だけのものにしようとする者
- 思想
  - 身分：子爵家の娘として生まれ、家を捨てた。血統主義の理屈は、家の中で嫌というほど聞いた
  - 導機と精霊：書庫に導灯を入れることには賛成（暗い書庫は本を傷める）。けれど、精霊石の導灯のそばにいると、声が大きくなる気がして、近寄れない
  - 霊と死者：……怖い
  - 学院：家を捨てた自分を拾ってくれた場所
  - 国：父のような議員が動かしている国は、信用しない
- 弱み・矛盾
  - 誰とでも打ち解けるのに、誰とも深い仲にならない
  - 精霊の声が聞こえる気がする（**精霊の声が、ときどき聞こえる気がする**）のに、それを「気の病」だと思って隠している
  - 子どもが好きなのに、自分の子は持てないと思っている（家を捨てたから、と）
  - 知恵は 25。書庫の司書なのに、本の中身はあまり読めていない。本を「探す」ことと「運ぶ」ことと「守る」ことが得意

## 五、望みと恐れ
- 短い目標：書庫に導灯を入れることを、書庫長に認めさせる（書庫長はずっと拒んでいる）
- 長い目標：いつか、孤児の子どもたちのための小さな書庫を、下町に開くこと
- 恐れていること：声のことが知られて、気が触れたと思われること。父の手の者が、自分を連れ戻しに来ること

## 六、ふるまいの手引き（GM 用）
- 頼みごとへの構え：本の頼みなら、何でも引き受ける。身分を問わない。子どもの頼みには、とくに弱い。幽霊や家にかかわる頼みは、ぴしゃりと断る
- 怒らせること：本を乱暴に扱う。家のことを聞く。幽霊の話をする
- 喜ばせること：剣の稽古の相手をする。祭りに一緒に行く。小さな子どもの話
- 断るときの理由：「あなたのためよ。わたしに深入りすると、わたしの家の面倒ごとが、あなたにも降りかかるかもしれないから」
- 戦い方：石の精霊（刻導 得意）にすさまじく好かれている。剣に刻導の紋を刻んで、刃を岩のように硬くする。光の精霊（光導 得意）で、相手の目をくらませる。剣の腕は、演習の教師モーンブレイが認めるほど
- 日々の過ごし方：朝から夕方まで書庫。昼休みに演習場で剣の稽古。夕方は都の市場の人混みへ（声から逃げるため）。夜、書庫の奥の声が大きくなる時間（真夜中）には、絶対に書庫にいない
- 主人公との接点：書庫で。エルスが本を探しに来れば、一冊ずつ探してくれる。エルスの影の精霊が、ドーソンの「何かに怯えている」気配に気づく。……そして、エルスには、ドーソンに聞こえている「声」の主が見えるかもしれない

## 七、過去の記録
- ドーソン子爵家の長女として生まれた。石と光の精霊に好かれていた。家は血統主義の家で、娘に求められたのは、よい家に嫁ぐことだけだった
- 十八のとき、父の決めた縁談を断り、平民の学者と駆け落ちしようとした。学者は、父の手の者に買収されて逃げた。家に連れ戻され、勘当された。親友だった令嬢たちは、皆、手のひらを返した
- 二十のとき、学院長に拾われて、書庫の下働きになった。家名を伏せ、商家の娘ということにしてもらった
- 二十五のころから、書庫の奥で、ときどき「声」が聞こえるようになった（**精霊の声が、ときどき聞こえる気がする**）。囁き声。誰かが、誰かを呼んでいる
- 書庫の手伝いに来る厨房の子どもたちに、字を教えている（**子どもが好き。子どもの前でだけ笑う**）

## 八、秘密（GM）
- 一層目：ドーソンさんは、本当は貴族の家の出らしい
- 二層目：ドーソン子爵家の長女。勘当されている。父は血統主義の議員
- 三層目：書庫の奥で聞こえる「声」は、精霊の声ではない。書庫の奥の「白紙の棚」（学院の謎 4）に閉じこめられた、修道院の古い写字僧の霊の声。写字僧は、二百年、禁書の写しを守り続けていて、それを読める者を呼んでいる。ドーソンの石の精霊への強い好かれ方（刻導 100）が、写字僧の声を拾わせている
- さらに：書庫長は、ドーソンが聞いている声に、気づいている（作り直しで、書庫長を決める）
