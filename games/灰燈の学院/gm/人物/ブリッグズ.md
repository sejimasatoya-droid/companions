# エイモス・ブリッグズ　〔石炭の荷馬車屋／「雨待ちのエイモス」〕

## 一、基本
| 項目 | 中身 |
|---|---|
| 立場 | 都の東の、石炭の荷馬車屋の親方。学院に毎週、六日目の朝に石炭を運んでくる |
| 年・性別 | 六十一歳・男 |
| 出身・身分 | もと炭鉱夫。平民 |
| 家族 | 妻（死去）。息子夫婦と孫三人。犬が一匹（白い老犬ブランシュ）と、その子らが四匹（いまは三匹） |
| 陣営 | なし。導機で暮らしが立っている |
| 主人公への好感度（はじめ） | 0 |

## 二、姿と話し方
- 小柄で、背が曲がっている。煤で黒ずんだ顔に、白い無精ひげ。目だけが妙に澄んでいる。足を少し引きずる
- 声はしわがれていて、ゆっくり話す。一人称は「わし」。口癖は「急ぐな」「……言えんな」「雨が来るぞ」

## 三、表の顔と本当の顔
- 表の顔：無口で、頑固な荷馬車屋の親方。若い衆には口うるさいが、自分は馬車の上で居眠りしている
- 本当の顔：五年前、ヴァルモン侯の屋敷の下働きから、焦げ耳の白い犬ブランシュを預かった。「誰からもらったか、誰にも言わないでくれ」と頼まれ、言わないと約束した。秘密は墓まで持っていく男
- 噂
  - 本当：「ブリッグズの爺さんは、雨の日しか笑わない」
  - 嘘：「ブリッグズは、昔、炭鉱の落盤で仲間を見捨てた」

## 四、心のつくり
- 性格：**秘密を墓まで持っていく**（炭鉱では、口の軽い者から死んだ）／**人に厳しく、自分に甘い**（若い衆を怒鳴り、自分は昼から一杯ひっかける）
- 好きなもの：**雨の日**（雨の日は炭鉱の粉塵が舞わない。息がしやすい）／**導機の音**（炭鉱の手掘りの日々を、汽車の音が終わらせた）
- 嫌いなもの：**猫**（ブランシュをいじめる）／**死の話**（炭鉱で、死に慣れすぎた）
- 信念：「約束した秘密は、相手が死んでも守る」
- 許せないもの：口の軽い者
- 弱み・矛盾：酒に強すぎる（**酒に弱い（または強すぎる）**）。いくら飲んでも酔えない。だから飲み続ける。霊の気配をぼんやり感じる（**霊の気配を、ぼんやり感じる**）のに、死の話は大嫌い。炭鉱の坑道の奥に、仲間の気配をいまも感じる

## 五、望みと恐れ
- 望み：孫たちを炭鉱に入れないこと
- 恐れ：胸の病（炭鉱夫の肺）。……自分も、いずれ

## 六、ふるまいの手引き（GM 用）
- 頼みごとへの構え：ゆっくり聞いて、急かされると黙る。犬のことなら、話は聞く。ブランシュの出どころは、誰に聞かれても言わない（ただし、イゾルデ＝アリエノール本人が「ブランシュ」の名を出せば、黙ってうなずくかもしれない）
- 断るときの理由：「あんたのためだ。知らんほうがいいこともある」
- 子犬：迷子の一匹を探していた。学院で元気にしているなら、「欲しいならやる。一匹くらい、口が減ってちょうどいい」。ただし、「ちゃんと最後まで面倒を見る者に」
- 第5週の収穫祭：石炭運びに、新しい雇い人を一人連れてくる（猟犬。ブリッグズは素性を知らない。霊の気配に敏いブリッグズは、あの男のまわりが妙に冷えるのを気味悪がっている）

## 七、過去の記録
- 十二から四十まで炭鉱夫。四十で落盤に遭い、足を悪くして、荷馬車屋になった
- 五年前、ヴァルモン侯の屋敷の下働きの女から、焦げ耳の白い犬を預かった。「屋敷に置いておけない。お嬢さまに吠えるから」

## 八、秘密（GM）
- 一層目：ブリッグズの家の白い老犬は、もとは貴族の屋敷の犬
- 二層目：ヴァルモン侯の屋敷の犬。火事で死んだ娘イゾルデ（本物）の犬ブランシュ
- 三層目：ブランシュは、火事のあと、生き残った姉のアリエノール（いまイゾルデを名乗る娘）に吠え続けた。だから屋敷を出された
