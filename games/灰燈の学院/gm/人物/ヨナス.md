# ブラザー・ヨナス　〔温室の林檎の木の幽霊／もと修道院の庭番〕

## 一、基本
| 項目 | 中身 |
|---|---|
| 立場 | 二百年前、沈黙の聖ベネディクタ修道院の庭番だった修道士の幽霊。温室の林檎の木の根もとにいる |
| 年・性別 | 死んだとき七十を越えていた・男 |
| 陣営 | なし |
| 主人公への好感度（はじめ） | 70（見える子。それだけで、孫のようにかわいい） |

## 二、姿と話し方
- 背の曲がった小柄な老修道士。灰色の修道服の裾が土で汚れている。歯の抜けた口でよく笑う。手に小さな木の鍬
- しわがれた声。一人称は「わし」。相手を「お主」「坊」と呼ぶ。口癖は「急がんでええ」「わしの木じゃ」

## 三、表の顔と本当の顔
- 表の顔：温室の林檎の木の根もとで、二百年、木の番をしているのんきな爺さん
- 本当の顔：修道院が封じた地下聖堂「沈黙の院」の三つの鍵の一つを、修道院長から預かって、林檎の木の根もとに埋めた者。鍵を渡すにふさわしい者を、二百年待っている

## 四、心のつくり
- 信念：「約束は、守っておる限り、枯れはせん」
- 好き：林檎の木、土いじり、坊（セドリック）の世話する手
- 嫌い：急かされること、木を乱暴に扱う者
- 弱み：鍵を渡す相手を見極める力に、自信がない（知恵 32）。人の心はよくわかる（心 93）

## 五、望みと恐れ
- 望み：鍵を、ふさわしい者に渡して、ようやく眠ること
- 恐れ：鍵が、修道院を奪った者たち（灰の環）の手に渡ること

## 六、ふるまいの手引き（GM 用）
- 鍵を渡す条件（ヨナスの中で）：林檎の木と、水の精霊との約束を大事にする者。二百年の約束を、急がずに守れる者。……エルスは水の精霊に好かれていない（癒導 37）。ヨナスは、そこを気にしている。セドリック（ルシアン）にも目をかけているが、セドリックにはヨナスが見えない
- 鍵の話は、エルスが通い続け、木を大事にするほど、少しずつ出てくる

## 七、過去の記録
- 修道院の庭番として、林檎の木を植えた。水の精霊と、枯らさない約束をした
- 修道院が召し上げられる前の夜、修道院長から、地下聖堂の三つの鍵の一つを預かった。林檎の木の根もとに埋め、その冬に死んだ

## 八、秘密（GM）
- 一層目：林檎の木の根もとに、大事なものが埋まっている
- 二層目：それは、修道院が封じた地下聖堂の鍵の一つ（学院の謎 7）
- 三層目：ヨナスは、二百年前、最初の精霊石を作った修道士たちの一人を知っている。その修道士の悔いの言葉を、覚えている
