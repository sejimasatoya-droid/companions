# 「猟犬」サイラス・ヴェン　〔灰の環の霊の狩り手／石炭運びの雇い人〕

## 一、基本
| 項目 | 中身 |
|---|---|
| 立場 | 灰の環の「狩り手」。死者の魂を探して数え、石に閉じこめる役の、下見をする者。収穫祭のころ、ブリッグズの荷馬車屋の新しい雇い人として学院に入りこむ |
| 年・性別 | 三十六歳・男 |
| 出身・身分 | 都の下町、運河沿いの貧民窟。母は南の大陸から来た洗濯女 |
| 家族 | 母（死去）。妹（導機の工場で働いている） |
| 陣営 | 灰の環（下の者）。ただし、環の上の者の顔は知らない |
| 主人公への好感度（はじめ） | 0 |

## 二、姿と話し方
- 痩せた中背。浅黒い肌。短く刈った黒髪に、白いものが混じる。右目に、真鍮の筒の片眼鏡（霊計。針の震えで、死者の魂の数を測る）。いつも厚手の外套を着ている（寒さが嫌い）。手袋を外さない
- 声は低く、丁寧で、抑揚がない。一人称は「私」。誰にでも「旦那」「お嬢さん」。口癖は「数えています」「覚えておきます」「……不公平ですな」

## 三、表の顔と本当の顔
- 表の顔：無口で几帳面な石炭運び。袋の積み方がやたらきれい
- 本当の顔：灰の環の狩り手。霊計で学院じゅうの死者の魂を数えている。そして、ふつうの者には見えない精霊が、生まれつき見える（**実は、精霊を見ることができる**）。石の中で精霊が苦しむのも、見えている
- 噂（ブリッグズの若い衆の）
  - 本当：「新入りは、川を見ると泳ぎたそうな顔をする」
  - 嘘：「新入りは、もと牢屋にいた」

## 四、心のつくり
- 性格：**几帳面で、物の置き場所が一つずれても気になる**（数を数える仕事にうってつけ）／**人の話を、驚くほどよく覚えている**（一度聞いた名と声は忘れない）
- 好きなもの：**川や湖で泳ぐこと**（運河で泳ぐのだけが、子どものころの楽しみ）／**機械の分解**（霊計を自分で直す）
- 嫌いなもの：**不公平**（下町の子は、精霊に好かれなければ一生煤の中。貴族の子は、好かれなくても学院へ行ける）／**寒さ**
- 信念：「灯は、生まれで分けられるべきではない」
- 許せないもの：生まれで人を数える者
- 思想：環が作ろうとしている「強い石」（霊石）が安く出回れば、下町にも灯が行き渡る、と信じている。……死者の魂を使うことに、目をつぶっている。精霊が見えるので、精霊石も霊石も、どちらも苦しんでいると知っている。それでも、生きている者の灯のほうが大事だと決めた
- 弱み・矛盾：不公平を憎みながら、死者の魂を数えて石にする仕事をしている。人に触れられるのが苦手（**人に触れられるのが苦手**）。母の国の言葉を話せる（**異国の言葉を一つ話せる**。南の大陸の言葉。モーンブレイが話せるのと同じ言葉）

## 五、望みと恐れ
- 望み：妹を工場から出すこと。下町に灯を
- 恐れ：環の上の者。自分が数えた魂が、どこへ行くのかを知ること

## 六、ふるまいの手引き（GM 用）
- 頼みごとへの構え：金と、不公平を正す話には乗る。貴族の頼みは丁寧に断る
- 断るときの理由：「旦那のためです。私に関わると、数えられますよ」
- 霊計：死者の魂の多いところで針が震える。エルスのまわりでは、死者の気配が濃すぎて針が振り切れる。イゾルデのまわりでは、石の中の精霊たちがざわつく（猟犬の目には、それが見える）
- 収穫祭の仕事：学院の霊の数を数える（礼拝堂のリリアン、書庫のマティアス、温室のヨナス、北の小部屋のアンセルム）。霊計を狂わせる子（エルス）と、石をざわつかせる子（イゾルデ）を見つけたら、クロフトに知らせる

## 七、過去の記録
- 運河沿いの貧民窟に生まれた。母は南の大陸の洗濯女。父は知らない
- 生まれつき、精霊が見えた。誰にも信じてもらえなかった。精霊には好かれなかった（識導 66、ほかもそこそこ）。給費生試験に落ちた
- 二十のとき、導機局の砕き場で働いた。そこで環の者に声をかけられ、精霊が見える目を買われた。霊計の使い方を教わった
- 妹は、いまも精霊石の工場で働いている

## 八、秘密（GM）
- 一層目：石炭運びの新入りは、片目に変な片眼鏡をかけている
- 二層目：灰の環の狩り手。霊計で、死者の魂を数えている
- 三層目（突飛：**実は、精霊を見ることができる**）：精霊が見える。石の中の精霊が苦しんでいるのも、霊石の中の魂が叫んでいるのも、見えている。見えていて、目をつぶっている
- 妹は、砕き場の隣の精霊石の工場で働いている。咳をしはじめている（石肺。ヘティの記録とつながる）
