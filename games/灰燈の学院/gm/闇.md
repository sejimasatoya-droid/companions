# 学院に潜む闇（GM。プレイヤーには見せない）

## 灰の環（はいのわ）
- **何者か**：王国の貴族と、王立導機局の一部の者がひそかにつくる結社。二百年の歴史がある
- **求めるもの**：**霊石**。精霊ではなく、**死者の魂**を石に閉じこめたもの。精霊石の十倍の力を出す。閉じこめられた魂は、石が燃え尽きるまで、苦しみ続ける
- **やり方**：
  - 死者の霊を「呼び寄せ」、刻導の紋で石に縛る。生者には霊が見えないので、霊のいる場所を「霊計」（ひそかに作られた導機）で探る
  - 霊を多く生むために、ときに人の死をつくる（事故に見せかける）
- **表の顔**：導機の改良を進める、進歩的な技術者と貴族の集まり
- **二百年前**：修道院を王に召し上げさせたのは、環の祖たちだった。修道院の書庫にあった「死者と精霊を敬う古い書」（アグネスが隠した書物）を奪い、裏返して使うつもりだった。書物は見つからなかった。アグネスを密告した修道女ベアトリスは、環に買われていた
- **ヘイズミア（背景。軸にはしない）**：十五年前、環は北の村ひとつぶんの魂を、一度に霊石にする「儀式」を試みた。儀式はしくじった。村人の魂は石に入らず、霊として村に残った。瘴気はその名残。環は村を立ち入り禁止にさせて、しくじりを隠した。……瘴気が薄れはじめたことに、環も気づいている
- **闇の術（世の中では、ほとんど知られていない）**：
  - **縛り紋**：刻導の禁じ手。霊や精霊を、石や物に縛る
  - **呼び寄せ**：死者の霊を、遠くから呼びつけて動けなくする（霊には激しい苦痛）
  - **影食み**：識導の禁じ手。人の心の、恐れの部分だけを大きくする
  - 世の中では「黒い導術」と呼ばれ、ずっと昔に絶えたと思われている

## 学院の中の環
- **副学院長マーガレット・ソーン**：環の一員。学院の中の目
- **猟犬ダグ**：環に雇われた、霊を狩る男。都の下町に住む。学院には、出入りの石炭運びとして入りこむ
- 導機局の役人エドガー・ヴァンス（公開の日に来る）は、環のことを知らない。環は、ヴァンスの「学院を導機の養成所に」という考えを、隠れ蓑に使っている

## 環の予定（何もしなければ）
| いつ | 何をする |
|---|---|
| 秋の学期 第2週 | ラヴェルが、幽霊の写った硝子板を学院長に見せに行く。その場に居合わせたソーンが、板を見る。「学院に霊がいる。それを写せた」と知る |
| 秋 第3週 | ソーンが、ラヴェルの研究に「予算をつける」と申し出る。誰と写したのかを、さりげなく聞き出そうとする |
| 秋 第5週（収穫祭） | 猟犬ダグが、石炭運びとして学院に入る。霊計で、学院の霊の居場所を探りはじめる |
| 秋 第9週（灯籠流し） | 霊が川岸に集まる夜。ダグが霊計で数を確かめる。エルスの近くで、霊計の針が狂う（エルスのせいかは、環にもわからない） |
| 冬の学期 第3週 | **タデウスが消える**（ダグの呼び寄せ。厨房の竈がしばらく泣かなくなり、グウェンが首をかしげる） |
| 冬 第6週 | **ノアが狙われる**。井戸の横穴の奥まで、ダグが降りてくる |
| 冬 第7週（公開の日） | ソーンが、ヴァンスとともに学院長の後任の話を進める。ラヴェルの写しが展示されれば、霊のいる場所がおおやけになる |
| 冬 第10週（聖灰の日） | 礼拝堂が開く日。ソーンは、アグネスの隠した書物を探しに、礼拝堂の床下を調べる |
| 夏の学期 | ソーンが学院長の後任に推される。導機競技会で、霊石を使った導機が「試作」として出される（出品者は、環の息のかかった工場の技師） |

## 止める手、気づく手（エルスとまわりの者が、知らずに握っているもの）
- ラヴェルの写しの硝子板：霊がどこにいるかを写せる。環にとっても、エルスにとっても、宝であり、危うい
- グリム：工場の事故の精霊石を調べている。霊石が混じっていれば、聞き分けられる（精霊の声と、人の声の違い）
- アグネスの隠した書物：霊を「縛る」のではなく「送る」古いやり方が書いてある。縛り紋を解く手がかり
- ミナセ：写本の中に見つけた印（書物のありかの手がかり）
- 学院長：環を古くから疑っているが、証がない。ソーンを副学院長に置いているのは、目の届くところに置くため
- エルス：霊と話せる。霊が消えたら、ほかの霊から聞ける。霊石の中の魂の声も、聞こえるかもしれない
