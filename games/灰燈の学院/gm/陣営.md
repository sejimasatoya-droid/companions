# 陣営と対立軸（GM。表に出ている部分は 世界.md にも書く）

## 学院を割る二つの考え
| | 血統主義（白鐘会） | 導機主義（歯車会） |
|---|---|---|
| 大事にするもの | 個人の術。精霊に選ばれた者が、自分の手で頼む | 導機。石さえあれば誰でも導術の力を使える |
| 暮らし | 導機を一つも使わない学生もいる。湯も灯りも自分の術で | 湯沸かしも灯りも導機。術は導機を作り直すため |
| 正しいと思うこと | 精霊との約束を何百年も守ってきた古い家こそ強い。石は精霊との約束を破るもの | 生まれのくじで決まる力は不公平。誰でも使える技が世を良くする |
| 行き過ぎた形 | 給費生は「石頼みの泥棒」。平民の素質は「三代で消える事故」。導機は焼けばいい | 精霊は資源。古い習いと霊の話は迷信。役に立たない者は要らない |
| 生徒の会 | **白鐘会**（会長セバスチャン・ロウ。鐘楼寮が牙城。実行役ダミアン・クロウ、下っ端ジェラルド、一年のまとめ役アデリーナ） | **歯車会**（会長ジャック・ハロウェイ。煙突寮が牙城。一年の星オスカー、二年トビアス） |
| 教師 | ブラックウッド（演習）、フェン（古文書・書庫長）、表向きはソーン副学院長 | グリム（導機学）。渉外のクインが裏で金を流す |
| 学院の外 | 貴族院の古い家の議員たち。王家の紋刻所の一部 | 王立導機局（エドガー・ヴァンス）、工場主の組合、新聞の大手 |
| 行き過ぎた外の団 | （白鐘会の一部の卒業生が作る「静かな鐘」：導機の工場に火をつける。まだ表に出ていない） | **煤の兄弟団**：平民の技師の過激派。「精霊も貴族も要らない」。貴族の屋敷の導術の品を壊す。学院の歯車会の一部と通じている |

## 中ほどにいる者・どちらにも収まらない者
- 学院長：どちらの味方もできない。対立が深まるのをまずいと思い、一石を投じるためにエルスを入れた。力は導機の側（理事会・導機局・金）に押されている
- ローデン家：古い家なのに、精霊石の紋で富を得た「導機の側の貴族」。白鐘会からは「家を石に売った」と蔑まれ、歯車会からは「搾り取る側」と憎まれる。セシリアは家と自分の目のあいだで揺れる
- イーディス、ラヴェル、クランツ、ホルム：導機を使わずに精霊に頼むが、血統の理屈には与しない
- ナディラ、ミナセ：異国の者。両方の陣営から、都合よく使われたり外されたりする
- マーゴット、ブラム：給費生だが、歯車会の「精霊は資源」にはなじめない
- クイン：両方の陣営に、会長に知らせずに金と便宜を流している。対立が深まるほど得をする

## 制度と慣習になった差別
- **給費生の飾り紐**：給費生は灰色の飾り紐を胸につける決まり。白鐘会は「灰紐」と呼んで見下す。歯車会は誇りとしてつける
- **寮の役**：監督生・鐘番などの寮の役は、王国の生まれの者に限る（ナディラは三年でも役につけない）
- **素質なしの者**：精霊にまったく好かれない者は、学院の門をくぐれない（グウェン料理長は、だから学院で働くしかなかった）
- **鐘楼寮の慣習**：鐘楼寮には、導機を持ちこめない。持ちこんだ一年は、白鐘会の「しつけ」を受ける
- **霊と死者**：多くの人にとって、霊は「祓うべき穢れ」。霊が見える、話せると言う者は、教会では悪魔憑き、導機の側では狂人と見なされる（だから学院長はエルスに口止めした）
- **異国の祈り**：南の諸島や東の島国の「精霊に供え物をして頼む」習いは、「未開の迷信」と笑われる

## 対立の火種（何もしなければ育つもの）
- ダミアンの工房棟を壊す計画（ソーンが煽った）。秋の学期の第8週の夜
- 煤の兄弟団が、トビアスとオスカーに近づく
- 導機局の「導機兵器の課程」の話（冬の公開の日に、ヴァンスが持ち出す）
- 学院長の後任争い（ソーンとクイン。白鐘会はソーン、歯車会と導機局はクインを推す）
