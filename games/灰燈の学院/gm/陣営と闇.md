# 陣営と闇（GM。表に出ている部分は 世界.md にも書く）

## 一、学院を割る二つの考え
| | 血統主義（白鐘会） | 導機主義（歯車会） |
|---|---|---|
| 大事にするもの | 個人の術。精霊と何百年も約束を守ってきた古い家の術 | 導機。石さえあれば、誰でも導術の力を使える |
| 暮らし | 導機を一つも使わない学生もいる。湯も灯りも自分の術で | 湯沸かしも灯りも導機 |
| 正しいと思うこと | 石は精霊との約束を破るもの。精霊は家の血と結んだ約束で応える | 生まれのくじで決まる力は不公平。誰でも使える技が世を良くする |
| 行き過ぎた形 | 給費生は「灰紐」「石頼みの泥棒」。平民の素質は「三代で消える借り物の灯」。導機の工場は焼けばいい | 精霊は資源。古い習いと霊の話は迷信。役に立たない者は要らない。古い家の屋敷の術の品を壊せばいい |
| 生徒の会 | **白鐘会**。会長オーガスタス・ヴェイル（四年）。一年の星イゾルデ・ヴァルモン。鐘楼寮が牙城 | **歯車会**。会長エゼキエル・トンプソン（四年）。顧問ヘレナ・ストラウド。煙突寮が牙城。一年のハンナ・ペリー、二年のピップ |
| 教師 | （はっきりした後ろ盾はいない。演習のモーンブレイは導機を憎むが、差別は嫌う。書庫長は古い家の味方） | ストラウド（顧問） |
| 学院の外 | 貴族院の血統派（ヴェイル伯、ヴァルモン侯、ドーソン子爵ら） | 王立導機局、工場主の組合、大手の新聞 |
| 行き過ぎた外の団 | **静かな鐘**：白鐘会の卒業生の一部。夜に導機の工場や精霊石の倉に火をつける。「石に閉じこめられた精霊を解き放つ」と言うが、火事で工員が死んでも気にしない | **煤の兄弟団**：平民の技師と工員の過激派。「精霊も貴族も要らない」。古い家の屋敷の「術の品」（家宝の杖や紋の板）を盗み、壊す。歯車会の一部と通じている |

## 二、中ほどの者・どちらにも収まらない者
- 学院長：どちらの味方もできない。学院を動かす力（理事会・導機局・金）は導機の側に握られ、押されている。一石を投じるためにエルスを入れた
- 副学院長ハーグレイヴ：争いから逃げる。どちらの会合にも顔を出して、揉めると席を立つ
- 礼法のクロフト：両方の会に、会長に知らせずに金と便宜を流している（対立が深まるほど、両方が自分を頼るから。そして、環の目くらましのため）
- 回廊寮の人々（寮監コール、監督生グレイ、留学生オコロ、エルス、トム）：回廊寮は、どちらの牙城でもない。だから、両方から勧誘され、両方から疑われる
- 書庫の司書ドーソン：誰にでも同じに本を貸す

## 三、制度と慣習になった差別
- **給費生の飾り紐**：給費生は灰色の飾り紐を胸につける決まり。白鐘会は「灰紐」と呼ぶ。歯車会は誇りとしてつける
- **寮の役**：監督生などの寮の役は、王国の生まれの者に限る（オコロは三年でも役につけない）
- **鐘楼寮の慣習**：鐘楼寮には、導機を持ちこめない。持ちこんだ一年は、白鐘会の「しつけ」（夜中に冷水を浴びせる、部屋の物を全部窓から捨てる）を受ける
- **素質なしの者**：精霊にまったく好かれない者は、学院の門をくぐれない。厨房や下働きにしかなれない
- **女の素質**：百年前ほどではないが、古い家では、娘の素質は「嫁入りの飾り」と見られる（ドーソン、ヴァルモン）
- **霊と死者**：霊が見えると言えば、教会では悪魔憑き（教会の霊安局が「保護」する）、導機の側では狂人
- **異国の者**：南の大陸の祈りは「未開の呪い」、東の島国の習いは「迷信」と笑われる。白鐘会の一部は、オコロの国について、ひどい作り話を流している

## 四、闇：灰の環（はいのわ）
- **何者か**：王国の貴族と、王立導機局の一部の者がひそかにつくる結社。二百年の歴史。表の顔は、導機の改良を進める学者と貴族の集まり
- **求めるもの**：**霊石**。精霊ではなく、死者の魂を石に閉じこめたもの。精霊石の十倍の力を出す。閉じこめられた魂は、石が燃え尽きるまで苦しみ続け、やがて心を失う
- **二百年前**：沈黙の聖ベネディクタ修道院の修道士が、はじめて精霊を石に閉じこめた（光と石の大精霊アウレア）。修道士たちは悔いて、石と、精霊と話す祈り・霊を送る祈りの書を、地下聖堂「沈黙の院」に封じた。環の祖たちは、修道院を王に召し上げさせ、閉じこめ方の写しだけを盗んだ。それが導機の文明の始まり。最初の石と、本物の書物は、いまも沈黙の院にある
- **百年前**：都の工房の寄り合い（いまの導機局の前身）で、盗まれた「最初の石の写し」の試しが暴走。ヘレナ・ストラウドの体の時が止まった
- **十年前**：導機局の東の試験場で、霊石が暴走して爆発。死者十四人。ヴィクトル・ドレイク（いまの副学院長ハーグレイヴ）は、死んだことにして逃げた。死者の魂のいくつかは、環が石に閉じこめた
- **十五年前**：北の荒れ野の湖の村ヘイズミアで、環は「村ひとつぶんの魂を一度に霊石にする儀式」を試みた。儀式はしくじり、湖に霧（瘴気）が湧き、村人の魂は石に入らずに霊として村に残った。立ち会ったのは、クロフトほか。……生まれたばかりのエルスだけが、霧の中で生き残った（理由は、まだ誰も知らない。物語の軸にはしない）
- **五年前**：都の西の精霊石の工場が焼けた（ヴァルモン家の娘の火）。工場には、環の試しの霊石が混じっていた
- **黒い術**（世の中では、とうに絶えたと思われている）：
  - **縛り紋**：刻導の禁じ手。霊や精霊を、石や物に縛る
  - **呼び寄せ**：死者の霊を遠くから呼びつけ、動けなくする（霊には激しい苦痛）
  - **影食み**：識導の禁じ手。人の心の恐れだけを大きくする
  - **霊計**：霊のいる場所を探る導機。針が震える
- **環の者（学院に関わる者）**：
  - 学院の中の目：**シルヴェスター・クロフト**（礼法の教師、渉外）
  - 霊の狩り手：**猟犬**（まだ作っていない。下町の男。収穫祭のころ、石炭運びとして学院に入りこむ）
  - 上の者：理事会の一人（まだ作っていない）、導機局の役人の一人（まだ作っていない）
- **環の目的（いま）**：
  - 沈黙の院の「最初の石」を手に入れること。最初の閉じこめ方の本物があれば、霊石を思いのままに作れる
  - 学院の霊を集めて、霊石を作ること（学院は二百年ぶんの死者がいる、霊の多い土地）
  - 学院長を退かせ、学院の地下を自由に調べられるようにすること

## 五、闇：怪物
- **荒れ精**：精霊石の中で長く苦しんだ精霊が、石が割れたときに狂って飛び出したもの。火の荒れ精は燃え、風の荒れ精は吹き飛ばし、影の荒れ精は人の心に恐れを吹きこむ。世の中では「導機の暴走」として片づけられる。学院では、工房棟の地下の「石の墓場」に巣くっている
- **怨霊**：縛られたり、深い怒りを抱えたまま長く一人でいたりした霊が、心を失ったもの。冷たい手で人の熱を奪う。リリアンは、怨霊になりかけている
- **影の獣**：ヘイズミアの瘴気の名残から生まれる、影のような獣。北の荒れ野にいる。……瘴気が薄れはじめてから、ときどき南へ流れてくる（冬の学期に、都の外れで目撃される）
- **石喰い**：霊石が燃え尽きたあとに残る、心を失った魂の殻。石の中から這い出て、ほかの石の中の魂を食べる。灰の環の試験場の跡にだけいる（まだ学院には出ない）

## 六、外の力
- **王立導機局**：学院の導機の授業を倍にし、「導機兵器の課程」を作りたい。窓口の役人（まだ作っていない）
- **理事会**：学院の金を握る。理事の半分は導機局と工場主の側。理事の中に、十七年前のリリアンの「度胸試し」をさせた名家の子がいる（まだ作っていない）
- **貴族院**：血統派の議員たち（ヴェイル伯、ヴァルモン侯、ドーソン子爵）と、導機派の議員たち
- **教会**：霊安局（トムの伯父）。霊と話す者を「保護」する。保護された者がどこへ行くのかは、霊安局の下の者も知らない（環が教会の上の者を通じて、保護された者を引き取っている。「霊が見える者」は、霊を探す道具になる）
- **新聞**：大手は工場主の側。小さな夕刊がいくつか、事故の本当を書こうとしている
