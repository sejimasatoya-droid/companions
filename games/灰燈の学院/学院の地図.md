# 学院の地図（生徒が知っている）

| 場所 | どこ |
|---|---|
| 正門・前庭 | 学院の南。鉄の門と、馬車回し |
| 大講堂 | 前庭の奥。もと修道院の聖堂。色硝子の窓が七枚（北の一枚だけ割れて、板で塞がれている） |
| 鐘楼 | 大講堂の西に立つ塔。鐘は六つ。上級生の許しなく登れない |
| 鐘楼寮 | 大講堂の西。鐘楼の根もとを囲む |
| 回廊寮 | 大講堂の東。旧修道院の回廊を囲む。中庭に古井戸。奥に閉ざされた礼拝堂（立ち入り禁止） |
| 書庫棟・書庫寮 | 回廊寮の北。もと写字室。地下に刻導の教室 |
| 大食堂・厨房 | 回廊寮と書庫棟のあいだ |
| 工房棟・煙突寮 | 学院の東の端。新しい煉瓦の建物。地下の倉庫は立ち入り禁止 |
| 温室・癒導の教室 | 書庫棟の裏。古い林檎の木がある |
| 演習場 | 学院の北の端。高い石の壁に囲まれた広場 |
| 北の塔 | 演習場の脇。光導の教師の研究室 |
| 学院長室 | 大講堂の二階 |
| 裏の川 | 学院の北を流れる小川 |

学院は、二百年前の修道院「沈黙の聖ベネディクタ修道院」を建て直したもの。

## 外へ出ること
- 学院の中に店はない。文房具や菓子は、週に一度、厨房の裏に来る行商の荷馬車で買う（毎週の六日目の朝）
- 週末は、寮監に届けを出せば、夕べの鐘まで都（ハルステッド）へ出てよい。正門から乗合の蒸気馬車で半刻
