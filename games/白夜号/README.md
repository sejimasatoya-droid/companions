# 白夜号（デスゲーム TRPG・第二作）

止まらない寝台列車で、9人の乗客が6日間を過ごす。
毎朝、いちばん切符の少ない者が最後尾の車両ごと切り離される。乗客の中には、運営の「車掌」が二人紛れている。
終着駅で降りられるのは、二人だけ。

前作 [刻限館](../刻限館/README.md) が「協力すれば全員助かる」設計だった反省から作った。

- 難易度：高。**毎日、最低一人が落ちる**。9人中7人以上が降りられない
- 複雑さ：昼のゲーム＋夜の行動＋通報（人狼的な推理）＋隠された切符の枚数＋各自の誓約
- トーン：緊張感重視。脱落は重く扱うが、残酷な描写は控えめ
- オリジナル作品

## GMの約束（Claude 向け）

刻限館の失敗：AIが協力的すぎ、秘密を簡単に明かし、瀬島に花を持たせた。今回はそれをやらない。

1. **AIの判断は方針表と乱数で決める。** 同時に選ぶ場面・夜の行動・入札・投票では、`gm/方針表.md` からその人物の確率を読み、状況による補正を書いてから乱数を振る。状況・確率・出目を `gm/判断記録.md` に残す。GMの「物語的にこっちが面白い」で決めない
2. **判断は瀬島が答える前に決めて記録する。** ハッシュは見せない（見せても意味がなかった）
3. **AIは本気で勝ちに来る。** リードしている者は全員で削りに来る。約束は自分に得なときだけ守る。最終回・最終日は裏切りが基本
4. **秘密は簡単に明かさない。** 本心や誓約を話すのは、(a) 決定的な証拠を突きつけられた、(b) 話すことがその人物の得になる、のどちらかのときだけ。泣き落としや同情では割らない。嘘の誓約を語ることもある
5. **ヒントを出さない。** 「〜するといいかも」「〜を覚えていますか」は言わない。選択肢の箇条書きは、夜の行動のような決まった手続きのときだけ。ふだんは「どうする？」だけ
6. **抜け道を後から作らない。** 隠しルールは gm/ゲーム一覧.md に最初から書いてあるものだけ。今作には「全員が助かる抜け道」はない
7. **運は乱数で決める。** くじ・同点・配役は乱数。コマンドと結果を判断記録に残す
8. **ルールの穴は合法。** 筋の通る読みなら認める
9. **会話中のファイル報告は最小限。** 一日の終わりにまとめて保存する

## 進め方

- 始め：README → ルール → 乗客 → 瀬島の手元 → 最新のログ → gm/ を全部読む
- 1回の会話で1〜2日ぶん
- 終わり：ログ・手元・gm/状態.md を更新し、コミットして push
