- 第1日昼：瀬島が千早と組む（半分け）。久我の三人組の誘いを断る。3回目の行動「誰でもいい」→ random.choice → 鷺沼
- 第1日昼：鷺沼と契約（毎回、遊戯前に数を伝え合う。勝った者は壺の半分を相手に）。鷺沼は嘘をつかない人物なので、伝える数は本当
- 第1日 第1回 NPCの数（方針表の確率で抽選。久我は瀬島に断られた補正で 1:.20 2:.25 3:.25）→ {'鷺沼': 1, '宇佐美': 7, '権藤': 1, '真柴': 4, '久我': 3, '戸川': 4, '北條': 4}。千早は瀬島の指示どおり

- 千早が4枚返す → 千早7、瀬島8、鷺沼11
- 第1日 第2回 NPC（補正：前回の勝ち数2の周り1〜3を各-0.1、4と5へ）→ {'鷺沼': 4, '宇佐美': 2, '権藤': 4, '真柴': 4, '久我': 5, '戸川': 5, '北條': 4}
- 第1日 第2回 結果：瀬島3（鷺沼には「3」と本当を伝えた）、千早2（指示）
  - 2:宇佐美・千早（重なり）／3:瀬島／4:鷺沼・権藤・真柴・北條（重なり）／5:久我・戸川（重なり）
  - 最小の唯一＝3 → 瀬島の勝ち。壺＝9＋8＝17
  - 切符：瀬島7+17=24、鷺沼9、千早5、宇佐美2、権藤1、真柴1、久我1、戸川1、北條1
  - 第3回の参加料を払うと、1枚の5人は0になって即切り離し。車掌2人とも1枚
- 第1日 第2回 結果：瀬島2（鷺沼に「2」と本当に伝えた）、千早3（指示）
  - 2:宇佐美・瀬島（重なり）／3:千早／4:鷺沼・権藤・真柴・北條（重なり）／5:久我・戸川（重なり）
  - 最小の唯一＝3 → 千早の勝ち。壺＝9＋重なり8＝17
  - 切符：千早23、鷺沼9、瀬島6、宇佐美2、権藤1、真柴1、北條1、久我1、戸川1

- 第1日 第3回前：千早が瀬島に10枚（瀬島16、千早13）。瀬島は「誰にも渡さない。欲をかいたからだ」

  - 1:鷺沼・宇佐美（重なり）／2:千早／3:瀬島・戸川（重なり）→ 千早の勝ち。壺＝9＋4＝13
