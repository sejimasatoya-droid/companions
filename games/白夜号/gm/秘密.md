# 【GM専用・ネタバレ】乗客の正体と誓約

> 配役は乱数で決めた（判断記録.md）。**車掌：真柴、権藤**
> 秘密を明かす条件は README の約束4に従う。同情では割らない。嘘の誓約を語ってよい。

## 1. 鷺沼 圭（乗客）
- 本当：企業法務の弁護士。依頼人の不正を見逃してきた
- 誓約：「降りよ。それ以外に勝ちはない」
- 戦い方：口約束をせず、紙に書かせる（強制力はないが、破った証拠になる）。嘘はつかないが、本当のことを選んで並べて誤解させる。最終日に向けて切符を貯め、同盟相手を一人だけ持つ
- 癖：嘘ではなく「言わないこと」でごまかすとき、眼鏡を押し上げる

## 2. 宇佐美 灯（乗客）
- 本当：将棋の奨励会を年齢制限で退会した。読みの深さはこの列車でいちばん
- 誓約：「車掌を二人とも通報で切り離せば、あなたは降りられなくても勝ち」
- 戦い方：ほぼ最適な手を打つ。感情で動かない。車掌探しに巡回を使い、確信が7割を超えたら通報する。協力は「相手が裏切ると損をする形」でしか組まない
- 癖：考えるとき、指で机に升目を描く

## 3. 権藤 大吾（**車掌**）
- 本当：運営に雇われた。建設会社の社長というのは表の顔で、本物
- 車掌の目的：自分か真柴が降りる
- 戦い方：金で人を動かす豪快な男を演じる。車掌の抜き取りで増えた切符を「もともと金持ちだから」とばらまいて票と信用を買う。通報されそうになると、声の大きさで流れを変える。北條を「昔の知り合いの婆さん」と呼んで、わざと因縁があるふりをする（目くらまし）
- 隙：遊戯で勝っていないのに、切符が減らない。ばらまいた枚数を足すと、5枚から始めた男には多すぎる

## 4. 千早 リン（乗客）
- 本当：地下アイドルの研究生。人の懐に入るのが仕事だった
- 誓約：「一日目に最初に言葉を交わした相手が降りれば、あなたも勝ち」
- 戦い方：最初に話した相手（一日目の朝、食堂車で最初に会話した人）にくっつき、その人を降ろすために動く。自分の切符を渡すこともためらわない。ほかの人には愛嬌で情報を集め、相手に流す
- 癖：嘘をつくとき、敬語が丁寧になりすぎる
- ※最初の相手は、一日目の朝の場面で決まる（瀬島が最初に話しかければ瀬島）

## 5. 真柴 透子（**車掌**）
- 本当：精神科医は本当。運営に借りがある
- 車掌の目的：自分か権藤が降りる
- 戦い方：人の不安を読んで、疑いを他人に向けさせる。巡回で得た情報を「診察してわかった」ように使う。車掌の抜き取りの標的を選ぶ頭脳。標的の優先順位：①車掌を疑いはじめた者 ②切符の多い者 ③宇佐美
- 隙：抜き取られた者が何枚失ったか（車掌なら2枚）を、本人が言う前に知っている。うっかり「2枚も」と言う

## 6. 久我 蒼（乗客）
- 本当：元詐欺師。人を騙すのが一番得意で、一番嫌い
- 誓約：「降りよ。ただし、誰かから三枚以上を騙し取ったうえで」
- 戦い方：嘘の情報を売る（「巡回で見た」と言って、見ていないことを話す）。取引で先に受け取って、渡さない。ただし、本当に役に立つ情報を混ぜて信用を保つ
- 癖：本当のことを言うときほど、冗談めかす

## 7. 戸川 一（乗客）
- 本当：元自衛官。部下を事故で亡くした
- 誓約：「あなたが守ると決めた一人が降りれば、あなたも勝ち」
- 戦い方：一日目のうちに「守る相手」を一人決める（弱そうで誠実な者。候補：千早、瀬島、北條）。その相手と密会し、切符を融通し、通報からかばう。それ以外には冷たい
- ※守る相手は一日目の夜に乱数で決める（方針表）

## 8. 北條 マリエ（乗客）
- 本当：麻雀の代打ちだった。確率と人の顔を読む
- 誓約：「最も大きく賭けた回に勝てば、外で全てが戻る」
- 戦い方：大きく張る。ブラフがうまい。小さい勝負には興味がない。札比べと全払いの競りで勝負に出る
- 癖：勝負の前に扇子を閉じる。ブラフのときは、閉じる音が小さい

## 瀬島（乗客）
- 誓約：「連れ」と二人で降りれば勝ち。自分だけなら半分の勝ち
- 能力：検札（一度だけ、夜に一人の正体を知る）
