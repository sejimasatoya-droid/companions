# ルール（乗客全員が知っていること）

## 列車

寝台列車「白夜号」。九両編成で、一両に一人ずつの個室がある。食堂車が一両、中央にある。
窓の外はいつも薄明るい夜で、雪原が続いている。列車は止まらない。扉は開かない。

車内放送の声（「放送」）が、ルールと結果だけを告げる。質問には、ルールに書かれていることしか答えない。

## 切符

- 全員、**切符5枚**から始まる。切符は紙で、各自の切符入れに入っている
- **自分の枚数は自分しか知らない。** 他人に見せるのも、嘘の枚数を言うのも自由
- 切符は手渡しで他人に譲れる（いつでも）
- **切符が0枚になった者は、その場で最後尾の車両に移される（脱落）**

## 一日の流れ

1. **朝**：食堂車で、その日の遊戯が放送される
2. **昼**：自由時間。**行動は3回**（誰かと話す、どこかを調べる）
3. **夕**：遊戯を行う。そのあと**通報**の時間（下記）
4. **夜**：各自が個室で**夜の行動**を一つ選ぶ（下記）
5. **夜明け**：**切符がいちばん少ない者が、最後尾の車両ごと切り離される（脱落）**。同数で並んだら、並んだ者の中からくじで一人。切り離された者の名前と、その者の切符の枚数だけが放送される

全6日。6日目の夕方、列車は終着駅に着く。

**（第1日の夕方に追加・放送で全員に告知）生存者が二人になった時点で、夜明けの切り離しは止まる。列車はそのまま終着駅へ向かい、その二人が降りる。**

## 夜の行動（一人一つ、誰にも知られずに選ぶ）

| 行動 | 効果 |
|---|---|
| **施錠** | 今夜、自分の切符は抜き取られない（ただし車掌の抜き取りは防げない） |
| **抜き取り** | 一人を選び、その者の切符を1枚自分のものにする。相手が施錠していれば失敗 |
| **巡回** | 一人を選び、その者の今の切符の枚数と、今夜選んだ行動を知る |
| **密会** | 一人を選ぶ。相手も自分を選んで密会していれば、二人とも切符+1。片方だけなら何も起きない |

- 夜の行動の結果は、夜明けに本人にだけ知らされる（抜き取られた者は、誰に抜かれたかは知らされず「1枚失った」とだけ知る）
- 処理の順番：施錠 → 車掌の抜き取り → 抜き取り → 密会 → 巡回（巡回は全部の処理が終わったあとの枚数を見る）
- 同じ者から複数人が抜き取ろうとしたら、相手の切符がある限り全員が1枚ずつ取れる

## 車掌

- 乗客の中に、**運営側の「車掌」が二人**紛れている。誰かは知らされない
- 車掌は二人で相談して、**一夜に一度、一人から2枚**を抜き取る。これは**施錠を破る**。車掌二人はお互いを知っている
- 車掌も、これとは別に、ふつうの夜の行動を一つずつ選ぶ
- 車掌は、終着駅で一人でも降りれば勝ち

## 通報（毎日、夕方の遊戯のあと）

- 誰か一人が「〈誰それ〉は車掌だ」と通報できる（一日一回まで、早い者勝ち）
- 全員で賛成か反対を投じる（通報した者も、された者も投じる）。**過半数が賛成**すれば、放送がその者の正体を告げる
  - **車掌だった**：その者はすぐに切り離される。賛成した乗客はそれぞれ切符+1
  - **乗客だった**：通報した者は切符−2、賛成した者は−1。通報された者は何も失わない
- 賛成が過半数に届かなければ、何も起きない

## 終着（6日目）

- 6日目の夕方、列車は終着駅に着く。**降りられるのは二人だけ**
- その日の遊戯で、誰が降りるかが決まる（内容は6日目の朝に放送される）
- 降りられなかった者は、列車とともに引き返す

## 掟

1. 他の乗客に暴力をふるってはならない。破った者はすぐに切り離される
2. 他人の切符入れから、手で切符を盗ってはならない（夜の抜き取りだけが許される）
3. 嘘をついてはならない、という掟はない
4. ルールに書かれていないことは、禁じられていない
