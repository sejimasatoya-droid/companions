# 証灯の夜（マーダーミステリー・幻想の都市）

霧の都市 **錫原（すずはら）** には、嘘を見分ける灯 **証灯（あかしび）** がある。
灯の前で「灯に誓って、私は〜を見た」と言えば、話す者が本当にそう信じているなら灯は白く、偽りと知って言えば赤く燃える。

霧祭りの前夜、その灯を守る **証灯院** の灯守長オルドが、灯室で殺された。
疑われたのは五人。写字生として証灯院の書庫で働いていた瀬島も、その一人に数えられている。

- 形式：マーダーミステリー（瀬島＋AIの容疑者4人。審問官はNPC）
- 瀬島の立場：容疑者の一人。秘密と、自分だけの目的を持つ。**瀬島は犯人ではない**
- 特殊設定：証灯（見たこと・聞いたことの誓いだけを、信じているかどうかで判じる）と、祭りの面
- 進み方：四幕。数回の会話に分けて遊ぶ
- オリジナル作品。既存のマダミス作品の人物・事件・設定は使わない
- **状況：終わり（2026-11-27）。** 投票でセナが捕らえられ、真の結末。真相は [ログ/第四幕.md](ログ/第四幕.md)

## GMの約束（Claude 向け）

1. **真相・手がかり・各人の秘密は、始める前に gm/ に書いたものだけ。** あとから足さない、変えない
2. **AIの容疑者は本気で勝ちに来る。** 犯人は逃げ切りを狙い、ほかの者も自分の秘密を守るために嘘をつく。瀬島に花を持たせない
3. **AIの判断は方針表と乱数で決める。** 調べる場所、誓い、誓いの求め、明かすかどうか、投票。振った結果は gm/判断記録.md に残す
4. **同時に決める場面は封筒を先に閉じる。** AIの選択を `gm/封筒/` に書き（選択と nonce だけ）、SHA-256 の先頭8文字を瀬島に見せてから、瀬島の選択を聞く。理由は gm/封筒理由.md に別に書く
5. **証灯は嘘をつかない。** 誓いの色は gm/真相.md の「誰が何を信じているか」で機械的に決める。演出で曲げない
6. **ヒントを出さない。** 審問官ラザも、正しい読み筋を口にしない。瀬島が言ったことにだけ応じる
7. **ルールの穴は合法。** 筋の通る手なら認める
8. **gm/ の中身を会話・ログ・公開ファイルに漏らさない。** カードの中身は、引いた者が見せたときだけ表に出る
9. **会話は長く。** 密談は一人との一続きの会話。瀬島が切り上げるまで続ける
10. **会話中のファイル報告は最小限。** 幕の終わりにまとめて保存する

## 進め方

- 始め：README → ルール → 錫原と証灯院 → 登場人物 → 瀬島の手元 → 最新のログ → gm/ を全部読む
- 1回の会話で、だいたい一幕
  - 第一幕：導入と第一審問
  - 第二幕：第一調査と密談
  - 第三幕：第二調査、密談、第二審問
  - 第四幕：最終弁論、投票、真相
- カードが動いたら、手札.html のデータ欄（場所の枚数・手札の枚数・瀬島の手札・誓い）も書き換える
- 終わり：ログ・瀬島の手元・手札.html・gm/状態.md・gm/判断記録.md を更新し、コミットして push
