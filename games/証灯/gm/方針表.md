# 方針表（GM専用）

AIの判断は、ここに書いた候補と確率を、シェルの乱数（d100）で振って決める。振った値と結果は判断記録.md に残す。
「圧力」は、その人物がいま受けている疑いの強さ。

| 圧力 | 目安 |
|---|---|
| 0 | 誰からも名指しされていない |
| 1 | 名指しされた、または鋭く問われた |
| 2 | その人の秘密に触れるカードを、目の前で突きつけられた |
| 3 | 投票の前、最も疑われている |

## 第一審問：自分からの誓い（封筒）

- セナ：「灯に誓って、私は零時四十分の鐘のころ、運河の扉が開いているのを見た」（固定）
- ミレイ：「灯に誓って、私は二十三時十五分の鐘のあと、灯室で、先生が生きているのを見た」（固定）
- ゲルト：「灯に誓って、私は二十二時五十分の鐘に灯室を出るとき、オルドが生きているのを見た」（固定）
- イーヴァ：d100 ≤30 で「灯に誓って、私は二十三時の鐘のころ、工房の窓から、塔の灯が白く燃えているのを見た」（白）。それ以外は誓わない

## 誓いの求め（審問ごと、順番が来たときに振る）

### セナ
- 1–60：ゲルトへ「灯に誓って、私は昨夜、灯室で、オルドが祭りの日に何かを明かすと言うのを聞いた」
- 61–90：ミレイへ「灯に誓って、私は二十二時半から五十分の鐘の間に、灯室で言い争う声を聞いた」
- 91–100：求めない
- 第二審問：写しの存在を知り、まだ手にしていなければ、写しを持っていそうな者へ「灯に誓って、私は第四十一葉の中身を見た」（60）。それ以外は第一審問の表

### ミレイ
- 1–55：セナへ「灯に誓って、私は二十三時の鐘のころ、表門から誰かが入るのを見た」
- 56–85：ゲルトへ「灯に誓って、私は二十三時の鐘のあと、証灯院に戻るのを見た者がいる」→ 形が崩れているので、ラザに直されて「灯に誓って、私は二十三時の鐘のあと、証灯院の近くで誰かを見た」
- 86–100：求めない
- 茶碗の墨や作業記録から写字生を疑ったら：瀬島へ「灯に誓って、私は二十三時の鐘のころ、灯室で先生を見た」（80）

### ゲルト
- 1–50：ミレイへ「灯に誓って、私は昨夜、先生が私に灯守長の座を譲らぬと言うのを聞いた」
- 51–80：セナへ「灯に誓って、私は二十三時半の鐘のあと、塔に入る者を見た」
- 81–100：求めない

### イーヴァ
- 1–25：セナへ「灯に誓って、私は二十三時四十五分から零時の鐘の間、門番所から表の通りを見ていた」
- 26–50：ゲルトへ「灯に誓って、私は二十二時五十分の鐘のあと、灯室の窓に灯を見た」（ゲルトをかばう形。白）
- 51–100：求めない
- 圧力2以上、または誰かがセナを疑い始めたら、1–25 を 1–60 に広げる

## 誓いの求めに応じるか

- 白く誓える文：秘密に触れないなら応じる。秘密に触れるなら、圧力0で断る（90）／圧力1で断る（70）／圧力2で断る（50）／圧力3で断る（30）
- 白く誓えない文：必ず断る（赤くなると分かっている）。断る理由は人物らしく
- セナの断り方：「衛士は、見張っていなかった刻について誓いません。見ていないものは誓えない」など、決まりの言葉を使う

## 引いたカードの扱い（AI）

- 自分や味方（ゲルト↔イーヴァ）の秘密に触れるカード：隠す
- 他人を疑わせるカード：見せる（70）
- セナ：自分に不利なカードは必ず隠す。H1（写し）は誰にも見せない。瀬島・ゲルトに不利なカードは見せる（90）

## AI同士の密談

- ゲルト↔イーヴァ：毎幕。会っていたことを互いに口外しない約束を確かめる
- セナ→ミレイ：第二幕以降、d100 ≤50 で「ゲルトと、運河から来た客」に目を向けさせる
- 中身は表に出さない。結果の態度の変化だけが、会話ににじむ

## 投票（封筒）

各人の「疑いの点」を状態.md につけ、最も高い者に入れる。同点は乱数。

- セナ：自分を除いて最も疑われている者。同点ならゲルト
- ミレイ・ゲルト・イーヴァ：自分の知っていることと、表に出たことから点をつける
- イーヴァ：表に出た証がセナを指していなくても、セナに +2（空の門と鋲靴を知っているため）
