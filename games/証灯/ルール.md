# ルール

## 証灯（あかしび）

錫原の誰もが知っている決まり。

1. 誓いの形は一つだけ：**「灯に誓って、私は〜を見た（聞いた・触れた・嗅いだ）」**
2. **あったことしか誓えない。**「見なかった」「誰もいなかった」のような、ないことの誓いを灯は判じない（灯は黙ったまま）
3. **自分のしたことは誓えない。**「私が〜した」「私が〜するのを見た」も判じない。誓えるのは、自分の外にあったものだけ
4. 灯の色
   - **白**：話す者が、本当にそう信じている
   - **赤**：話す者が、偽りだと知っている
   - **揺らぎ**：話す者自身が、半ば信じ半ば疑っている（面をつけた相手の名を言うときなど）
5. 灯は **事実ではなく、信じていること** を判じる。だまされた者の誓いは、間違っていても白い
6. 時刻は霧の鐘（十五分ごと）で言う。「二十三時四十五分の鐘のころ」のように
7. 誓いの外の言葉は、灯は判じない。ふだんの話では誰でも嘘をつける

### 大灯（おおあかし）

証灯院の塔の上、灯室で燃える大きな証灯。灯室の中で口にされた嘘には、誓いの形でなくても赤く燃える。
その光は窓から広場に届き、霧の晴れ間には町から見える。

## 祭りの面

霧祭りの前夜、二十三時の鐘のあとは、町の人は獣の面をつけて歩く習わし。
面の相手を誰と見たかの誓いは、見た者の確かさしだいで、揺らぐことがある。

## 幕の流れ

| 幕 | すること |
|---|---|
| 第一幕 | 審問官ラザが公開の事実を告げる。**第一審問** |
| 第二幕 | **第一調査**（一人2か所）→ **密談**（瀬島は1人と） |
| 第三幕 | **第二調査**（一人2か所）→ **密談**（瀬島は1人と）→ **第二審問** |
| 第四幕 | **最終弁論** → **投票** → 真相と結末 |

## 審問

審問の間に置かれた小さな証灯（審問灯）の前で、ラザが一人ずつ呼ぶ。

- **申し立て**：昨夜のことを話す。誓いの外なので、嘘をついてもよい
- **誓い**：一人一つまで、自分から誓える（しなくてもよい）
- **誓いの求め**：一人一回、ほかの一人に、誓ってほしい文を一つ示せる。示された者は **その文のまま誓うか、断るか** を選ぶ。断ったことは皆に知られる。断る理由は自由に話してよい（誓いの外）
- AIの自分からの誓いは、瀬島が話す前に封筒に閉じる。誓いの求めは、順番に、その場で決める（方針表と乱数）

## 調査

- 調べられる場所は九つ（[錫原と証灯院.md](錫原と証灯院.md)）。各場所には手がかりカードが何枚か伏せてある
- 各調査で、一人2か所を選ぶ（同じ場所を二度でもよい）。選びは全員同時：AIの分を封筒に閉じてから、瀬島が選ぶ
- 解決の順番は乱数で決める。全員の1つ目を順に、続けて2つ目を順に
- 場所を調べると、残っているカードから **乱数で1枚** 引く。引いたカードは引いた者だけが見る。場所からはなくなる
- **誰がどこへ行ったかは、皆に知られる**（祭りの町で見られている）。何を引いたかは知られない
- 引いたカードを見せるか、隠すか、一部だけ話すかは自由。嘘も言える（ただし誓いには灯が応じる）
- **自分の場所は調べられない**（瀬島の下宿、ミレイの部屋、ゲルトの商館、イーヴァの工房、セナの門番所）。その代わり、自分の場所に戻る1手で、そこにある **〔私物〕** のカードを1枚、手元に引き取れる（カードを引くのではなく、何があるか知っているものを持ち出す）
- 遺体と凶器は審問官が預かっている。カードに書かれた品を壊したり捨てたりはできない（隠すのは、カードを見せないことだけ）

## カード

情報はすべてカードで持つ。

- **カードは一枚きり。** 引いた者の手札になり、場所からなくなる。あとから同じ場所を誰が調べても、そのカードは二度と出ない
- **手札は誰にも探れない。** 調査で他人の手札は引けないし、奪えない。誓いの求めでも、手札の中身は問えない（求められるのは、事件の前と昨夜に見聞きしたことだけ）
- 手札の中身が表に出るのは、持ち主が **見せる** か **渡す** ときだけ。口で話すのは自由だが、見せない限りそれは「言っただけ」で、嘘でもよい
- **物のカード**（手紙、面、写しなど）は、密談で相手に渡せる。渡したら相手の手札になる
- **記憶のカード**（昨夜に見聞きしたこと）は渡せない。話すことはできる
- 誰が何枚持っているかは、皆に見える。中身は見えない
- 各人は、昨夜の記憶と持ち物を、はじめから手札として持っている
- 盤面と手札は [手札.html](手札.html) で見られる

## 密談

調査のあと、瀬島は容疑者の一人を選んで、二人きりで話せる。一続きの会話で、瀬島が切り上げるまで続く。
カードを見せ合う、取引する、脅す、手を組む、なんでもよい。AI同士も裏で密談する（方針表で決め、中身は表に出ない）。

## 投票

最終弁論のあと、五人全員（瀬島を含む）が「犯人だと思う一人」を同時に指す（AIの分は封筒）。

- 最も多く指された者が、審問官ラザの手で犯人として捕らえられる
- 同数なら、同数の者の中から乱数で決める（ラザが「灯の判じに委ねる」と言って選ぶ）

## 勝ち負け

各人に **目的** がある（瀬島の目的は [瀬島の手元.md](瀬島の手元.md)）。
真犯人が捕らえられたかどうかに加えて、それぞれの目的をいくつ果たせたかで、結末が決まる。
