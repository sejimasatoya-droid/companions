# 錫原と証灯院

## 錫原（すずはら）

山あいの谷にある、運河と石橋の町。夜になると谷底から霧が上がり、町じゅうに鐘が十五分ごとに鳴る（霧の鐘）。
今日は年に一度の **霧祭り**。前夜は、二十三時の鐘から夜明けまで、獣の面をつけて歩く。

## 証灯院（あかしびいん）

広場の北に立つ三階建ての塔。町の審問はここで行われ、証灯の火はすべてこの塔の大灯から分けられる。

```
            【広場】  泉、屋台
               │
         ┌─────┴─────┐
  三階   │   灯室    │  大灯。広場側に大きな窓
         ├───────────┤
  二階   │ 書庫 │ ミレイの部屋 │
         ├───────────┤
  一階   │ 門番所(表門) │ 審問の間 │ 運河の扉(裏) │
         └─────┬─────┘
               │（裏手）
            【運河】  石段、細い道
```

- 階段は一本。一階の真ん中から三階まで続く
- **表門**には門番所があり、夜は衛士が一人で番をする。出入りは門番帳につける
- **運河の扉**は、裏手の運河に面した荷入れ口。油の樽を入れるのに使う。**内側から閂をかける**。門番所からは壁に隠れて見えない

## 審問官ラザが告げた事実（公開）

- 灯守長オルドは、灯室で、後頭部を打たれて死んでいた。そばに真鍮の油差しが転がっていた。床に油がこぼれていた
- 大灯は消えていた
- 見つけたのは衛士セナ。零時四十分の鐘のころ
- 二階の書庫で、**灯籍簿（とうせきぼ）**――審問で灯が赤く燃えた記録の帳――から、**第四十一葉が一枚、破り取られていた**
- 一階の **運河の扉は閂が外れ、少し開いていた**
- ラザの見立て：亡くなってから、見つかるまで、長くても二時間ほど
