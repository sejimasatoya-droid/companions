# 遊戯集（GM専用・ネタバレ）

> **瀬島は読まない。** デスゲームの「昼の遊戯」をためておく場所。新しい作品を作るときは、ここから選び、その作品の `gm/ゲーム一覧.md` に写して数を合わせる。

## なぜ作ったか

白夜号の遊戯は、一つの遊戯に仕組みが一つだけだった（最小の唯一、押しつけ、大小比べ、全払い、平均の2/3）。読み筋も一段で終わり、「わかったら勝ち」になっていた。
ここに置く遊戯は、**一つの遊戯の中に、少なくとも三つの層**を重ねる。

## 方針の転換（氷室のあと、2026-11-24）

**資源（貝・炭・切符）を日をまたいで持ち越すデスゲームはやめる。一回一回の遊戯が独立したデスゲームにする。**

- 理由：持ち越すと、早く勝った者が強くなり続ける。遊戯の中の読み合いより、持っている量で決まってしまう（氷室で白石が7枚から14枚になり、負けても痛くない側にいた）。情報の値打ちも小さかった
- 測ったこと（乱数、2万回前後。持ち越し型の遊戯での「知ることの得」）
  - 影踏み：何も知らない −0.96、一人の札を知る −0.70、全員の札を知る +0.03
  - 雪見の競り：自分の箱だけ知る約+0.4〜0.8、全部の箱と全員の書く数を知って最善に打っても約+0.9。知っても1枚ほどしか変わらない
  - 申告の帳場：何も知らずに嘘をつく −0.2、全員の申告を知って最善に打つ +1.2（+1.4の差。一人ぶんだけ知って推し量ると、かえって −1.3）
- これからの遊戯：その遊戯の中だけで勝ち負け（生き死に）が決まる。始まりは全員同じ。前の日の勝ち負けを持ち込まない
- 下の「設計の約束」のうち、三つの層・協力が崩れる・情報の値打ち（約束8）は引き継ぐ。持ち札（約束7）と「一日一人が落ちる枠組み」は、新しい形に合わせて作り直す

## 設計の約束

1. **三つの層。** 次の三つを必ず重ねる
   - **隠し情報**：自分しか知らない札・重さ・中身がある。人によって知っていることが違う
   - **取引**：遊戯の途中で、物や情報をやりとりできる。ただし、確かめられる情報と確かめられない情報がある
   - **ルールの読み**：公開ルールの中に、素直に読むと見落とす一文がある。それに気づいた者が得をする「深い手」と、それを見越した「返し手」がある
2. **全員で協力すると損をする。** 全員が持っている情報を正直に出し合うと、全員がほぼ同じ手を選び、取り分が割れて、参加料の分だけ負ける。協力は「少数で組んで、残りを出し抜く」形でしか得にならない
3. **一回では終わらない。** 3〜4回、または2段階に分け、前の回の結果（放送）から推理が進むようにする
4. **計算させる。** 枚数・確率・重さの合計を数えた者が得をする。ただし計算だけで解けないよう、相手の嘘が入る
5. **公開ルールはすべて放送で読む。** 深い手の一文は、ほかのルールと同じ調子で、同じ長さで読む。強調しない。質問されたら、ルールの文言どおりにだけ答える
6. **釣り合いを数で確かめる。** 各遊戯に、乱数で打ったときの期待値と、−3以上を食う割合を書く。作品の枠組み（切符の枚数、切り離し）は、この数から逆算して決める（白夜号の第1日は、これをしなかったので9人中6人が落ちた）
7. **遊戯は「持ち札」で戦う。** 炭（貝・切符）の多さが、遊戯の中で打てる手を増やさないようにする（氷室の反省：書ける数が手持ちで縛られ、多く持つ者だけが強気に打てた）
   - 遊戯の朝、全員に同じ枚数の「持ち札」を配る。参加料・入札・支払い・遊戯の中のやりとりは、すべて持ち札で行う
   - 持ち札が足りなければ、払える分だけ払い、その回からは降りる（その場で脱落はしない）
   - 遊戯が終わったら、**持ち札の増減を炭に直す**。ただし**一日に失う炭は多くても5枚**
   - 持ち札の枚数は、遊戯ごとのファイルに書く。遊戯の外（昼の取引・遺品の競り・告発）は、これまでどおり炭で行う
8. **情報に値打ちがあるかを数で確かめる。** 隠し情報の遊戯なら、乱数で「何も知らずに打つ」「一人の手を知って打つ」「全員の手を知って打つ」の三つを比べる。**一人の手を知ると +1 以上、全員の手を知ると +3 以上**良くならなければ、情報戦になっていないので入れない（影踏みは、一人で +0.3、全員でも +1.0 しかなかった）

## 作品に入れるとき

- **誓約と能力は [誓約と能力.md](誓約と能力.md) の約束に従う**（澪標で働かなかった反省）
- **持ち札（約束7）を使う。** 澪標より前の五つの遊戯（天秤の塔〜救命艇の名簿）を使うときも、参加料と支払いを持ち札に直す。持ち札の枚数は、乱数打ちで持ち札が尽きる人が1割以下になるように決める

- 一日一つ。同じ作品で、同じ層（例えば「伏せ交換」）を二日続けない
- 枠組みの切符の枚数は、遊戯の期待値と振れ幅から決める。目安：**一日で平均一人が落ちる**ように、遊戯の損と参加料を合わせる
- NPCがどの手を取るかは、その作品の `gm/方針表.md` に、遊戯ごとの確率として書く（「深い手に気づく確率」「嘘をつく確率」など）
- 新しい遊戯を作ったら、ここに足して一覧に一行書く
