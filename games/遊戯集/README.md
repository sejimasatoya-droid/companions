# 遊戯集（GM専用・ネタバレ）

> **瀬島は読まない。** デスゲームの「昼の遊戯」をためておく場所。新しい作品を作るときは、ここから選び、その作品の `gm/ゲーム一覧.md` に写して数を合わせる。

## なぜ作ったか

白夜号の遊戯は、一つの遊戯に仕組みが一つだけだった（最小の唯一、押しつけ、大小比べ、全払い、平均の2/3）。読み筋も一段で終わり、「わかったら勝ち」になっていた。
ここに置く遊戯は、**一つの遊戯の中に、少なくとも三つの層**を重ねる。

## 設計の約束

1. **三つの層。** 次の三つを必ず重ねる
   - **隠し情報**：自分しか知らない札・重さ・中身がある。人によって知っていることが違う
   - **取引**：遊戯の途中で、物や情報をやりとりできる。ただし、確かめられる情報と確かめられない情報がある
   - **ルールの読み**：公開ルールの中に、素直に読むと見落とす一文がある。それに気づいた者が得をする「深い手」と、それを見越した「返し手」がある
2. **全員で協力すると損をする。** 全員が持っている情報を正直に出し合うと、全員がほぼ同じ手を選び、取り分が割れて、参加料の分だけ負ける。協力は「少数で組んで、残りを出し抜く」形でしか得にならない
3. **一回では終わらない。** 3〜4回、または2段階に分け、前の回の結果（放送）から推理が進むようにする
4. **計算させる。** 枚数・確率・重さの合計を数えた者が得をする。ただし計算だけで解けないよう、相手の嘘が入る
5. **公開ルールはすべて放送で読む。** 深い手の一文は、ほかのルールと同じ調子で、同じ長さで読む。強調しない。質問されたら、ルールの文言どおりにだけ答える
6. **釣り合いを数で確かめる。** 各遊戯に、乱数で打ったときの期待値と、−3以上を食う割合を書く。作品の枠組み（切符の枚数、切り離し）は、この数から逆算して決める（白夜号の第1日は、これをしなかったので9人中6人が落ちた）

## 作品に入れるとき

- **誓約と能力は [誓約と能力.md](誓約と能力.md) の約束に従う**（澪標で働かなかった反省）

- 一日一つ。同じ作品で、同じ層（例えば「伏せ交換」）を二日続けない
- 枠組みの切符の枚数は、遊戯の期待値と振れ幅から決める。目安：**一日で平均一人が落ちる**ように、遊戯の損と参加料を合わせる
- NPCがどの手を取るかは、その作品の `gm/方針表.md` に、遊戯ごとの確率として書く（「深い手に気づく確率」「嘘をつく確率」など）
- 新しい遊戯を作ったら、ここに足して一覧に一行書く
