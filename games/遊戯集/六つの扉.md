# 六つの扉（手がかりと嘘の札）

## 一言で
六つの扉の向こうに、得と損がある。手がかりは全員に散らばっていて、合わせれば全部わかる。**ただし、みんなが同じ扉を選ぶと、取り分が割れて損をする。** 手がかりの中に、一枚だけ嘘がある。

## 用意（乱数）
- 扉 A〜F の値：`−4, −2, 0, +2, +4, +8` を乱数で並べる
- 手がかりの札：扉の値から、正しい文を作る（例：「Bの値はDより大きい」「Fは負」「AとCを足すと正」「最も大きい扉は、AかEのどちらか」）。**一人二枚**配る
- そのうち**一枚だけ、誤った文**にする。どの札を嘘にするかは乱数。**嘘の札がある、ということは公開する**
- 札の文は、全員分を合わせると、嘘の一枚を除いても扉の値がほぼ決まるように作る

## 公開ルール（放送でそのまま読む）
1. 食堂車の奥に、六つの扉があります。扉の向こうの値は「−4、−2、0、+2、+4、+8」が一つずつです
2. 皆さんには手がかりの札を二枚ずつ配りました。**配った札のうち、一枚だけが誤りです**。それ以外は正しいことしか書いてありません
3. 札は、ほかの人に見せても、見せなくても、内容を言うだけでも構いません。札を他人に渡しても構いません
4. 遊戯は三回です。各回、全員が参加料として切符を一枚払い、同時に扉を一つ選びます。すでに開いた扉は選べません
5. 選んだ扉の値が**正なら、その扉を選んだ者でその値を分けます**（端数切り捨て）。**負なら、その扉を選んだ者は一人ずつ、その値の半分（切り上げ）を払います**。0なら何も起きません
6. 各回のあと、**選んだ人数がいちばん多かった扉を開け**、その値を放送します。人数が並んだら、くじで一つ。各扉を何人が選んだかも放送します

## 読み筋（三段）
1. **素直な手**：手がかりを持ち寄って+8を探す
   - 罠：七人全員が+8を選ぶと、8÷7＝1。参加料1と差し引き0。三回で−3近くになる
2. **深い手**：
   - **知っている人が少ないほどもうかる。** 二人だけが+8を知っていれば4ずつ。だから札は「全部は見せない」「一部だけ見せる」「言うだけで見せない」が基本になる
   - 開くのは「いちばん多く選ばれた扉」。**+8を知っている者は、ほかの皆を別の扉に集めれば、+8を開けさせずに二回目も取れる**
   - 嘘の札が一枚ある。見せられた札が正しいとは限らない。札どうしの矛盾から、嘘の札を割り出せる
3. **返し手**：
   - 自分の札が嘘だと気づいた者は、それを「本当らしく見せて」他人を−4の扉へ誘える
   - 札を見せれば信用が得られるが、見せた相手が+8に来る。見せたあとに、自分は+4へ逃げる手もある
   - 二回目以降は、一回目の放送（各扉の人数と、開いた扉の値）から、誰が何を知っているかが割れる

## 協力が崩れる理由
- 全員が札を全部見せ合うと、全員が同じ扉に集まり、取り分が割れて参加料で負ける（乱数シミュレーションで、全員が全部知ると平均−2）
- 得をするのは、少人数で情報を独占したときだけ（二人だけが知ると、その二人は平均+2.2、残りは−2.8）

## 釣り合い
- 誰も何も知らずに選ぶと、平均 **約−0.9**
- 全員が全部知ると **−2**、二人だけが知ると **+2.2 / −2.8**

## GM処理
1. 扉の値と札を乱数で作る。嘘の札がどれかも乱数。全部を判断記録に残す
2. 昼：札を見せる・言う・渡すを処理する。NPCが本当を言うか、札を見せるかは方針表と乱数
3. 各回：NPCの扉を決める → 瀬島の扉を聞く → 処理 → 開いた扉と人数を放送
