# 影踏み（三すくみの札）

## 一言で
グー・チョキ・パーの札を三枚ずつ持ち、三回、一枚ずつ同時に出す。じゃんけんの遊戯に見えるが、人数が多いと三つの形がほとんど必ず出そろう。そのとき勝つのは、**出た枚数がいちばん少ない形**。札は全部配られているので、数えれば残りがわかる。

## 用意（乱数）
- 札：グー7、チョキ8、パー9 の24枚（8人のとき。人数×3枚。内訳は「グーが一番少なく、パーが一番多い」ように合わせる）
- 全部配る。各自3枚

## 公開ルール（放送でそのまま読む）
1. 皆さんに、グー・チョキ・パーの札を三枚ずつ配りました。札は全部で二十四枚、内訳は「グー七枚、チョキ八枚、パー九枚」です。抜いた札はありません
2. 遊戯は三回行います。各回のはじめに、全員が参加料として炭を一枚、壺に入れます
3. 各回、全員が同時に、手の札を一枚伏せて出します。出した札は手に戻りません
4. 出た形が一種類だけなら、勝者はいません。二種類なら、じゃんけんで強いほうの形を出した者が勝ちです。三種類とも出たら、出た枚数がいちばん少ない形を出した者が勝ちです。いちばん少ない形が並んだら、勝者はいません
5. 勝った者は、壺の中身を等分して受け取ります。ただし一人が一回に受け取れるのは五枚までです。残りは次の回へ持ち越し、三回目のあとに残ったものは、こちらで預かります
6. 各回のあと、それぞれの形が何枚出たかと、勝った者の名前を放送します
7. 回と回のあいだに、二人の合意があれば、札を一枚ずつ交換できます。見せて交換しても、伏せて交換してもかまいません。炭を添えてもかまいません

## 読み筋（三段）
1. **素直な手**：じゃんけんとして読む。「パーが一番多いから、チョキを出せば勝てる」
2. **深い手**：
   - 8人だと、三つの形が出そろう確率は約94%。**ほとんど毎回、ルール4の後半（少ない形が勝つ）で決まる**。じゃんけんの強さはほぼ関係ない
   - 札は全部配られていて、内訳は公開。毎回の枚数も放送される。**三回目の前には、場に残る8枚の内訳が正確にわかる**。三回目に出すのは最後の一枚なので選べない。だから**勝ち負けは二回目のあとの交換で決まる**
   - 少ない形の札を、最後の一枚として手元に残すように、一回目・二回目の出し方を組み立てる
3. **返し手**：
   - 深い手に気づいた者は、みな「残りがいちばん少ない形」に寄る。寄ると少数でなくなる。**二番目に少ない形**を出すほうが勝ちやすい場面がある
   - 三回目の前の交換では、少ない形の札の値打ちが跳ね上がる。持っている者は炭を添えさせて売れる。伏せて交換すれば、多い形の札を「少ない形だ」と偽って渡せる

## 協力が崩れる理由
- 全員で「順番に勝たせる」約束をしても、三つの形が出そろう限り、少数側に入る人数を合わせる必要がある。一人が形を変えるだけで崩れる。誰が約束を破ったかは、枚数の放送からしかわからない
- 一人の上限が5枚なので、大勝ちを分け合う得が小さい

## 釣り合い（乱数打ち、8人、2万回）
- 乱数で出す：平均 **約−1.0**、−3以下が約6割（三回とも負けると−3）
- 「残りが少ない形」に全員が寄る：平均 約−1.1（寄るほど損）
- 深い手を一人だけ使い、交換で最後の一枚を整える：平均 +1 前後（GMの見積もり）

## GM処理
1. 札を乱数で配る。瀬島には自分の札だけを見せる
2. NPCの出し方：深読みに失敗した者は「じゃんけんで読む」か乱数（.5ずつ）。成功した者は「残りが少ない形」、返し手にも成功した者は「二番目に少ない形」を .6 で選ぶ
3. 交換：二回目のあと、最後の一枚が多い形の者は、攻め の確率で交換を持ちかける。伏せて交換するときは、嘘 の確率で形を偽る
4. 各回：NPCの札を決めて記録 → 瀬島の札を聞く → 集計 → 放送
