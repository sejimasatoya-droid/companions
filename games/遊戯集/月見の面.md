# 月見の面（名前を書いて一人ずつ退場・最後は二人の賭け）

> 一回で完結する長いデスゲーム。資源の持ち越しはない。始まりは全員同じ。使った作品：月見座
> 着想：オープンソースの『AIデスゲーム』（MIT）の骨組み（議論二周→投票、最多が退場、同数は全員、最後の二人は囚人のジレンマ、司会の介入）。面・お題・形見・幕の数え方はオリジナル

## 一言で
七人が幕ごとに名前を書く。最も多く書かれた者が退場（並べば全員）。生きて出られるのは多くても二人。**面**が票の数え方を、一人ずつこっそり変えている。

## 三つの層
- **隠し情報**：自分の面（翁・小面・般若・天狗・狐・素面二枚）。形見の行き先。票は数だけ放送する（誰が誰に書いたかは伏せる）
- **取引**：箱を見せる（偽れない。確かめられる）／口で名乗る（偽れる）／札の約束（開票の数で一部だけ確かめられる。狐と公開札なら確かめられる）／形見の約束（退場する者は、誰に渡すかで最後に一票ぶんの力を持つ）
- **ルールの読み**（ほかの文と同じ調子で読む）：
  1. **自分の名前を書いた札は数えない。** 最後の二人で二人とも自分を書けば、最多が零 → 誰も退場しない → 二人とも生還。片方だけ相手を書けば、書かれた方だけが退場。二人とも相手を書けば並んで二人とも退場（囚人のジレンマが、数え方から自然に出る）
  2. **小面は一つ少なく数える。** 最後の二人で小面が相手を書くと、相手は1、小面は「1−1＝0」。**小面は最後の二人で負けない**（相手が翁でなければ）。翁も、相手を書けば2対1で負けない。翁と小面が残ると、またジレンマになる。だから素面の者は、翁と小面を最後の二人より前に落としたい → 誰が翁・小面かを知ることが生き死にに効く
  3. **七人で五幕。** 二人まで減らすには五人の退場が要る。零の幕（全員が自分を書く「休戦」）を一度でも挟むと、どこかで二人以上を落とさない限り、第五幕のあとに全員が退場する。協力して休むほど死ぬ
  4. **第五幕が終わって二人なら、賭けなしで二人とも生還。** 第四幕までに三人に減らし、第五幕で一人だけ落とせば、最後の賭けを避けられる。計算屋の深い手
  5. **逆さ札では、零の者も退場する。** 全員が一つずつ書き合う「輪」を作ると、全員が最少で並び、全員が退場する。自分に二つ以上集めた者だけが安全。協力の輪が一番危ない
  6. **般若の道連れ**：般若の名を書いた者のうち一人が一緒に落ちる。般若だと口で名乗るのは、札を避ける一番安い嘘
  7. **形見は「次の幕から両方の力」。** 素面が小面を受け取れば、最後の二人で負けない札になる。退場する者は、そのことで取引できる

## 協力が崩れる理由
- 生還は多くても二人。七人の協力は、五人の死の割り振りの話になる。誰も自分を落とす案に乗らない
- 休戦（全員が自分を書く）は、一人が裏切って誰かを書けば、その一人の札だけで書かれた者が退場する（最多1）。休戦するほど、残りの幕で二人落としが要り、最後は全員退場に近づく

## 釣り合い（乱数、3〜4万回。`games/月見座/gm/釣り合い.py`）
- 打ち方の型：毎幕、群れの的を一人選び、各人 .55 でそれに書く。.08 で自分を書く。残りは乱数。最後の二人は .5 で自分を書く（翁・小面は .85 で相手を書く）。退場者は .7 で形見を乱数の一人に渡す。天狗は .4 で使う
- 生還の人数：**0人 32%、1人 59%、2人 8%**（平均 約0.77人）
- 面ごとの生還率：小面 .15、翁 .13、般若 .11、天狗 .10、狐 .09、素面 .09（一人あたりの平均は .11）
- 一幕の退場：1人が5割、2人が4割弱、3人以上が1.5割（並び・二人札・逆さ札・道連れ）。多くは第3〜4幕で終わる
- **知ることの得**（素面の一人が、面の知識で札と的の誘導を変えたとき）：何も知らない .108 → 一人の面を知る .119（+1.1pt）→ 全員の面を知る .165（**+5.7pt、生還率は1.5倍**）
  - 資源の遊戯の「一人で+1、全員で+3」の目安は、生還率では測れない。全員を知ると1.5倍になるので、情報戦にはなっていると見た。一人だけ知る得は小さい（その一人が翁・小面か般若のときだけ効く）
  - 乱数の型は、知識の使い方が粗い（最後の二人の打ち方を変えていない）。実際の得はこれより大きい見込み
- 試して捨てた案：小面を「半分に数える」にしても生還率はほとんど変わらなかった（.15→.16）。わかりやすい「一つ少なく」にした
- 幕の上限：6だとほとんど効かない。4にすると「第4幕のあと二人」で賭けなしに生還する筋が16%になり、甘い。**5**にした（上限で全員退場はまれ、「第五幕のあと二人」は2%弱）

## GM処理
1. 配り・お題の順を乱数で決め、`gm/秘密.md` に書く。瀬島には二つの箱から選ばせる
2. 各幕：口上（お題）→ 楽屋（NPCの予定を先に振る）→ 評定の順を振る → 二周 → NPC六人の札を振って記録 → 瀬島の札 → 開票 → 道連れ・形見 → 放送

## 第二版（第一回のあと、2026-11-28）
- 直したところ（文面は `games/月見座/ルール.md`）
  1. **決選**：最多が並んだら、並んだ者のほかが並んだ者の中から書き直す。それでも並べば全員
  2. **般若の道連れは、書いた者が一人だけのとき。** 二人以上で書けば道連れなし（「一人で書くな」が読みの層になる）
  3. **見せ合いの届け出**：箱を見せ合って届け出た二人は、その幕、互いに書いた札が数えられない。確かめられる約束。代わりに面を相手に渡す
  4. **形見は一人一つまで**
  5. **二人札は第三幕から**
  6. **客席の野次**：退場した者は、評定のあとに一言、名前を一つ言える（瀬島が落ちたあとも遊べる）
- 乱数（3万回、同じ型。見せ合いは一幕に一人あたり .25 で組む）
