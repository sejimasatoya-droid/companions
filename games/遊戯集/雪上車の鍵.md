# 雪上車の鍵（終着向け）

## 一言で
脱出の乗り物に席は二つ。誰が乗るかは全員の書いた名前の数で決まる。だが、乗り物を動かす鍵は、誰か一人が封筒に入れて隠し持っている。**鍵を持つ者が乗らなければ、誰も出られない**。

## 用意（乱数）
- 封筒：人数分。一通だけに鍵、ほかは空。各自に一通。自分の封筒の中は自分だけが見られる

## 公開ルール（放送でそのまま読む）
1. 雪上車が着きました。席は二つです
2. 皆さんに封筒を一通ずつお渡ししました。一通にだけ、雪上車の鍵が入っています。ほかの封筒は空です
3. 夕方まで、二人の合意があれば、封筒を交換できます。中を見せても、見せなくてもかまいません
4. 夕方、全員が同時に、紙に二人の名前を書きます。自分の名前を書いてかまいません。同じ名前を二度は書けません
5. 名前を書かれた数の多い者から二人が、席につきます。並んだら、くじで決めます
6. 席についた二人のどちらかが鍵を持っていれば、雪上車は出ます。どちらも持っていなければ、雪上車は出ません
7. 鍵を持つ者が席につかなかったときは、出発の前に一度だけ、鍵を席の者に渡すことができます。渡すかどうかは、鍵を持つ者が決めます
8. 雪上車が出なかったときは、全員が残ります

## 読み筋（三段）
1. **素直な手**：自分と、組んでいる相手の名前を書く
2. **深い手**：
   - 4人で二つずつ書くと、票は8。**二人組が二組だと、2票・2票・2票・2票で並び、くじになる**。くじを避けるには、三人目の票が要る
   - 鍵を持つ者が誰かで、全部が変わる。鍵の持ち主は、席につけなくても、ルール7で「誰を出すか」を決められる。だから鍵の持ち主は、乗れなくても取引ができる
   - 鍵は封筒ごと交換できる（ルール3）。中を見せずに交換すれば、鍵がどこにあるかを誰も確かめられない
3. **返し手**：
   - 「鍵を持っている」と嘘をついて票を集める。席についても鍵がなければ出られないが、本物の持ち主はルール7で鍵を渡すか決められる。**持ち主に渡す理由がなければ、全員が残る**
   - 全員が残ることで勝つ誓約（仇、長者、語り部）を持つ者は、わざと鍵を隠して車を止める
   - 他人の名前を書いて、その者を席に押し上げる（連れの手）

## 協力が崩れる理由
- 席は二つしかない。三人以上が組むと、誰かが必ず残る。残る者には、ルール7の鍵か、仇の誓約で、車を止める理由がある

## 持ち札
- 使わない（炭の損得がない）。票の取引は炭で行ってよい（最終日なので、炭の多さが効くのはここだけ）

## 釣り合い
- 炭の損得はない。結果は誓約の勝ち負けで決まる
- 4人なら、くじに頼らずに席が決まるのは、三人目の票を買えたとき

## GM処理
1. 封筒を乱数で配る。鍵の持ち主を判断記録に書く（番頭の秘密になる）
2. NPCが鍵を持っていると明かすか：嘘 の確率で偽る（持っていないのに持っていると言う、またはその逆）
3. NPCの書く名前：誓約から決める（方針表）。迷う枠は乱数
4. NPCの名前を記録 → 瀬島の名前を聞く → 集計 → くじ → ルール7 → 放送
